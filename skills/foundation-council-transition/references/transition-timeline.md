# 换届时间轴（transition-timeline）

> 三段式：会前（筹备与报批）→ 会议当天 → 会后（备案与回填）。T 为换届会议日。**北京口径**：会前 30 天报批、会后 30 天内备案。其他地区替换提前天数与材料名称。

## 一、总览（三段式）

```
【第一段·会前报批】（T-30 提交登记管理机关）
  换届申请 / 理事会工作报告 / 财务工作报告 / 换届审计报告 / 法定代表人离任审计报告 /
  经济责任归属申请 / 监事意见草稿 / 理事及负责人候选人名单与简历（均需盖章）

【第二段·会议当天】（T-0，同一天开两次会）
  议程 / 两份选举办法 / 候选人名单简历 / 选票与票样 / 计票统计单 / 主持词 / 背景材料 /
  秘书长专职承诺书 / 监事增补备案书 / 邀请函与回执

【第三段·会后备案】（T+30 内提交登记管理机关）
  会议议程 / 理事会选举办法 / 新一届一次会议选举办法 / 两套选票与计票统计单 /
  两份会议纪要 / 理事监事负责人变动备案书 / 理事表（逐人） / 秘书长专职承诺书
```

## 二、关键节点时间轴（T-365 → T+30）

| 时点 | 节点 | 责任方 | 产出物 | 级别 |
|---|---|---|---|---|
| T-365 ~ T-180 | **开始物色下一届人选**（推荐越早越好，提前一年不为过） | 理事长/发起人 | 人选意向清单 | 基础 |
| T-180 | 确认任期届满日、清点届次台账、启动正式酝酿 | 秘书处 | 届次台账 | 基础 |
| T-120 | 向登记机关咨询当期换届要求，取得材料清单（**提前 2–3 个月问分管老师**） | 秘书处 | 当地材料清单 | 基础 |
| T-120 | 聘请会计师事务所，启动**换届审计 + 离任审计** | 财务部 | 审计业务约定书 | 基础 |
| T-90 | 明确分工（哪怕一人兼，也要列全四类活儿） | 秘书长 | 分工清单 | 进阶 |
| T-60 | 候选人资格审查、征集简历与身份材料 | 换届小组 | 资格审查表、简历册 | 基础 |
| T-45 | 起草理事会工作报告、财务工作报告（覆盖届期） | 秘书处 | 两份报告草稿 | 基础 |
| **T-30** | **向登记机关提交第一份材料包** | 秘书处 | 材料包 + 受理回执 | 基础（红线） |
| T-15 | 发邀请函、回收回执、预核法定人数 | 秘书处 | 回执台账 | 基础 |
| T-7 | 材料定稿、印制；选票印制；会务确认 | 秘书处 | 会议材料 | 基础 |
| **T-0** | 换届会议 ＋ 新一届第一次会议（两次会） | 理事会 | 签到、选票、计票单、两份纪要 | 基础 |
| **T+30 内** | 向登记机关提交第二份材料包（备案） | 秘书处 | 材料包 + 受理回执 | 基础（红线） |
| T+30 后 | 回填理事名册、届次台账、任期台账、变更台账 | 秘书处 | 更新后的名册与台账 | 基础 |

## 四、两段会议的区别（必须分两次）

| | 换届会议 | 新一届第一次会议 |
|---|---|---|
| 参加人 | 本届理事、监事 | 新一届理事、监事 |
| 选什么 | 新一届理事、监事 | 理事长、副理事长、秘书长 |
| 表决门槛 | 普通决议：出席理事过半数 | 特别决议：出席理事 2/3 以上 |
| 时间 | 同一天，先开 | 同一天，紧接其后 |
| 纪要 | 一份（换届会议） | 一份（新一届第一次会议） |

> 合并成一份会怎样：届次台账混乱（一次会议产生两个届次决议）、登记机关退回、日后查"理事长是哪次会议选的"查不出。**必须两次会议、两份纪要、两套签到与选票。**

## 五、延期换届（退路）

- 能延多久：通常可延期一年（以属地口径为准）。
- 正确顺序：提前半年到一年确认候选人（最好根本不走这一步）→ 若来不及，**主动提前申请延期**，不要等届满后被动逾期 → 准备延期换届申请（理由 + 拟完成时间）→ 与属地确认要求 → 在年报如实体现。
- **延期换届须单独上会审议**，不能默认顺延（见 `templates/07-延期换届报告骨架.md`）。
