# 换届常见坑与易错点（common-pitfalls）

> 开工前先扫一遍。下表按"被登记机关退回频率"排序，前六项占了绝大多数返工。

## 一、被退回频率最高的六项

| # | 漏什么 / 错什么 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | **审计区间写成自然年度**而非届期 | 退回重做，直接吃掉 1–2 个月 | 换届审计与离任审计区间＝本届起算日至届满日 |
| 2 | 只做换届审计，**漏做法定代表人离任审计** | 报送件不全 | 两份审计并行启动、同一机构办理 |
| 3 | 资格审查漏查**现职国家工作人员**与**近亲属** | 选出来的人不合资格，选举结果无效 | 逐人填资格审查表，交叉核验 |
| 4 | 换届会议与新一届第一次会议**合并出一份纪要** | 退回；届次台账从此对不上 | 两次会议、两份纪要、两套签到与选票 |
| 5 | 用**普通决议门槛**（过半数）选理事长/副理事长/秘书长 | 应 2/3 以上，决议可被推翻 | 新一届第一次会议选举办法写明"出席理事 2/3 以上" |
| 6 | 多位监事**只签一份**监事意见 | 补签，且监事监督留痕不完整 | 每位监事逐人签，不可共签一份 |

## 二、其余常见坑

| # | 坑 | 说明 |
|---|---|---|
| 7 | 会前报批材料照抄旧版 | 未对照属地当期《换届指引》；名称/份数/线上填报要求可能已变 |
| 8 | 临到期才找审计机构 | 报告出不来 → 被迫延期换届 |
| 9 | 临到点才发现没人接手 | 只能延期换届；最好提前半年到一年确认候选人 |
| 10 | 候选人酝酿无书面记录 | 报批要交提名与民主协商记录，没有就得补 |
| 11 | 把年度工作报告直接当理事会工作报告交 | 时间跨度对不上——理事会工作报告须覆盖整个届期 |
| 12 | 选票发出数与收回数不等却已计票 | 程序瑕疵，必须核对并记载 |
| 13 | 选举办法门槛与章程不一致 | 选举结果可被质疑 |
| 14 | 兼职秘书长却签了专职承诺 | 不实承诺，年检易被查 |
| 15 | 换届后备案超期 | 属变动未及时备案，年检扣分项 |
| 16 | 变动备案书与理事表信息不一致 | 姓名、职务对不上，退回 |
| 17 | 延期后忘记在年报体现 | 口径不一致被追问 |
| 18 | 延期这一年没有再推进人选 | 一年后同样卡住 |

## 三、通用校验点（不随属地变）

无论北京还是其他地区，以下校验点通用，记入清单逐项打钩：

- [ ] 资格审查项齐全：理事 5–25 人、领酬不超 1/3、负责人年龄、近亲属不得同任、在职公务员不得兼任
- [ ] 审计区间覆盖整个届期（非自然年度）
- [ ] 换届审计 + 离任审计两份俱在
- [ ] 换届会议与新一届第一次会议分成两次、出两份纪要
- [ ] 签字为逐人签，不共签一份
- [ ] 延期换届已单独上会审议（如适用）
- [ ] 监事意见逐人签

## 四、判断纠偏

| 情形 | 归线 |
|---|---|
| 任期届满、整体重选 | 换届线（本 Skill） |
| 届中增补/罢免/辞任个别理事、监事 | 日常会议线（仍须资格审查 + 变动备案） |
| 理事长人选未定需延期 | 换届线 + 单独上会审议延期 |

> 一句话：换届是"整届到期、整体重选"，不是零散的人事变动。
