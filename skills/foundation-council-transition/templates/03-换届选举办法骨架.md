# 模板 03 · 换届选举办法骨架（两份，可填）

> ⚠️ **版本提示（2026-09-29）**：《基金会管理条例》修订草案已于 2026-09-11 经国务院常务会议审议通过，**尚未正式公布施行**。本文依据的仍是现行《基金会管理条例》（国务院令第 400 号，2004 年施行）。修订正式公布后，本文涉及的条款号与数字门槛须逐项重新核对。


> 换届需两份选举办法：一份选理事、监事（换届会议用），一份选理事长/副理事长/秘书长（新一届第一次会议用）。**当选门槛须与章程一致；选负责人的门槛为出席理事 2/3 以上**。

## 一、第 {X} 届理事会换届选举办法（选举理事、监事）

```
第一条  选举对象与名额：本届理事会理事 {N} 名、监事 {M} 名。

第二条  候选人产生：经理事会统筹，经{党组织/发起人/主要捐赠人/会员}民主协商提出，
        候选人名单为理事 { } 人、监事 { } 人（差额/等额）。

第三条  表决方式：无记名投票，一人一票。

第四条  监票计票：由理事会推举监票人 { } 名、计票人 { } 名，候选人不得担任。

第五条  当选门槛：获得出席理事 {过半数 / 三分之二以上} 赞成票者当选（以章程为准）。

第六条  无效票认定：{空白票、多选票、无法辨认票}。

第七条  争议处理：对选举结果有异议的，当场向监票人提出，由理事会裁定并记录。

第八条  本办法经 {YYYY} 年 {MM} 月 {DD} 日理事会表决通过后施行。
```

## 二、第 {X+1} 届理事会第一次会议选举办法（选举理事长、副理事长、秘书长）

```
第一条  选举对象与名额：选举理事长 1 名、副理事长 { } 名、秘书长 1 名。

第二条  候选人产生：由本届理事会（或换届会议推举的筹备组）提名。

第三条  表决方式：无记名投票，一人一票。

第四条  监票计票：由理事会推举监票人 { } 名、计票人 { } 名，候选人不得担任。

第五条  当选门槛：理事长、副理事长、秘书长属特别决议事项，须获得出席理事
        {三分之二以上} 赞成票（依据《基金会管理条例》第二十一条；不得用普通决议门槛）。

第六条  无效票认定：{空白票、多选票、无法辨认票}。

第七条  争议处理：对选举结果有异议的，当场向监票人提出，由理事会裁定并记录。

第八条  本办法经 {YYYY} 年 {MM} 月 {DD} 日新一届第一次会议表决通过后施行。
```

> 易错：办法里的门槛与章程不一致 → 选举结果可被质疑；选负责人用了过半数 → 程序瑕疵。
