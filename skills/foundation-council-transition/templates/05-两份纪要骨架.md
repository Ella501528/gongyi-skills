# 模板 05 · 换届两份纪要骨架（可填，不可合并）

> 换届要出**两份纪要**：纪要一＝换届会议（选理事、监事）；纪要二＝新一届第一次会议（选理事长、副理事长、秘书长）。两份必须分开，各配一套签到与选票。**北京口径**；其他地区正文结构通用，报送环节按属地替换。

## 纪要一 · 换届会议

**{基金会全称}**
**第 {X} 届理事会第 {X} 次会议（换届会议）纪要**

会议时间：{YYYY} 年 {MM} 月 {DD} 日 {hh}:{mm}
会议地点：{地点，写到门牌与房间号}
会议形式：现场会议　　表决形式：无记名投票
主持人：{姓名}　　记录人：{姓名}

### 一、会议出席情况
本届理事会应到理事 {N} 人，实到理事 {M} 人（其中受托 {K} 人），实到人数超过理事总人数的三分之二，符合《章程》规定，本次会议有效。本会监事 {A} 人列席会议。

### 二、审议本届理事会工作报告与财务报告
会议听取并审议了 {姓名} 所作的《第 {X} 届理事会工作报告》和《财务工作报告》，并听取了 {审计机构} 出具的**换届审计报告**与**法定代表人离任审计报告**。经表决，同意 {X} 票，反对 {Y} 票，弃权 {Z} 票，上述报告获得通过。（审计区间须覆盖整个届期）

### 三、通过换届选举办法
会议通过了《第 {X} 届理事会换届选举办法》，确定新一届理事会由 {N} 名理事、{M} 名监事组成，推举 {姓名} 为监票人、{姓名} 为计票人。

### 四、选举新一届理事、监事
经无记名投票，下列人员当选为第 {X+1} 届理事会理事（逐人记赞成/反对/弃权票数）：

| 姓名 | 赞成票 | 反对票 | 弃权票 |
|---|---|---|---|
| {姓名} | | | |
| {姓名} | | | |

下列人员当选为第 {X+1} 届监事：{姓名}、{姓名}。

### 五、决议
一、选举产生第 {X+1} 届理事会理事 {N} 人、监事 {M} 人，任期 {X} 年，自本次会议通过之日起算。
二、责成办事机构于本次会议后 {N} 日内，向登记管理机关报送换届全套材料并办理备案/变更登记。

**理事签字：**

**监事意见：**本次换届会议的召集程序、出席人数、选举与表决方式符合法律法规和本会《章程》规定，选举结果有效。

**监事签字（逐人，不可共签一份）：**

## 纪要二 · 新一届理事会第一次会议

**{基金会全称}**
**第 {X+1} 届理事会第一次会议纪要**

会议时间：{YYYY} 年 {MM} 月 {DD} 日 {hh}:{mm}
会议地点：{地点，写到门牌与房间号}
会议形式：现场会议　　表决形式：无记名投票
主持人：{姓名}（本届理事会推举）　　记录人：{姓名}

### 一、会议出席情况
第 {X+1} 届理事会应到理事 {N} 人，实到理事 {M} 人，实到人数超过理事总人数的三分之二，符合《章程》规定，本次会议有效。新一届监事 {A} 人列席会议。

### 二、选举理事长、副理事长
经无记名投票，{姓名} 当选为理事长（赞成 {X} 票，反对 {Y} 票，弃权 {Z} 票，**达到出席理事三分之二以上**）；{姓名} 当选为副理事长（赞成 {X} 票，反对 {Y} 票，弃权 {Z} 票）。

### 三、聘任秘书长
根据理事长提名，会议决定聘任 {姓名} 为秘书长（赞成 {X} 票，反对 {Y} 票，弃权 {Z} 票）。（秘书长须提交专职承诺书，随会后材料报送）

### 四、决议
一、{姓名} 任第 {X+1} 届理事会理事长，{姓名} 任副理事长，任期 {X} 年。
二、聘任 {姓名} 为秘书长。
三、责成办事机构办理负责人变更备案。

**理事签字：**

**监事意见：**本次会议的召集程序、出席人数、表决方式符合法律法规和本会《章程》规定，各项决议有效。

**监事签字（逐人，不可共签一份）：**

　　　　　　　　　　　　　　　　**{基金会全称}**（盖章）
　　　　　　　　　　　　　　　　{YYYY} 年 {MM} 月 {DD} 日

## 两份纪要的四个易错点

| # | 易错点 | 正确做法 |
|---|---|---|
| 1 | 两份纪要合并成一份 | 必须分开，各配一套签到与选票 |
| 2 | 只写"会议通过"，不写票数 | 换届选举到人，逐人记赞成/反对/弃权 |
| 3 | 漏写审计情况 | 北京口径下两份审计是硬门槛，正文须写明已出具并审议 |
| 4 | 监事只写一个"同意" | 多位监事须逐人签字，不可共签一份 |
