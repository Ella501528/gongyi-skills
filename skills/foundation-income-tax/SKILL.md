# 非营利组织收入税务判定

基金会**不是"不交税"的**，只是**部分收入免税**。本 skill 用于判断「某笔收入要不要交税」。

> ⭐ 核心认知纠正：
> - ❌ "基金会是免税单位，不用管税"
> - ✅ "基金会**特定收入**依 122 号免税；**其他收入照章纳税**；**特定行为另有流转税义务**"

## 铁律

1. **机构中立**：正文写「某基金会 / 本机构」，不出现具体机构名、人名、金额。
2. **逐条引用**：结论落到「财税〔2009〕122 号第 X 条」「企业所得税法第 X 条」等具体条款。
3. **无依据如实说**：拿不准的写「存在不确定性，建议向主管税务机关确认」。
4. **算税 ≠ 办资质**：本 skill 只管「税怎么算、怎么交」，不管「资质怎么申请、怎么保」（那是资质管理的事）。

## 企业所得税三步判断路径（最重要）

```
步骤1：本组织是否持有【免税资格】（财税〔2018〕13 号）且在有效期内？
   ├─ 否 → 全部收入按一般企业处理，照章纳税
   └─ 是 ↓
步骤2：该笔收入是否属财税〔2009〕122 号列举的 5 类免税收入？
   ├─ 是 → 免税（但仍须"分别核算"，否则可能被否）
   └─ 否 ↓
步骤3：是否属《企业所得税法》第七条"不征税收入"（财政拨款等）？
   ├─ 是 → 不征税收入（对应支出不得扣除）
   └─ 否 → 应税收入，照章纳税
```

## 常见收入归类速查（一句话结论）

| 收入 | 归类 | 依据 |
|---|---|---|
| 接受捐赠（现金/实物） | ✅ 免税 | 122 号（一） |
| 政府补助（**无偿**） | ✅ 免税 | 122 号（二）前段 |
| ⭐ 政府购买服务 | ❌ **应税** | 122 号（二）**但书** |
| 会费（省级以上规定） | ✅ 免税 | 122 号（三） |
| 银行存款利息（源于免税/不征税收入） | ✅ 免税 | 122 号（四） |
| **国债利息** | ✅ 免税（**另一依据**） | 企税法第二十六条 + 实施条例第八十二条 |
| ⭐ 理财/基金/股票收益 | ❌ **一般应税** | 不在 122 号（四）内 |
| 出租房产 / 销售商品 / 提供服务 | ❌ 应税 | — |

## 增值税要点

捐赠收入本身不是增值税应税行为（无偿受赠不是"销售"）。但**经营活动**可能触发增值税：

- 销售货物（如义卖）→ 一般视同销售/销售货物
- 提供有偿服务（培训、咨询、场地租借）→ 应税
- 政府购买服务 → 应税
- 保值增值投资 → 视具体品种

> 依据：财税〔2016〕36 号《营业税改征增值税试点实施办法》及附件（部分条款已陆续废止，引用须核现行效力）。

## 何时用本 skill

- "这笔收入/捐赠要不要交税？"
- "政府给的钱要交税吗？"（分财政拨款/无偿补助/购买服务三类）
- "投资收益要不要交税？"（国债免、理财应税）
- "股权捐赠怎么处理？"（会计按公允、票据按历史成本/财产原值）
- 年度税务自查
