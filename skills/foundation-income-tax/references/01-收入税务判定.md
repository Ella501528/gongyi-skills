# 非营利组织收入税务判定细则

## 一、企业所得税判断路径（最重要）

```
步骤1：本组织是否持有【免税资格】（财税〔2018〕13 号）且在有效期内？
   ├─ 否 → 全部收入按一般企业处理，照章纳税
   └─ 是 ↓
步骤2：该笔收入是否属财税〔2009〕122 号列举的 5 类免税收入？
   ├─ 是 → 免税（但仍须"分别核算"，否则可能被否）
   └─ 否 ↓
步骤3：是否属《企业所得税法》第七条"不征税收入"（财政拨款等）？
   ├─ 是 → 不征税收入（对应支出不得扣除）
   └─ 否 → 应税收入，照章纳税
```

## 二、财税〔2009〕122 号五类免税收入

| # | 免税收入 | 关键点 |
|---|---|---|
| （一） | 接受其他单位或个人**捐赠**的收入 | 现金/实物均免 |
| （二） | 除《企业所得税法》第七条规定的财政拨款以外的**政府补助收入**（不含政府购买服务） | ⭐ 政府补助无偿→免；**购买服务→应税** |
| （三） | 按照省级以上民政、财政部门规定收取的**会费** | |
| （四） | 免税收入孳生的**银行存款利息** | ⭐ **只免存款利息**，理财/基金/股票收益应税 |
| （五） | 财政部、税务总局规定的**其他收入** | 兜底条款 |

## 三、常见收入归类速查

| 收入 | 归类 | 依据 |
|---|---|---|
| 接受捐赠（现金/实物） | ✅ 免税 | 122 号（一） |
| 政府补助（**无偿**） | ✅ 免税 | 122 号（二）前段 |
| ⭐ 政府购买服务 | ❌ **应税** | 122 号（二）但书 |
| 承接委托项目（有对价） | ❌ 应税 | 交换交易性质 |
| 会费（省级以上规定） | ✅ 免税 | 122 号（三） |
| 银行存款利息（源于免税/不征税收入） | ✅ 免税 | 122 号（四） |
| **国债利息** | ✅ 免税（另一依据） | 企税法第二十六条 + 实施条例第八十二条 |
| ⭐ 理财/基金/股票收益 | ❌ 一般应税 | 不在 122 号（四）内 |
| 出租房产收入 / 销售商品 / 提供服务 | ❌ 应税 | — |

> **【陷阱】国债利息双重依据易讲混**：国债利息免税的依据**不是** 122 号第一条第（四）项（那项只管"银行存款利息"），而是《企业所得税法》第二十六条第一项 + 实施条例第八十二条。挂错依据会被质疑。

## 四、政府补助 vs 政府购买服务（判据：要否交付对价）

| 情形 | 性质 | 判据 | 税务 |
|---|---|---|---|
| 财政拨款 | 不征税收入 | 列入预算、有拨款文件 | 不征税（对应支出不得扣除） |
| 无偿政府补助 | 补助 | 非交换、无对价交付 | 免税（122 号（二）前段） |
| 政府购买服务 | 购买 | 交换、要交付对价（成果/服务） | **应税** |

一句话：**看合同实质——要不要交付对价（成果/服务）。**

## 五、股权捐赠与投资收益

- **股权捐赠会计 vs 票据**：会计按**公允价值**入账；票据按**历史成本**（企业，财税〔2016〕45 号）/**财产原值**（个人，2019 年 99 号）开具。两侧口径不同，须制度性明确差异处理并在附注披露。
- **投资收益**：国债利息免税（企税法 26 条）；银行存款利息免税（122 号（四））；**理财/基金/股票/信托收益应税**。
- **增值税**：金融商品转让有专门规定；贷款服务利息属应税。

## 六、纳税缴费信用等级（资格失效传导链第一环）

现行依据《纳税缴费信用管理办法》（国家税务总局公告 2025 年第 12 号，2025-07-01 施行），替代旧的《纳税信用管理办法（试行）》（2014 年第 40 号，已全文废止）。

| 级别 | 判定（第十六条） |
|---|---|
| A | 年度评价指标得分 90 分以上 |
| B | 70 分以上不满 90 分 |
| M | 新设立，或 70 分以上但年度内无生产经营业务收入 |
| **C** | 40 分以上不满 70 分 |
| **D** | 不满 40 分，或有严重失信行为 |

⭐ **为什么重要**：C/D 级是「资格失效传导链」第一环——免税资格（财税〔2018〕13 号第六条）、扣除资格（2020 年 27 号）均将「纳税信用等级 C/D」列为取消资格情形；而未依法代扣代缴个税等行为会直接拉低纳税信用得分。**保住 A/B 级 = 保住免税资格 + 扣除资格的前置条件。**

## 七、年度税务自查清单（精简）

1. ☐ 免税资格（牌②）在有效期内？扣除资格（牌③）在最新名单内？
2. ☐ 3 月 31 日前报送经审计的上年度专项信息报告？
3. ☐ 应税收入与免税收入是否**分别核算**？
4. ☐ 政府资金是否区分"财政拨款/无偿补助/购买服务"？
5. ☐ 投资收益是否按免税/应税分类（国债 vs 理财）？
6. ☐ 增值税：是否有销售/服务/租赁行为？纳税人身份是否明确？
7. ☐ 个税代扣代缴是否完整（含劳务报酬、讲课费）？
