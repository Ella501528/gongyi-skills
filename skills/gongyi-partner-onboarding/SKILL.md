# 慈善组织合作方准入与协议

合作方的问题，多半不是"选错了人"，而是**选的时候没核、用的时候没写清、用完了没对账**。本技能把合作方从准入到评估做成可查的四步：**核资质 → 定角色 → 签协议 → 定期对账**。

> 先分清两个词：**关联方**（与机构存在关联关系的特定人，如理事及其控制的企业）与**相关方**（与机构有往来的各方，含合作方）。合作方属**相关方**；若某合作方**同时**具备关联关系，还须按关联交易程序另行处理。

## 什么时候会用到它

| 时机 | 你要做的事 |
|---|---|
| 确定合作前 | 用第一节核主体资格与资质，判角色边界 |
| 起草协议时 | 用第二节对齐协议四要素 |
| 合作过程中 | 用第三节定期对账，第四节管联合宣传口径 |
| 涉关联关系时 | 用第五节判断是否需转关联交易程序 |
| 年度或阶段结束时 | 用第六节做合作方评估与续约结论 |
| 检查、评估前 | 把合作方台账交给 `scripts/check_partner.py` 跑一遍 |

## 一、准入：核主体资格与资质，定角色边界

**核什么**：
- 主体资格：依法设立、存续状态正常；
- 专业资质：若合作方承担需要资质的业务（服务、施工、医疗、培训等），须核相应资质；
- 履约能力与信用：必要时查公开的信用与处罚信息。

**角色边界（硬要求）**：**商业公司不作为受益方或受资助方**，只可作为**供应商、服务提供方或联合宣传方**。若出现"资助某公司"，无论名义如何，都应重新审视合作性质。

| 角色 | 含义 | 资金流向 |
|---|---|---|
| 供应商 | 提供货物 | 机构付款给对方 |
| 服务提供方 | 提供服务 | 机构付款给对方 |
| 联合宣传方 | 共同宣传，各自出资源 | 一般不涉及机构出资 |
| 受资助方 | 接受机构资助 | **不得为商业公司** |

## 二、协议：四要素

书面协议应写清以下四项，缺一即为要素不全：

1. **权责**——各方做什么、不做什么、谁签字负责；
2. **资金走向**——金额、支付条件与节点、票据要求；
3. **成果归属**——合作产生的成果、资料、知识产权归谁，如何使用；
4. **宣传口径**——双方名称与标识如何出现、不得如何使用。

> 涉及**合作募捐**的，另按「合作募捐合规与对账」处理（评估、协议、载明、监督，款物全部纳入本机构账户）。

## 三、对账：定期做，留记录

- **资金类**：按协议节点对账，收付款与票据一致；
- **物资/服务类**：数量、单价、交付与验收一致；
- **对账留痕**：对账表、确认记录（谁核的、什么时候）。

## 四、联合宣传：口径先确认

- 使用机构名称、标识、项目信息**须经机构确认**；
- **不得超出确认范围**使用（如把机构列为"赞助单位""合作方"而未经同意）；
- 宣传物料发布**前**送机构确认，而不是发布后再改。

## 五、涉关联关系：转程序

若合作方是机构发起人、理事、管理人员及其近亲属，或由其控制的企业，**属关联方**，应按**关联交易程序**处理（回避、审查、披露），不能仅按普通合作方处理。

## 六、评估与续约

阶段结束（项目结束、年度）应做合作方评估，形成**结论**：续约 / 有条件续约 / 不续约。评估维度：履约质量、对账情况、宣传合规、风险事件。

## 七、脚本用法

```bash
python scripts/check_partner.py --input sample_data/sample_input.json --out ./合作方体检报告.xlsx
```

- **输入**：一份 JSON，合作方清单（`partners`），结构见 `sample_data/sample_input.json`。
- **输出**：Excel 四表——**汇总 / 合作方明细 / 异常清单 / 待补材料**；无 openpyxl 时降级 CSV。

## 八、判定口径（八条）

| 编号 | 判什么 | 严重度 |
|---|---|---|
| P1 | 未做主体资格或资质核验 | 高 |
| P2 | 商业公司作为受益方或受资助方 | 高 |
| P3 | 未签书面协议 | 高 |
| P4 | 协议要素缺失（权责／资金走向／成果归属／宣传口径） | 中 |
| P5 | 未定期对账 | 中 |
| P6 | 涉关联关系未按关联交易程序处理 | 高 |
| P7 | 联合宣传口径未确认或超范围 | 中 |
| P8 | 未做合作方评估或无评估结论 | 低 |

规则编号与 `references/判定规则索引.md` 一一对应。

## 九、边界与降级（必读）

1. **命中项是待核项，不是违规结论**。如"资质未核"可能是尚未补录，须核实。
2. **含真实机构与个人信息时**：脚本只读输入、不联网；报告对**人名**打码，机构名不主动外泄。
3. **缺关键字段时不猜**：无角色、无协议要素清单时，相关规则报"无法判定"。
4. **本技能不判合作募捐的专门合规**——那属「合作募捐合规与对账」。
5. **本技能不替代法律意见**：涉及重大合作、复杂股权与控制关系的，应请专业律师判断。

## 十、什么时候不该用本技能

- 合作**募捐**（公开募捐的合作安排）→ 用「合作募捐合规与对账」。
- 志愿者（招收、记录、保险）→ 属志愿者主题。
- 关联方的识别与交易审查 → 属关联方专题，不在本技能。
