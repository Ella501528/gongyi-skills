# 慈善组织术语速查

按词条查阅的术语工具。不按顺序读，**用一个词查一个词**。

## 什么时候会用到它

| 时机 | 你要做的事 |
|---|---|
| 写材料时拿不准某个词能不能用 | 查这个词，看它是法律术语、政策统称还是口语词 |
| 两个词分不清（公募／非公募、变更登记／备案……） | 查任一个，会自动带出对比表 |
| 看到别人用了一个不熟悉的说法 | 查它，确认是老词、口语，还是新规 |
| 老同事说的词跟文件里不一样 | 查老词，会指向对应的现行说法 |
| 回复捐赠人或同行的提问 | 查完照解释答，不要凭印象 |

## 怎么用

```bash
# 查一个词
python scripts/lookup_term.py --q 公募

# 连完整解释一起输出（默认只给前 180 字）
python scripts/lookup_term.py --q 民非 --full

# 列出某一类的全部词条
python scripts/lookup_term.py --cat 治理

# 列出九类与全部词条名
python scripts/lookup_term.py --list

# 供程序调用
python scripts/lookup_term.py --q 公募 --json
```

**输出分三块，按需要看**：

1. **直接命中的词条** —— 词条名就是你要查的，给完整解释；
2. **在别的词条里被提到** —— 该词出现在其他词条的解释里，列出来供延伸；
3. **容易混，务必对照** —— 该词属于六组易混对比之一时自动附上对比表。

## 这个词典的读法（先知道一件事）

行业的词一直在变：「民非」变「社会服务机构」、「年检」分出「年报」、公募／非公募的叫法在基金会和社团之间不一样。所以碰到一个没见过的说法，**先判断它是老词、口语，还是新规**——这三种处理方式完全不同。

**凡是带「资格」两个字的，都要单独确认：是不是必须具备、怎么申请、有效期多久。**

## 词条的两类标注

| 标注 | 含义 |
|---|---|
| （法律上有明确定义） | 这个词在法规里有明确界定，写材料时按法定含义用 |
| （统称） | 政策文件里的统称，不是法律定义 |
| （属性，要认定） | 不是登记时选的，需要另外申请认定 |
| （口语词）（老词，仍在用） | 日常能用，正式材料里要换成对应的规范说法 |
| （非法定角色） | 机构自己的叫法，法规里没有这个名称 |

## 边界与降级（必读）

- **词典只收录 94 条**，没查到时**不要据此推断词义**。脚本会给近似建议，那只是按字面相近列出来的，不是解释。
- **词典是"怎么用词"的工具，不是法规检索工具**。词条里出现的时限、比例、资格条件，如果要用在正式材料里，**须回发布机关官网核对现行原文**。
- 词条解释是**通用口径**。地方可能有单独规定（如地方性法规对某些事项另有口径），具体办事以属地要求为准。
- 本工具**不替代法规原文**，也**不构成法律意见**。涉及具体权利义务判断时，以现行法规与主管机关口径为准。
- 数据文件缺失时脚本会直接报错退出，不会给空结果——看到报错先查 `data/` 下两个 JSON 是否完整。
