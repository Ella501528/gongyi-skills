# 公益慈善常用术语词典（全文）

> 九类 · 94 条 · 附六组「容易混」对比。按词条查阅，不按顺序读。


## 公益与慈善

### 公益

指涉及公共利益的事。范围宽。法律上没有一个统一的"公益"定义，它更多是日常词和政策词。说"我在做公益"，没人会纠正你。

实务上判断"公益性"通常看两点：①公共性——受益人群是公众，而不是跟机构有特殊利害关系的人（不是捐赠人、近亲属、本公司职员、会员这类特定群体）；②有益性——项目实施后对受益人群产生有益的结果，且不产生有害的、或既无益也无害的结果。

### 慈善（法律上有明确定义）

《慈善法》第三条把"慈善活动"定义为：自然人、法人和非法人组织以捐赠财产或者提供服务等方式，自愿开展的下列公益活动——共六类：

① 扶贫、济困；

② 扶老、救孤、恤病、助残、优抚；

③ 救助自然灾害、事故灾难和公共卫生事件等突发事件造成的损害；

④ 促进教育、科学、文化、卫生、体育等事业的发展；

⑤ 防治污染和其他公害，保护和改善生态环境；

⑥ 符合本法规定的其他公益活动。

两点要留意：一是慈善活动的主体不限于慈善组织——自然人、法人和非法人组织都可以开展（"人人可慈善"）；二是方式主要是"有钱出钱、有力出力"两种：捐赠财产、提供服务。

### 公益和慈善的区别

《慈善法》用的是"大慈善"概念——把传统意义上的公益事业基本都纳进了慈善范畴，所以两者在范围上高度重叠。但不是所有"公益"都是"慈善"：

· 慈善活动：受《慈善法》规范，需要具备慈善组织资格，或与具有公开募捐资格的慈善组织合作开展；

· 一般公益活动：比如社区志愿服务、环保公益宣传，不一定受《慈善法》直接规范，可能受其他法律法规调整。

一句话：慈善是公益里被法律明确划出来的那一块。

### 公益组织 / 公益机构（口语词）

不是法律术语，没有定义。泛指做公益的各类主体，不严格区分类型。日常说"公益组织""公益机构""公益圈"，都没问题。但正式材料里要对应到具体的词——"社会组织"或"慈善组织"。这也是为什么很多人觉得"公益组织"和"慈善组织"是一回事：口语里确实是一回事，文件里不是。

### 社会组织（统称）

政策文件里的统称，指在各级民政部门依法登记的社会团体、社会服务机构（民办非企业单位）、基金会这三类，都是为公益目的或者其他非营利目的成立、不向出资人／设立人／会员分配所得利润的非营利法人。它是"统称"，不是法律定义。2006 年党的十六届六中全会开始使用这个词。

### 慈善组织（属性，要认定）

依法成立、符合《慈善法》规定、以面向社会开展慈善活动为宗旨的非营利性组织。

关键：它不是第四种组织形式，而是一种"属性"。准确的表述是——《慈善法》第八条："慈善组织可以采取基金会、社会团体、社会服务机构等组织形式"。也就是说，上面三类组织，符合条件的都可以申请认定为慈善组织；同一家机构，组织形式是"基金会"（登记证书上写的），属性上"是慈善组织"（认定来的）。

### 非营利性（最容易误解的一个词）

"非营利"不等于"不能赚钱"。准确的说法是——可以赚钱，但不能分钱。

· 可以有收入：捐赠收入、会费、提供服务收入、政府补助、投资收益、符合规定的经营活动收入……这些都可以有；

· 但盈余不能分配：所有收入必须全部纳入本组织法定账簿核算；组织的资产归法人所有，不得向出资人、设立人、举办者、负责人、理事、监事、捐赠人等分配或变相分配；

· 钱只能用于章程规定的业务范围和公益目的；出资属于捐赠，不能抽回；终止时清偿债务后的剩余财产也不得向出资人分配，应按规定用于公益，或转给宗旨相同、相近的组织；

· 可以有薪酬，但那不是分红——给专职人员发合理工资，跟按出资额分利润是两回事；反过来，兼职理事、监事履行职责时，也不得以劳务费、专家费等方式领取报酬。

两句话记住：①"不以营利为目的"约束的是利润分配，不是收入本身；②钱一旦进了机构账户，就是社会公共财产，由机构管着花，但不能分给任何人。

### 非营利法人 / 捐助法人

《民法典》里的分类：为公益目的或者其他非营利目的成立、不向出资人、设立人或者会员分配所取得利润的法人，叫非营利法人，包括事业单位、社会团体、基金会、社会服务机构等。

其中基金会和社会服务机构属于捐助法人（以捐赠财产为基础设立，没有会员）。这个分类决定了很多事：比如"没有股东、不分配利润"是从法人性质上就定死的。


## 主体与登记

### 社会团体

中国公民自愿组成、为实现会员共同意愿、按照其章程开展活动的非营利性社会组织。

关键词是"会员"：有会员（代表）大会、有会费、有会员名册、要换届选举，还要管会员事务。协会、学会、商会、研究会、促进会、联合会、校友会都是。

登记依据：《社会团体登记管理条例》。注意：社会团体中有一类专属性较强的——行业协会商会，它是"会员主体为同行业经济组织、同业人员、同地域经济组织"的社会团体，实行行业服务与自律管理，且正在推进与行政机关"脱钩"。

### 基金会

利用自然人、法人或者其他组织捐赠的财产，以从事公益事业为目的的非营利性法人。没有会员，围绕募集资金开展公益。名称一般以"基金会"结尾。登记依据：《基金会管理条例》。

### 社会服务机构（登记证书上写：民办非企业单位）

企业事业单位、社会团体和其他社会力量以及公民个人，利用非国有资产举办、从事非营利性社会服务活动的社会组织。常见形态：民办学校、幼儿园、民办医院、诊所、养老机构、社工服务中心、民办博物馆、民办科研院所、职业培训中心等。登记依据：《民办非企业单位登记管理暂行条例》。

两个名字的关系："社会服务机构"是现在政策文件里用的名，"民办非企业单位"（俗称"民非"）是登记条例和登记证书上的名，指的是同一类机构——所以官方文件常并列写成"社会服务机构（民办非企业单位）"。

写材料、写文章：两个都写最稳妥；填表、核证照：以证件上写的"民办非企业单位"为准，不要自己按新名去改证照上的字。

### 登记事项

写进登记证书、必须登记的那几项：名称、住所、类型、宗旨、公益活动的业务范围、原始基金数额（或开办资金）、法定代表人。这几项叫"登记事项"——它们变了，要办"变更登记"。

### 变更登记

登记事项发生变化时，向登记管理机关申请变更登记。因为这些东西是印在法人登记证书上的，所以变更后要换领新的证书。

常见需要变更登记的情形：改了名称、搬了办公地址（住所）、调整了业务范围、换了法定代表人（一般即理事长）、变更了原始基金数额、变更了类型。

涉及这些的，一般要经理事会决议、有业务主管单位的先经其同意，再报登记管理机关审批并换证。另外：换届和更换法定代表人之前，应当先做财务审计。

注意它和"备案"不是一回事——见第八类对比。

### 认定

已经登记的组织，向民政部门申请确认为慈善组织的过程。区别于"登记"——登记是取得法人身份，认定是取得慈善组织属性。

要申请、要审核、要换证，没有"自动归入"这回事。两条路：①还没取得法人资格的组织，法人登记和慈善组织属性认定合并审查；②已经取得法人资格的，向登记的民政部门申请认定，换发标有"慈善组织"字样的登记证书。有业务主管单位的，还要先经其同意。

### 登记管理机关

就是县级以上人民政府民政部门。证是它发的，年报／年检是报给它，变更登记也是找它。国务院民政部门和省、自治区、直辖市人民政府民政部门是基金会的登记管理机关（分层负责）。

### 业务主管单位

部分组织登记前需要先经其审查同意的行业主管部门（例如某基金会由某部委主管）。

改革后很多类型已不再需要，改为直接登记。你的机构到底有没有，以登记证书登记时的实际情况为准——这件事直接影响年检／年报的时间点（有主管单位的要 3 月 31 日前先报它初审）。

### 双重管理

指"业务主管单位 + 登记管理机关"两头管的体制。有的机构有业务主管单位，有的没有（直接登记、已脱钩的就没有）。

它解释了为什么有些流程有两个时间节点（先报前者初审，再报后者）。改革方向是简化前置审批、强化事后监管。

### 直接登记

不需要业务主管单位前置审查，直接向民政部门登记。曾对行业协会商会、科技类、公益慈善类、城乡社区服务类四类探索实行，后续政策要求稳妥审慎，部分地区暂停。具体能不能直接登记，问当地民政部门最准。

### 法定代表人

代表机构对外行使权利的负责人。基金会里必须由理事长担任，且不得同时担任其他组织的法定代表人。

国籍有讲究：公募基金会，以及原始基金来自中国内地的非公募基金会，法定代表人应当由内地居民担任；其他情形可由港澳台居民或外国人担任，但每年在中国内地居留时间不得少于 3 个月。

社会服务机构的法定代表人一般由理事长或执行机构负责人担任。

### 负责人（有特定含义）

不是"所有领导"。在民政登记口径里，基金会的负责人就是三个人：理事长、副理事长、秘书长。这三个人都是登记备案事项。

"执行秘书长""副秘书长""部门总监"都不在这个名单里——登记材料、年报、公开信息里，负责人只写那三位。

### 章程

机构的"根本大法"。宗旨、业务范围、治理结构、负责人产生方式、财产处理规则都写在里面。

三件事先看章程：①很多内部规定能不能立，先看章程有没有授权；②申请慈善组织认定，章程里必须有"剩余财产转给宗旨相同或相近慈善组织"的条款；③副理事长设几个、分管什么，由章程定。

修改章程要经理事会（社团会员大会）决议，有业务主管单位的先经其同意，再报登记管理机关核准。


## 治理

### 理事会

决策机构。章程谁定、负责人谁选、预算谁批、重大事项谁点头，都在这。

人数：基金会 5–25 人；社会服务机构理事人数一般为 3 至 25 人。法规里没有"必须是单数"的硬规定，但实务中多数机构会取单数——因为表决时能减少票数对等的僵局。

开会规则：每年至少 2 次；须有 2/3 以上理事出席才能开；一般决议出席理事过半数通过；重大事项（章程修改、选举罢免负责人、重大募捐投资、分立合并）须出席理事 2/3 以上通过。

表决方式：一人一票；民主选举、民主决策，理事长（会长）末位表态，对不同意见应予记录。

通知与记录：一般会议提前 5 日、决议重要事项提前不少于 7 日书面通知（章程示范文本口径，各地要求可能不同）；会议记录由出席理事审阅、签名，反对意见应记入记录。

一条容易忽略的：机构的人、财、物、活动中按规定由会员大会（如有）或理事会决策的事项，不得由个人专断，也不得用"理事长办公会"之类的形式代为决策。

### 理事（角色）

理事会的组成人员。要做六件事：

①到会——出席理事会，这是最基本的履职；长期不到会本身就是问题。

②表决——一人一票，对议题投出自己的一票。

③审议与签字——审阅会议记录、年度工作报告与财务报告，签字确认。

④担责——决议违反法律法规或章程、给机构造成损失的，参与决策的理事要承担相应赔偿责任；但在表决时明确反对、并记载于会议记录的，可以免责。

⑤提供资源——不是强制，但实务中理事往往带来捐赠、社会资源链接、渠道，这也是机构请他们来的原因之一。

⑥提思路、提建议——对机构方向、项目规划、发展路径提意见。

任期：每届不超过 5 年，可连选连任。

限制：遇有个人利益与机构利益关联时，不得参与相关事宜的决策；理事、监事及其近亲属不得与本机构有任何交易行为。

### 领酬理事

从机构领取报酬的理事。不得超过理事总数的三分之一；未在本机构担任专职工作的理事，不得获取报酬。

这条的用意是：如果大多数理事都从机构领工资，理事会就变成"给自己定薪的会"。

### 理事的近亲属限制

这条很少被提到，但安排理事人选时第一个要查：

机构类型规则

用私人财产设立的非公募基金会相互间有近亲属关系的理事，总数不得超过理事总数的 1/3
其他基金会（公募、以及非私产设立的非公募）具有近亲属关系的，不得同时在理事会任职

### 理事长

就是基金会的法定代表人——召集和主持理事会，代表机构对外签署重要文件、参加重大活动，以法定代表人身份对机构整体行为负责。（这是条例明文，不是惯例。）

资格要求：不得同时担任其他组织的法定代表人；最高任职年龄一般不超过 70 周岁；不得由现职国家工作人员兼任；公募基金会及原始基金来自内地的非公募基金会，法定代表人应当由内地居民担任。

内部有矛盾时，理事长要充分协调各方、及时组织召开会议推动达成一致；本人不能正常履职的，可按章程规定的程序推举一位负责人召集会议。

### 四种人不能担任负责人

理事长／副理事长／秘书长，有下列情形之一的不能担任：

· 属于现职国家工作人员的（行政机关工作人员一律不得担任）

· 因犯罪被判处管制、拘役或者有期徒刑，刑期执行完毕之日起未逾 5 年的

· 因犯罪被判处剥夺政治权利正在执行期间，或曾经被判处剥夺政治权利的

· 曾在因违法被撤销登记的基金会担任理事长／副理事长／秘书长，且对该基金会的违法行为负有个人责任，自该基金会被撤销之日起未逾 5 年的

### 副理事长

负责人之一，应当设置。协助理事长工作，按章程分工分管某一方面；理事长缺位时，按章程规定代行其职责。

设几名、分管什么，由章程决定，一般 1–2 名。有些地方（如北京）在登记时明确要求有副理事长，以便三个负责人齐全。

兼任方面：法规明文禁止的是"理事长与秘书长不得由同一人兼任"（决策与执行要分开）；法规没有禁止副理事长兼任秘书长，实务中确实有机构是这样安排的。

### 秘书长

执行机构（秘书处）负责人，负责人之一。全面主持秘书处日常工作、落实理事会决议，制定年度工作计划与预算方案并定期向理事会汇报，管理团队、对接民政部门、统筹筹资与合规。

必须专职。两个依据：①《基金会章程示范文本》第二十三条（二）把"秘书长为专职"写进负责人的条件，登记机关核准章程时按此把关，实务中通常还要签专职承诺书；②具有公开募捐资格的慈善组织，秘书长专职是申请公开募捐资格的必备条件（《慈善组织公开募捐管理办法》）。

不得兼任理事长；不得由现职国家工作人员兼任；最高任职年龄一般不超过 70 周岁。

### 执行秘书长（非法定角色）

部分机构自设的岗位，法规里没有这个名称。出现的两种情形：

①秘书长是挂名的——实际工作几乎全由执行秘书长做；秘书长的角色主要在签字、承担责任、对外报备这些"名义上的动作"。

②机构大了、或秘书长偏对外（管大局、引资源、代表机构露面）——执行秘书长承担日常运营的一块或全部。

可以类比企业的 董事长／CEO 与执行 CEO、或者 CEO 与 COO：一个定方向、一个保运转。

使用注意：登记材料、年报、公开信息里负责人只能写理事长三人，不能填这个岗；内部可以设，但职权要写进章程或内部制度，否则出了争议没有依据。

### 副秘书长（非法定角色）

机构自设的岗位，法规里没有这个名称。

多数情况分管一块——比如分管项目、传播或行政某一条线，是部门之上的一个层级；少数情况承担实际上的日常管理（当秘书长和执行秘书长都偏对外时，日常那块可能落到副秘书长身上）。

和执行秘书长的关系：层级上，执行秘书长一般略高于副秘书长——因为执行秘书长通常管全局或接近全局，副秘书长多数是分管一块。这是常规情形，具体以各机构自己的设置为准。

### 监事 / 监事会

监督机构，独立于理事会和秘书处（它不是决策机构）。三者关系是：理事会决策、秘书处执行、监事（会）监督。

怎么设：

· 监事——规模小的机构可以不设监事会，只设监事，至少 1–2 名；

· 监事会——有 3 名以上监事的，应当设监事会，人数 3 至 7 人、取单数，具体由章程定。

两条硬要求：具有公开募捐资格的慈善组织，应当设立监事会；在省级以上民政部门登记的基金会，也应当设监事会。

不得兼任监事的人：理事、理事的近亲属、执行机构负责人（秘书长）、财会人员，以及上述人员的近亲属。另有一条更硬、更容易被忽略的：理事、监事及其近亲属，不得与其所在的基金会有任何交易行为。

监事不领取报酬——而且这条比"不领工资"更宽：以劳务费、专家费、咨询费等任何名义领取，都不行。

任期与理事相同，届满可以连任；监事之间不得有近亲属关系。

### 监事长

设监事会才有，1 名，由监事会选举产生和罢免（全体监事过半数通过）。

职责：召集并主持监事会会议；决定是否召开临时监事会；检查监事会决议的实施情况并向监事会报告；代表监事会向理事会、主要捐赠人或公众发布监事会年度工作报告；签署监事会的决议和建议。

### 监事会怎么开会

事项规则

开会频次每年至少召开 2 次
出席人数须有 三分之二以上监事出席方可召开
表决一人一票；决议须经全体监事过半数通过才有效
谁来召集主持监事长
记录制作会议记录；形成决议的当场制作会议纪要，出席监事签名确认；监事的反对意见应当记入记录
留档监督检查记录、会议记录、会议纪要要妥善保管、留档保存

### 监事能做什么

职权比很多人以为的要宽：

· 按章程规定的程序检查财务和会计资料，每年至少 2 次检查财务情况；

· 监督理事会遵守法律法规和章程的情况；

· 监督负责人、理事、财务管理人员的职务行为；

· 列席理事会会议，监督会议程序和决议的合法性，有权向理事会提出质询和建议；

· 对违反法律法规、章程或理事会决议的负责人，提出罢免的建议；

· 当负责人的行为损害机构利益时，要求其纠正；

· 提议召开临时理事会会议；理事会不履行召集职责时，可召集并主持；

· 监督理事会履行信息公开责任；

· 向登记管理机关、业务主管单位以及税务、会计主管部门反映情况；

· 对公益项目实施情况可以实行全程监督。

提意见的三种正式方式：①当场质询（列席理事会时提出，须记入会议记录）；②书面意见（提交理事会；年报里的"监事意见"就是正式的书面出口）；③直接反映（向登记管理机关、业务主管单位、税务或会计主管部门反映）。

应具备什么：财务、会计、审计、法律等方面的专业知识和工作经验，或有保护机构资产安全与相关者利益的能力。

### 现职国家工作人员

在任的国家机关工作人员。不得兼任慈善组织的理事长、副理事长、秘书长。

范围一般包括：党的机关、人大机关、政府机关、政协机关、审判机关和检察机关中的现职工作人员；法律法规授权行使行政管理职能的其他机构的工作人员。

### 任职回避

与本人或近亲属有利害关系的事项，本人应当回避，不参与讨论和表决。常见于关联交易、采购、人事任免。

不限于理事：负责人、理事、监事、主要捐赠人等，与机构交易对象存在控制关系或能够施加重大影响的，应当主动报告并按规定回避表决，相关交易情况应依法如实披露。

### 换届

理事、监事、负责人任期到期后重新产生。要开会、形成决议、办变更登记或备案。

最常出问题的环节：任期已过但没换届。超龄超届任职是年检年报的关注点之一。

### 重大事项报告

除依法需要行政审批和备案的事项之外，可能对机构自身、会员、服务对象及社会公众产生较大影响、应当主动报告的重要事项。各地一般都有专门的办法，通常分五类：

类别包含

形成重要决定召开换届会议或延期换届；届中调整主要负责人（会长、理事长）、秘书长；设立分支（代表）机构；调整会费标准（社会团体）
举办重要活动面向社会公开举办的节庆、论坛、研讨会、展会、比赛等活动；经批准的评比达标表彰、创建示范活动；设立、转让或注销经济实体；接受使用重大捐赠及资助；重大项目合作
开展涉外交往与境外组织合作或联合举办活动；出国出境访问；参加国际会议、加入国际组织；接受或向境外捐赠；涉港澳台活动同样归这一类
发生重大事件安全事故造成人员伤亡或财产损失；产生负面舆情或造成社会负面影响；内部矛盾、外部纠纷或诉讼导致工作不能正常开展
涉及违法违规违反法律法规受到行政处罚；负责人涉及犯罪

时限通常分三类：①涉及换届、重要活动、涉外交往的，提前报告（多地要求提前 30 日，也有 15 日、10 日的；行业协会商会负责人调整有的要求提前 2 个月）；②发生安全事故、负面舆情等突发事件的，即时报告；③受行政处罚等情形，一般事后 15 日内报告。具体按本机构登记的民政部门的办法执行。

### 专项基金

基金会内部为特定用途设立的专项，多以某个捐赠人的意愿为起点，但不具备独立法人资格——它是以基金会的名义挂牌运作的资金专项。

几条不能碰的红线：

· 对外用名必须用"基金会全称 + 专项基金名称"，不能以独立组织名义对外活动；

· 不得单独开设银行账户、不得单独刻章；收支全部纳入基金会母体账户统一核算与管理；

· 不得以独立组织名义对外募捐、签协议；

· 不得再下设分支机构；

· 专项基金开展活动产生的法律责任，由设立它的基金会承担。

现状：民政部门对专项基金的要求越来越细，很多机构对新设专项基金持审慎态度、部分暂缓。

### 分支机构 / 代表机构

分支机构＝依据业务范围或财产划分、专门从事某项业务的机构（基金会的专项基金管理委员会、社会团体的专业委员会／分会都属于这一类）。

代表机构＝在住所地以外、属活动区域内设立，代表本机构开展活动、承办交办事项的机构（如代表处、办事处、联络处）。

共同点：都没有独立法人资格。不得单独开户、不得单独刻章、不得以独立组织名义募捐或签协议，且不得再下设分支机构；对外用名要冠母体全称；开展活动产生的法律责任由母体承担。

两条特别规定：①社会团体不得设地域性分支机构、分支机构不得再设分支机构；②社会服务机构不得设立分支机构。

管理动作：设立、变更、终止要有理事会决议并备案；建立分支（代表）机构台账（名称、负责人、授权范围、活动区域）；统一管理其用名、用章、宣传口径；收取半年或年度工作总结并归档。注意：社会团体、基金会设分支（代表）机构已取消行政审批，改为理事会决定 + 备案／自律管理，但"审慎决策"的要求反而更强调了。


## 募捐

### 公开募捐

面向社会公众募集财产。必须取得公开募捐资格，且募捐方案要报民政部门备案；开展时要在现场或载体的显著位置公布组织名称、资格证书、募捐方案、联系方式、募捐信息查询方法。

### 定向募捐

面向特定对象募集财产。不需要公开募捐资格，但也不得超出特定对象的范围。两者的分界线就是"对象是不是社会公众"。

### 公开募捐资格

开展公开募捐的前置资格，由民政部门发给资格证书。

申请条件：依法登记满一年（2023 年修正后；原为两年）的慈善组织，可以向办理其登记的民政部门申请；民政部门自受理之日起 20 日内作出决定；符合条件的发给资格证书，不符合的要书面说明理由。

两个实务要点：①"内部治理结构健全、运作规范"是实质条件，所以申请前先把治理做扎实；②对具有公开募捐资格的慈善组织，秘书长专职是必备条件之一。

没有这个资格，就不能自己公开募捐。

### 公募基金会 / 非公募基金会

指基金会按有没有公开募捐资格分的两类。这两个词至今都在用——《基金会管理条例》和《慈善法》里都直接写，日常人家问"你们是公募还是非公募"，问的就是这个。

不是"不叫了"，而是：说基金会时可以用这个老叫法；换成社会团体、社会服务机构，同样的意思得说成"具有／不具有公开募捐资格"。

### 募捐方案备案

开展公开募捐前，要把募捐方案报登记的民政部门备案。方案里要写清：募捐目的、起止时间和地域、活动负责人姓名和办公地址、接受捐赠方式、银行账户、受益人、募得款物用途、募捐成本、剩余财产的处理。

注意"募捐成本"是方案里必须写的一项——这和 2026 年新规把募捐成本单列出来定标准，是配套的。

### 一号一源

通过统一信息平台（慈善中国）开展公开募捐，会获得可追溯、可识别查询的募捐备案编号。"一号一源"指的就是：每一笔募捐活动对应一个编号、一个可追溯的来源。

### 互联网公开募捐服务平台

由民政部指定、可以开展互联网公开募捐的平台。慈善组织通过互联网开展公开募捐，应当在民政部指定的平台进行，也可以同时在机构自己的网站进行。

数量：民政部先后公开遴选并指定，目前共 20 家左右（名单会调整，以民政部最新公告为准）。常见的如腾讯公益、支付宝公益等，各家平台的募捐项目、规则和运营节奏都不一样。

对平台的硬约束（写进《慈善法》的）：

· 无正当理由不得拒绝为具有公开募捐资格的慈善组织提供服务；

· 不得向慈善组织收费；

· 不得在公开募捐信息页面插入商业广告和商业活动链接；

· 平台要提供公开募捐信息展示、捐赠支付、捐赠财产使用情况查询等服务。

对机构的实务要求：不是"发个链接"那么简单——涉及上线资质审核、文案规范、进展更新的频率、财务批复、结项、审计。各家平台的年度活动（比如某些平台一年一次的大型活动）规则很细，不少机构会专门安排人研究平台规则。

### 合作募捐

没有公开募捐资格的组织或个人，基于慈善目的，与有资格的慈善组织合作，由对方开展公开募捐。

四条要点：①合作方不得以任何形式自行开展公开募捐；②具有资格的慈善组织应当对合作方进行评估；③依法签订书面协议；④在募捐方案中载明合作方的相关信息，并对合作方的行为进行指导和监督。

款物归属：合作募得的款物由具有公开募捐资格的那一方统一管理和会计核算，全部收支纳入其账户。

### 慈善信托

以慈善为目的设立的信托。慈善信托即公益信托，要向办理其备案的民政部门备案。

受托人确定受益人，应当坚持公开、公平、公正的原则，不得指定或者变相指定受托人及其工作人员的利害关系人作为受益人；委托人也不得指定或变相指定其利害关系人作为受益人。

和基金会的区别：信托不是法人，是"财产安排"；可以由信托公司或慈善组织担任受托人。


## 财税与会计

### 非营利组织免税资格（常简称"免税资格"）

税务部门认定的资格，有了它，规定范围的收入可以免企业所得税。八项条件要同时满足，其中一条是"工作人员平均工资薪金水平不得超过当地同行业同类组织平均工资水平的两倍"。

有效期五年，到期要复审。申请要向所在地的税务主管机关提出（按登记层级分别报省级／地市级／县级）。取得免税资格后仍要按期进行纳税申报。

### 公益性捐赠税前扣除资格

企业或个人向具有这个资格的组织捐赠，可以在计算所得税时按规定的比例扣除。

两个容易混的点：①企业和机构的资格不是一回事——捐赠人自己有税前扣除的权利，受赠方要有"公益性捐赠税前扣除资格"，两者要分别确认；②评估等级有关联——一般要求 3A 以上评估等级（部分地方对民办非企业单位有不同规定）。

### 公益事业捐赠票据

接受捐赠时开给捐赠人的法定凭证，捐赠人凭它税前扣除。开错、漏开、作废不规范，是检查高频问题。

出纳或会计常做的几件事：申领、开具、保管、核销；实物捐赠要有计价依据；没有公允价值证明的，按规定不得开具票据。

### 限定性收入 / 非限定性收入

捐赠人指定了用途或时间的，叫限定性（只能照指定的用）；没指定的叫非限定性。

做账和做预算时要分开看——非限定性资金才是机构真正能动的钱。期末要把限定性收入和非限定性收入分别结转到净资产项下的对应科目。

### 净资产

相当于是民间非营利组织会计里的"家底"——资产减去负债后的余额。它按有没有限制分成两类：

类型意思

限定性净资产资产提供者设了限制的：要求在规定时间之内或之后使用，或要求用于特定用途
非限定性净资产没有这类限制的

三件事要记住：

① 内部限定不算限定——理事会自己作的限定性决议、拨款限额，属于内部管理限制，不构成限定性净资产。判据一句话：限制必须来自"资产提供者"或者"国家法律法规"，不能来自机构自己的决议。

② 净资产规模直接决定费用比例——不具有公开募捐资格的慈善组织，年度支出和管理费用就是按上年末净资产分档的。所以净资产不是个纯会计数字，它跟你能不能达标直接挂钩。

③ 净资产是累计概念，一年年攒下来的；它跟"本年收入"不是一回事。算比例时，要看文件要求的是"净资产"还是"总收入"——两者不能混。

### 慈善活动支出（年度支出）

基于慈善宗旨、在章程业务范围内开展慈善活动，向受益人捐赠财产或提供无偿服务发生的费用，在"业务活动成本"下核算。有比例下限。

2026 年的新规进一步要求：慈善活动支出应当主要用于受益人；计算比例时，应当将到达最终受益人的款物作为慈善活动支出。这句话把"中间环节的钱算不算"这个问题收紧了。

### 管理费用

为保证机构正常运转发生的费用。有比例上限，而且按组织类型和净资产规模分档，不是只有一个 10%。

包含五项：①理事会等决策机构的工作经费；②监事会等监督机构的工作经费；③党建工作经费；④行政管理人员的工资、奖金、住房公积金、住房补贴、社会保障费；⑤办公费、水电费、邮电费、物业管理费、差旅费、折旧费、修理费、租赁费、无形资产摊销费、资产盘亏损失、因预计负债所产生的损失、聘请中介机构费等。

②③这两项是 2026 年新规明确写进来的——以前这两笔常不知往哪放。

### 募捐成本

基于慈善宗旨、在募集财产时发生的费用，在"筹资费用"下核算。2026 年新规把它单列出来定标准：年度募捐成本不得高于前三年捐赠收入平均数的 3%。

包含：①为开展募捐活动直接发生的场地设备、人员差旅、专业技术服务等必要费用；②为获得捐赠财产计入当期费用的汇兑损失（减收益）。

一条明确的排除：募捐活动中涉及本组织场地设备和工作人员的相关费用，不得计入募捐成本。并且要求据实列支。

### 三条费用线的分档（现行依据：民发〔2026〕12 号）

三个数同时受约束：慈善活动支出（下限）、管理费用（上限）、募捐成本（上限）。按"是否公开募捐 + 组织形式 + 上年末净资产"取值：

两个口子：①年度管理费用低于 20 万元的，不受管理费用比例的限制；②符合特定情形（如登记为慈善组织未满 1 年尚未全面开展活动、折旧费与无形资产摊销费、资产盘亏损失突发性增长等）导致难以达标的，应当及时报告登记的民政部门并向社会公开说明情况——这是法定出路。

计算技巧：可以用前三年收入平均数代替上年总收入、用前三年年末净资产平均数代替上年末净资产——这是为了照顾收入有大小年的机构。

具体数字以现行文件为准，办理前请核对原文。

### 保值增值

让账上的慈善财产通过合规方式不贬值。基金会应当按照合法、安全、有效的原则实现基金的保值、增值。

不是有钱就能投：有专门的管理规定和内部决策程序要求（有些地方要求理事会决议、投资决策记录留档）。投资收益的税务属性和免税收入不是一回事，要单独看。

### 民间非营利组织会计制度

慈善组织执行的那套会计准则，和企业的完全不同。报表结构、科目设置都不一样，找会计时要注意对方熟不熟这套。

2026 年起施行新版，科目和口径有调整（比如费用按功能分七类、长期股权投资统一改为成本法、取消了合并报表编制要求等）。适用对象包括社会团体、基金会、社会服务机构、宗教活动场所、境外非政府组织在中国境内依法登记设立的代表机构等。

### 三张报表

资产负债表、业务活动表、现金流量表——民间非营利组织的三张主表。

企业叫"利润表"，这里叫"业务活动表"，因为不核算利润，核算的是"业务活动"的收支。看表时要留意这个差别。

报送期限：年度财务会计报告至少于年度终了后 4 个月内对外提供；要加盖公章，并由单位负责人、主管会计工作的负责人、会计机构负责人签名并盖章。

### 代理记账

把记账、报税整体委托给会计师事务所或经批准的代理记账机构。小机构常用。

三个注意点：①委托代理记账要在财务报告（包括审计报告）中披露代理记账机构的信息；②会计不得兼任出纳，出纳不得兼管稽核、会计档案保管和收入／费用／债权债务账目的登记；③机构主要负责人不得兼会计、出纳。

底线：外包机构承担的是技术活，不承担责任——报表签字、年报填报、数据核对的责任仍在机构。

### 关联方 / 关联交易

与机构存在特定关系的个人或单位（理事、负责人、主要捐赠人及其近亲属、以及其控制的企业等），叫关联方；与关联方发生的交易叫关联交易。

要从两个层面同时管：

①治理层面——要识别、要登记、要走流程：负责人、理事、监事、主要捐赠人等，与交易对象存在控制关系或能够施加重大影响的，应当主动报告并按规定回避表决，相关交易情况应依法如实披露。

②会计层面——要履行内部决策程序、保证价格公允，并在会计报表附注中披露关联方关系的性质、交易类型及交易要素。

两条硬红线：

· 理事、监事及其近亲属，不得与其所在的基金会有任何交易行为；

· 不得将大额财产长期无偿交由或出借给其他组织、个人而不收回。

为什么这么严：慈善组织的钱是社会公共财产，关联交易是"自己人跟自己人做生意"，最容易被用来变相转移财产。不是不能做，是不能"不声不响地做"。


## 监管与评估

### 年检 / 年报（两个不同的制度）

年度报告：慈善组织用，依据《慈善法》向民政部门报送年度工作报告和财务会计报告。

年度检查：其他社会组织用；2026 年 1 月 1 日起《社会团体年度检查办法》施行，其他类型社会组织均实施年度检查。

时间点看有没有业务主管单位：

情形时间安排

有业务主管单位3 月 31 日前报业务主管单位初审 → 经初审后 5 月 31 日前报登记管理机关
无业务主管单位直接于 5 月 31 日前报登记管理机关
登记机关出结论原则上 9 月 30 日前作出结论并向社会公布

两类制度的两点差别：主体不同（年报以自报为主，年检以民政部门主导、多部门协同核查为主）；后果不同（未按规定提交年报的，实施信用监管，列入活动异常名录等；未按要求参加年检的，可依法作出警告、限期停止活动、撤销登记等行政处罚）。

### 年度工作报告 / 财务会计报告

年报的两个组成部分。报告要包括：年度开展募捐和接受捐赠、慈善财产的管理使用、慈善项目实施、募捐成本、慈善组织工作人员工资福利、与境外组织或个人开展合作等情况。

慈善组织还要另行在统一信息平台公开年度工作报告全文，这一步容易漏。涉及国家秘密、商业秘密、个人隐私的信息不予公开。

### 抽查审计 / 专项检查

不打招呼就来查的方式，包括财务抽查、慈善活动规范检查、管理漏洞排查等。这是"要经得起查"这句话的由来。

现在的监管是一整套组合：年检年报 + 抽查审计 + 专项检查 + 等级评估 + 舆情监测 + 信用信息管理 + 法人库数据比对。对发现的问题用梯次工具：提醒敦促 → 约谈负责人 → 发放整改文书 → 行政处罚。

### 等级评估 / 社会组织评估

民政部门组织的综合评估。从基础条件、内部治理、工作绩效、社会评价等方面打分（党的建设是其中一个方面），结果分 5A 至 1A 五档，有效期五年，实行动态管理。

参评条件：一般要求取得登记证书满一定年度、未参加过评估，或等级有效期届满需重新评估。

不予评估的情形：未参加上年度年检年报、年检不合格或连续 2 年基本合格、上年度受到行政处罚且未执行完毕、正在被立案调查、党组织应建未建等。

### 5A / 4A / 3A（有优待的三档）

3A 以上（含 3A）：可优先承接政府职能转移，优先获得政府购买服务和政府奖励；慈善组织可据此申请公开募捐资格；公益性社会组织可申请公益性捐赠税前扣除资格；有开展评比、达标、表彰等业务活动的资格。

4A 以上：年检可简化程序；有的地方还可在评优评先中直接推荐。

5A：报国家民政部备案；有的地方免予参加年检 1–2 年。

等级也是对外的信誉证明：开展活动和宣传时可以出示证书，牌匾要悬挂在办公或服务场所的明显位置。

### 2A / 1A（低等级是怎么回事）

1A／2A 本身不是行政处罚，是"没有优待"。影响分三层看：

①最直接的：没有 3A 以上，就没有那些资格。政府职能转移、政府购买服务、公开募捐资格申请、公益性捐赠税前扣除资格申请，都需要 3A 及以上等级。

②会被要求整改。有地方明确规定："获得 2A 以下评估等级的社会组织，应按照登记管理机关指导进行加强自身建设，提升等级。"

③还有一种状态比 1A 更低：无评估等级。符合条件却没申请参加评估、或者等级有效期届满没再申请的，视为无评估等级。

真正的"惩罚机制"在动态管理那一层。获得等级后有下列情形之一的，会被降低等级，情节严重的取消等级：

· 评估中提供虚假情况和资料，或与评估人员串通作弊，致使评估情况失实；

· 涂改、伪造、出租、出借评估等级证书，或伪造、出租、出借等级牌匾；

· 连续 2 年年度检查基本合格；

· 上年度年度检查不合格，或上年度未参加年度检查；

· 受相关政府部门警告、罚款、没收非法所得、限期停止活动等行政处罚；

· 其他违反法律法规规定的情形。

后果：被降低等级的，2 年内不得提出评估申请；被取消等级的，3 年内不得提出评估申请。降低或取消等级要书面通知机构及其业务主管单位，并向社会公告；原证书、牌匾要按规定交回。

### 信息公开

慈善组织的法定义务。要在统一平台公开章程、登记信息、年度报告、募捐信息、重大事项等。不是"愿意公开就公开"。

公开募捐的专门时限：公开募捐活动结束后三个月内要公开募得款物情况、已使用募得款物的用途、尚未使用的募得款物的使用计划；募捐周期超过六个月的，至少每三个月公开一次；项目结束后三个月内要全面公开项目实施情况和募得款物使用情况。

### 新闻发言人制度

指定一名负责人担任新闻发言人，统一对外口径、做好舆情应对。

作用不是宣传，是风险管理——保证对外只有一个出口：谁说、说什么、按什么口径说，事先定好。

从"倡导建立"到"评估必查"，要求越来越实。等级评估里，新闻发言人制度、对外口径管理、舆情应对机制都是评分项。

### 慈善中国

全国慈善信息公开平台，民政部建设的统一信息平台，2017 年 9 月正式对外提供信息发布服务。年报、募捐备案、机构信息查询都在这里。

要上什么：慈善组织登记事项、慈善信托备案事项、具有公开募捐资格的慈善组织名单、具有出具公益性捐赠税前扣除票据资格的慈善组织名单、税收优惠与购买服务信息、表彰与处罚结果等。凡开展公开募捐活动，要通过平台获得"一号一源"、可追溯识别查询的募捐备案编号。

### 活动异常名录 / 严重违法失信名单

民政部门记录的社会组织信用信息。未按规定提交年度报告等行为会被列入，一处失信，会在很多地方被限制（承接政府购买服务、评优评先、税收优惠等）。

民政部门还建了社会组织法人库、信用信息管理平台，推进跨部门信息共享，失信会有联合惩戒。

### 行政处罚

民政部门等对违规行为的处罚。常见情形：未按章程宗旨和业务范围活动、填制凭证与编制报告弄虚作假、不按规定办理变更登记、未完成公益事业支出额度、未按规定接受年检或年检不合格、不履行信息公布义务或公布虚假信息。

处罚种类包括警告、责令停止活动、罚款、没收非法所得、限期停止活动、撤销登记等。申请慈善组织认定前二年内受过行政处罚的，不予认定。收到任何处罚告知，第一时间找专业意见。

### 应建未建

指按要求应当建立党组织但没有建立。实务上会直接影响等级评估资格——有的地方规定应建未建的不予评估。这是资格问题，不是加分问题。


## 项目与相关方

### 立项

项目正式开始前的决策程序：明确做什么、花多少、谁负责、怎么验收。立项书是后面所有执行动作的依据。

立项要解决的通常是四件事：目标（要解决什么问题、怎么衡量）、预算（钱从哪来、怎么花、科目怎么设）、权责（谁是负责人、谁配合、谁审批）、回避（有没有关联方参与、要不要回避）。预算科目一旦定了，后面尽量不要随手改——结项时对不上账是常见问题。

### 受益人 / 受益对象 / 受益群体

项目最终服务到的人或群体。称呼上还有受助人、服务对象的说法，意思接近，具体用哪个看机构习惯和项目语境。

三个必须做的动作：①需求调研（他们到底需要什么）；②名册建立与资格审核（谁符合条件、依据是什么）；③触达与反馈（东西到没到、人有没有反馈）。

为什么这一环最要紧：受益人是资金流向的终点——检查最看重这里。名册不全、信息不实、签收缺失，是项目检查里最常见的问题。

### 欠发达地区 / 经济困难群体（表述在变）

写项目材料常用的一组词：欠发达地区、经济欠发达地区、经济困难群体、困难群众、低收入群体、困境群体。

注意用词的变化：2020 年脱贫攻坚完成之后，"贫困""贫穷"这类说法在正式材料里明显减少，一般改用"困难""低收入""欠发达"，有时也表述为"脱贫地区""乡村振兴重点帮扶县"。

写新材料的，跟着现行口径走；引用旧材料原文的，保留原词并说明当时的背景。

### 留痕

把做过的事留下可查的证据：签字、照片、票据、记录、纪要。慈善组织的一切工作，最终都要"经得起查"。

三种常见的留痕缺口：①钱花出去了，但没有签收或验收记录；②物资发下去了，但没有发放台账或照片；③事情办成了，但没有审批单或会议记录。这三处补起来最容易，也最容易被忽略。

### 台账

按时间或类别逐笔记录的登记簿（如捐赠票据台账、物资发放台账、印章使用登记表、证照年检台账）。台账是档案和财务报表之间的那道桥。

好的台账一般有三列：时间、事项、凭证号——有了凭证号，就能顺着找到原始单据。

### 结项

项目结束时的收口：财务决算、成果说明、档案归集、结余资金处理。结项不是"做完了"，是"交代清楚了"。

结项通常要交这几样：项目总结报告、财务决算（和预算对得上）、受益人情况统计、影像与案例素材、档案目录。涉及公开募捐的，还要按规定公开项目实施情况和募得款物使用情况。

### 结余

项目结束后剩下的钱。怎么处理要看捐赠协议约定和机构制度，不能自行挪作他用。

常见处理：按协议约定退回捐赠人、经捐赠人同意转用于同类项目、或按机构制度转入其他公益项目。无论哪种，都要有记录和依据，不能口头决定。

### 志愿者 / 志愿服务记录

自愿、无偿提供服务的人。机构应当记录服务时间、内容、评价，并可以出具证明。

志愿者管理和员工管理不是一回事——有专门的规定，涉及招募公示、风险告知、岗位适配、培训、协议、排班、激励与关系维护。三个必须留痕的地方：招募时要公示全部信息并告知可能的风险；岗前培训要覆盖必要内容；风险告知要留痕。

### 利益相关方 / 相关方

与机构有利益关系的各方：捐赠人、受益人、合作方、供应商、政府、员工、社区等。

相关方管理不是"关系维护"，是合规管理。要做的动作包括：识别谁算相关方（特别是关联方）、建立台账、明确对接人、规范合作程序、留好协议与往来记录。合作方管理尤其要看：主体资格与资质、角色边界、采购比价与回避、协议要素、对账与资金管理。

### 资方 / 捐赠方 / 资助方

口语里都指给钱的一方，但含义略有差别：捐赠方偏指捐赠人（把钱物捐给机构）；资助方偏指以项目资助形式给钱的基金会或机构；资方最口语，有时带上"出资人"的意味。

在公益语境里要小心用"资方"——公益机构没有"股东"，说"资方"容易让人误以为有出资人权益。


## 只在口头出现的说法

### 社平

"社会平均工资"的口头简称，常出现在讨论薪酬的时候。

一个必须留心的坑：免税资格那条"两倍"线，比的不是社平，而是"税务登记所在地地市级以上地区同行业同类组织平均工资水平"。听到有人说"两倍社平"，多问一句：是按哪个口径算的？

### 两倍

单独说"两倍"，通常指免税资格里"工作人员平均工资薪金不超过同类组织平均工资两倍"这条线。

它管的是能不能保住免税资格，不是工资该发多少——两件事，别混。

### 专基 / 专项

"专项基金"的口头简称。"你们有没有专项？"问的就是有没有专项基金。见第三类和第八类。

### 民非（老词，仍在用）

"民办非企业单位"的简称，就是法律文件里说的社会服务机构，登记证书上写的是"民办非企业单位"。老文件、老同事常用。详见第二类【社会服务机构】那一节。

### 双重管理

"业务主管单位 + 登记管理机关"两头管。听到这四个字，通常是在解释某个流程为什么这么绕、为什么要有两道手续，或者为什么年检要多一个 3 月 31 日的节点。

### 脱钩

行业协会商会与行政机关脱钩改革。听到"脱钩前／脱钩后"，说的是这段改革前后的差别。已经脱钩的，通常不再有业务主管单位——这直接影响年检／年报的时间点。

### 资方 / 捐赠方 / 资助方

见第七类。提醒一句：公益机构没有"股东"，说"资方"容易引起误解。

### 备案 / 审批 / 核准 / 认定

四个词的区别在管的松紧：

词管的松紧典型场景

审批最严——不批不能做设立登记、变更登记
核准次之——审内容合规章程修改报核准
备案告知 + 存档，一般不实质审募捐方案备案、负责人备案
认定确认某个身份或资格慈善组织认定、免税资格认定

听到哪个词，就知道这件事的空间有多大。


## 容易混的六组

### 第一组：公益 / 慈善

|  | 公益 | 慈善 |
|---|---|---|
| 性质 | 日常词、政策词，法律上没有统一定义 | 《慈善法》第三条有明确定义（六类活动） |
| 范围 | 宽——涉及公共利益的事 | 窄一些——法律明确划出来的那一块 |
| 受什么规范 | 不一定受《慈善法》直接规范 | 受《慈善法》规范，需要慈善组织资格或合作开展 |
| 怎么用 | 日常聊天、写文章都行 | 正式材料、涉及资格和募捐时必须准确 |

### 第二组：社会组织 / 慈善组织

|  | 社会组织 | 慈善组织 |
|---|---|---|
| 是什么 | 政策文件的统称（社团、基金会、社会服务机构三类） | 一种属性，要申请认定 |
| 怎么来 | 登记就是社会组织 | 登记之后还要认定为慈善组织，换发标有"慈善组织"字样的证书 |
| 关系 | 三类组织（社团／基金会／社会服务机构）中，符合条件的可以申请认定为慈善组织——不是并列关系，是"属性叠加" |

### 第三组：社会团体 / 基金会 / 社会服务机构

|  | 社会团体 | 基金会 | 社会服务机构 |
|---|---|---|---|
| 怎么来的 | 会员自愿组成 | 用捐赠财产设立 | 用非国有资产举办 |
| 有无会员 | 有（会员大会／代表大会） | 无 | 无 |
| 最高层 | 会员大会／代表大会 | 理事会（5–25 人） | 理事会，或举办者 |
| 典型 | 协会、学会、商会、研究会 | ××基金会 | 民办学校、民办医院、养老机构、社工机构 |
| 登记依据 | 《社会团体登记管理条例》 | 《基金会管理条例》 | 《民办非企业单位登记管理暂行条例》 |
| 登记证书上写 | 社会团体 | 基金会 | 民办非企业单位 |
| 能不能设分支机构 | 可设，但不得设地域性分支、分支不得再设分支 | 可设（须登记） | 不得设立分支机构 |

### 第四组：公募基金会 / 具有公开募捐资格的慈善组织

|  | 公募基金会 / 非公募基金会 | 具有／不具有公开募捐资格 |
|---|---|---|
| 说的是谁 | 只用于基金会 | 三类组织都适用（社团、基金会、社会服务机构） |
| 说的是什么 | 都是同一个维度：能不能面向社会公众募捐 |
| 怎么用 | 说基金会时的习惯叫法 | 说社团、社会服务机构时，只能用这个说法 |

### 第五组：专项基金 / 分支机构 / 项目

|  | 是什么 | 怎么来的 | 能不能独立对外 |
|---|---|---|---|
| 专项基金 | 基金会内部为特定用途设立的资金专项，多以某个捐赠人意愿为起点 | 基金会内部决定、按要求备案 | 不能——用名要冠基金会全称 |
| 分支机构 | 依据业务范围或财产划分、专门从事某项业务的机构（含基金会的专项基金管理委员会、社团的专委会／分会） | 理事会决定 + 备案／自律管理（社团、基金会已取消行政审批） | 不能——也不得再下设分支机构 |
| 项目 | 有明确目标、期限、预算和受益人的具体活动 | 机构内部立项程序 | 不能——以机构名义开展 |

### 第六组：变更登记 / 备案，以及 年检 / 年报

|  | 变更登记 | 备案 |
|---|---|---|
| 管什么 | 登记事项：名称、住所、类型、宗旨、业务范围、原始基金数额、法定代表人 | 理事、监事、其他负责人（秘书长等）的变更 |
| 后果 | 要换领新的法人登记证书 | 一般只报备，不换证 |
| 前置 | 有业务主管单位的，一般都要先经其同意 |
| 谁用 | 慈善组织 | 其他社会组织（2026 年起全面实施） |
| 主体 | 以组织自报为主 | 民政部门主导、多部门协同核查 |
| 没做的后果 | 信用监管：列入活动异常名录、严重违法失信名单等 | 可依法作出警告、限期停止活动、撤销登记等行政处罚 |
