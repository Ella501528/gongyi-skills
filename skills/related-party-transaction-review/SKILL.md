# 慈善组织关联交易合规审查

## 何时使用

- 与关联方发生往来，要判断是否构成关联交易
- 要履行回避、决策、定价审查程序
- 遇到高频疑难场景（资助理事所在机构、发工资、提供办公场所等）
- 要生成交易审查记录留痕

## 何时不用本技能

- 对方是不是关联方还没定 → 先用关联方识别与登记确定主体范围
- 已走完程序，只要公开文本、时限核对或违规后果分析 → 用关联交易公开与责任
- 主体不是慈善组织（企业、政府采购、事业单位等）→ 口径不同，本技能不适用
- 要的是法律定性、争议代理或对外答复 → 本技能不作法律意见，交律师、登记管理机关或专业机构

## 输入输出契约

**你要准备什么**

一份按本包 `sample_data/sample_input.json` 结构填写的事实 JSON。本技能负责 `facts.transaction` 与 `facts.procedure` 两组字段，取值三态：`true`（存在或已完成）、`false`（不存在或未完成）、`null`（资料未取得）。

| 分组 | 字段 | 采集什么 |
|---|---|---|
| transaction | `occurred`、`resource_transfer`、`recognized_as_related` | 有无往来、是否转移资源服务或义务、是否已认定为关联交易 |
| transaction | `deemed_not_related_because_no_payment` | 是否以未收款为由否定关联交易认定 |
| transaction | `beneficiary_related_designated` | 是否指定利害关系人为受益人 |
| transaction | `close_relative_transaction` | 是否与理事、监事近亲属发生交易 |
| transaction | `type_classified` | 是否已归入九类常见交易类型 |
| transaction | `pure_benefit`、`full_procedure_for_pure_benefit` | 是否纯获利益行为、是否被要求履行全部程序 |
| procedure | `avoidance_done`、`avoidance_recorded` | 是否已回避、回避与表决有无留痕 |
| procedure | `collective_decision`、`resolution_document` | 是否经决策机构审议、有无决议文件 |
| procedure | `pricing_only_negotiated`、`overpriced_purchase`、`underpriced_disposal` | 定价依据是否仅双方协商、有无高价采购或低价处置 |
| procedure | `dedicated_body` | 是否设立关联交易决策机构或专门评估机制 |

**跑之前先装依赖**（只需一次）

```
pip install openpyxl
```

未安装也能跑，脚本会自动降级为 CSV 清单与 Markdown 摘要。

**跑完得到什么**

在包根目录执行：

```
python scripts/run_check.py -i 我的机构.json
```

得到 `（输入文件同级目录）/out/关联方合规体检报告_YYYYMMDD.xlsx`，四个工作表：体检摘要、缺陷清单、待确认项、评分明细。控制台同时输出 Markdown 摘要。本技能另交易审查记录，含：交易描述、关联方判定及依据、是否构成关联交易、四要件逐项核查结果、公开与披露安排、责任人、日期。

**什么叫成功**

1. 报告文件已生成，四个工作表均有内容；
2. 报告中的评分、命中数、待确认数与控制台摘要完全一致；
3. 「缺陷清单」按高、中、低排序，每条都带法规依据与整改建议，可直接作为整改派工单；
4. 「待确认项」列出需补充的字段路径，补齐后复评，评分上升即说明程序缺口已补上。

**资料不全或跑不动时怎么办**

- 字段填 `null` 即标记为「待确认」，不计入评分分母，既不会被算作通过，也不会被算作命中；
- 多数程序类规则仅在 `recognized_as_related` 为 `true` 时评估，这一字段缺失会使相关规则整体转为「待确认」；
- 未安装 openpyxl 时自动降级为 CSV 清单与 Markdown 摘要，不中断；
- 报告文件被 Excel 或 WPS 占用时，用 `-o` 指定新文件名再跑；输入 JSON 语法错误会给出行列位置。

## 第一步：是否构成关联交易

**定义**：关联方之间转移**资源、服务或义务**的行为，**不论是否收取价款**。

要点：是否收款、价格高低，都不影响"构成关联交易"这一判断。免费提供的服务、无偿资助同样可能构成。

**六类须公开情形**（信息公开办法第 14 条）：接受重要关联方捐赠、对其资助、共同投资、委托其投资、发生交易、其他资金往来。

**常见类型**（会计制度第 90 条）：购销商品及资产、提供或接受服务、提供或接受捐赠、设立或受托管理慈善信托、提供资金、租赁、代理、许可协议、代结算、关键管理人员薪酬。

## 第二步：四要件核查（缺一不可）

| 要件 | 要求 | 留痕 |
|---|---|---|
| **决策回避** | 关联方不得参与本组织有关该交易行为的决策 | 会议签到、回避声明、表决记录 |
| **民主决策** | 经理事会或关联交易决策机构审议，不得以个别负责人审批替代 | 决议文件 |
| **价格公允** | 不得高价采购关联方产品，不得低价处置本组织财产；不得利用关联关系损害组织、受益人和社会公共利益 | 市价比对依据或独立说明 |
| **公开与披露** | 发生后三十日内平台公开；财报附注披露四项要素 | 公开截图、财报附注 |

## 第三步：财务会计报告披露四项要素

1. 关联方关系的性质
2. 交易类型
3. 交易金额
4. 未结算项目的金额、条款和条件；未结算应收项目的坏账准备金额；定价政策

**定价政策是审查重点**，须有可比照的市价依据或独立说明，不能只有"双方协商确定"。

## 高频场景速查

| 场景 | 结论 | 要点 |
|---|---|---|
| 资助理事、监事所在机构 / 与其合作 | 可以 | 属关联交易，须回避、公允、公开、披露 |
| 向捐赠方成立的其他慈善机构捐赠 | 可以 | 若捐赠方能通过其机构影响决策，应保守认定为关联方 |
| **给管理人员发工资** | **属于关联交易** | 须回避、公允定价、公开与财务披露；其他工作人员工资不属关联交易 |
| 理事监事企业有偿提供办公场所 | 可以 | 属租赁类型，四项要求照走 |
| 捐赠方员工或子女致贫可否资助 | 可以 | 属关联方则须回避与公开；**理事监事的子女或近亲属除外，不得接受资助** |
| 关联方免费使用公益服务 | 可以 | 须公开，且不得损害公共利益 |
| **关联方免费讲课（纯获利益）** | 财报登记即可 | 无需履行回避决策与信息公开义务 |
| 礼品馈赠与接待 | 构成交易 | 应节制，取纪念意义而价值不高之物 |
| 设立慈善信托 | 可能构成 | 委托设立、受托管理已列入常见类型 |
| 指定利害关系人为受益人 | **禁止** | 属法定违规情形 |

## 必须主动提示的情形

1. 对方是理事、监事**近亲属** → 提示不得发生任何交易，包括接受资助
2. 定价只有"双方协商" → 提示须补充可追溯依据
3. 纯获利益行为被要求走全部程序 → 提示财报登记即可，避免不当增加负担
4. 引用旧条号（第 99、100 条） → 提示现行已调整为第 110、112 条
5. 三处口径不一致（年报 / 平台 / 财报） → 提示以同一份台账为唯一数据源

## 审查记录输出

含：交易描述 / 关联方判定及依据 / 是否构成关联交易 / 四要件逐项核查结果 / 公开与披露安排 / 责任人 / 日期。

> 依据：《慈善法》第 14 条（回避、不得损害利益、交易情况应当公开）、第 110 条第二项（指定利害关系人为受益人）；《慈善组织信息公开办法》第 14 条；《民间非营利组织会计制度》（财会〔2024〕25 号）第 88 条第十八项、第 90 条。具体比例的现行标准以公布的规定为准。
