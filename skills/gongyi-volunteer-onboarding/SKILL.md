# 慈善组织志愿者招募培训与岗位适配

志愿者管理里出事最多的一段，是**招进来、还没用好**这一段。三句最常见的话——"公告里没写清楚"、"让他干了他干不了的"、"这个岗位本来要证的"——分别对应本技能的三块：**告知、适配、培训与资格**。

## 什么时候会用到它

| 时机 | 你要做的事 |
|---|---|
| 发招募公告前 | 用第一节自查公告要素是否齐、风险是否写明 |
| 志愿者报名后、上岗前 | 用第二节做岗位适配（年龄／技能／身体状况） |
| 岗位需要专门技能或资格时 | 用第三节核对培训与证书 |
| 长期、有风险或专业服务 | 用第四节判断要不要签协议 |
| 上岗前最后一道关 | 用第五节核岗前培训是否完成 |
| 评估、检查、出了事要复盘时 | 把安排表交给 `scripts/check_onboarding.py` 跑一遍 |

## 一、招募：公示全部信息 + 告知风险

**法定要求**（《慈善法》第六十四条、《志愿服务条例》第十二条）：招募时应**公示与志愿服务有关的全部信息**，并**说明服务过程中可能发生的风险**——不是"简单提一句"，而是说明到志愿者能作判断的程度。

招募公告至少应含：**服务内容、时间与地点、岗位要求、风险提示、保障条件（交通/食宿/保险）、报名方式、联系人**。

**风险告知**两条硬要求：
1. **写入公告**（面向所有人）；
2. **上岗前书面告知并留签收**（面向确定参加的人）。签收记录是出事时"已尽告知义务"的证据。

## 二、岗位适配：年龄、技能、身体状况

**法定要求**（《慈善法》第六十七条、《志愿服务条例》第十五条）：安排的服务应当与志愿者的**年龄、知识、技能和身体状况相适应**，**不得要求志愿者提供超出其能力的服务**。

| 维度 | 判什么 | 常见红线 |
|---|---|---|
| 年龄 | 未成年人是否参加与其年龄相适应的活动 | 未成年人不得单独参加高体力／高风险活动 |
| 技能 | 岗位是否需要专门技能 | 医疗护理、心理干预、水域救援等属专业岗 |
| 身体状况 | 是否有不宜参加该活动的健康情形 | 高强度、长途、夜间、水下等活动须先核 |

> "相适应"是**双向**的：既不能强派，也不能明知不适配还让他上。

## 三、培训与职业资格

**法定要求**（《慈善法》第六十四条、《志愿服务条例》第十六条）：安排需要**专门知识、技能**的服务，应当**对志愿者开展相关培训**；开展专业志愿服务应执行国家或行业标准规程；**法律、行政法规对职业资格有要求的，志愿者应当依法取得相应资格**。

三句话：
1. **需要专门技能 → 必须先培训**（并留培训记录）；
2. **需要职业资格 → 必须先持证**（如急救员证、水域救援证、教师/医护执业资格）；
3. **培训完成前 → 不得安排上岗**。

## 四、协议：什么时候应当签

**法定要求**（《慈善法》第六十五条、《志愿服务条例》第十四条）：可**根据需要**签订协议，明确双方权利义务，约定服务内容、方式、时间、地点、工作条件与安全保障措施。

判断口径（实操）：**出现以下任一情形，建议签书面协议**——
- 服务跨一定周期（如超过一个月）、需长期排班；
- 服务具有人身危险或高强度；
- 涉及专门技能、职业资格；
- 涉及志愿者个人信息的收集与对外使用；
- 志愿者本人要求签。

## 五、岗前培训与上岗前核对

岗前培训至少覆盖：**组织与项目介绍、服务内容与规范、风险与应急、保密与行为准则**。

**培训未完成不得排班**。这一条要落到排班表上——排班表应能显示"该志愿者已完成岗前培训"。

## 六、脚本用法

```bash
python scripts/check_onboarding.py --input sample_data/sample_input.json --out ./招募体检报告.xlsx
```

- **输入**：一份 JSON，含本次活动定义（`activities`）与人员安排（`assignments`），结构见 `sample_data/sample_input.json`。
- **输出**：Excel 四表——**汇总 / 安排明细 / 异常清单 / 待补材料**；无 openpyxl 时降级 CSV。
- **阈值**：未成年人下限年龄用 `--minor-age`（默认 18）；协议触发的高风险级别用 `--risk-for-agreement`（默认 高）。

## 七、判定口径（八条）

| 编号 | 判什么 | 严重度 |
|---|---|---|
| O1 | 招募公告要素不全或未公示 | 中 |
| O2 | 未做风险告知或未留签收 | 高（高风险活动）／中（其他） |
| O3 | 应当签协议而未签 | 中 |
| O4 | 岗位与年龄／身体状况不匹配 | 高 |
| O5 | 岗位与技能不匹配 | 高 |
| O6 | 需专门技能而未培训 | 中 |
| O7 | 需职业资格而未取得 | 高 |
| O8 | 岗前培训未完成即安排上岗 | 高 |

规则编号与 `references/判定规则索引.md` 一一对应。

## 八、边界与降级（必读）

1. **命中项是待核项，不是违规结论**。如"技能不匹配"可能是登记口径问题，须核实。
2. **含真实个人信息时**：脚本只读输入、不联网；报告对人名打码。
3. **缺关键字段时不猜**：无年龄、无活动风险级别时，相关规则报"无法判定"。
4. **"相适应"是判断题不是算术题**：脚本只对"明显不匹配"（如无证上岗、未成年人单独高风险）报警，不对边缘情形下结论。
5. **本技能不判记录与证明**——那属「名册与服务记录证明」；不判保险——那属「风险与保险」。

## 九、什么时候不该用本技能

- 志愿者实名登记、服务记录、开证明 → 用「名册与服务记录证明」。
- 哪类活动必须投保、出险怎么处理 → 用「风险与保险」。
- 合作方招募与管理 → 属合作方主题。
