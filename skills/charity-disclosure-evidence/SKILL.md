# 慈善组织信息公开取证工具包
本技能聚焦"外部评查"口径：只看这家机构**对外公开了什么**，用证据说话，输出公开度比例与逐项四态判定。供捐赠人、媒体、评估方、同行、拟合作方在核查时自行上手使用。

## 何时用本工具包
- 评查一家机构的公开透明度 / 做捐赠前尽调
- 按渠道检索并留痕"这家机构到底公开了什么"
- 输出公开度比例、逐项四态判定、核验盲区清单
- 媒体 / 同行 / 评估方的外部核查

## 关键作业步骤
1. **读口径**：`references/evidence/maturity-rating-rubric.md`
2. **定渠道**：`references/evidence/external-evidence-sources.md`
3. **套清单**：`templates/01` 逐项落四态并留痕
4. **出报告**：`templates/09`
5. **必查依据原文**：判定"未公开"前回 `references/spine/legal-basis.md` 确认法定要素与时点
6. **FTI 辅助**：`references/maturity/fti-benchmark.md` 作行业水位对照（D 级证据，不作"已公开"证明）

## 本包必守铁律
1. **外部评查第一铁律：无法核实 ≠ 未公开**。二者必须分表分列，任何情况下不得合并计数。
2. **完整分母**：无法核实项保留在分母内、分子记 0，另列盲区清单。不得把"查不到"从分母剔除（会让比例虚高），也不得把它计成"未公开"。
3. **只给百分比，不设等级**：不得输出 A–E 等级、分档、星级或徽章，也不得使用"完备／良好／薄弱"这类档位词。
4. **证据等级**：A 级（平台原始条目）可作"已公开"证据；D 级（第三方评分/排名，含 FTI）永不能作"已公开"证据；B 级（机构自有渠道）不能单独支撑"未公开"，也不能顶替 A 级条目；内部自持材料不是公开证据。
5. **机构名称必须用登记全称**检索。
6. **FTI 只观测基金会**；FTI 是 D 级证据，不得作为"已公开"证明或机构整体评价背书。
7. **不得编造数据、案例、处罚结果**；缺失信息写"待核实"或"未检索到明确依据"。
8. 每次交付末尾附免责声明：本成果为合规参考，不构成正式法律意见。
