# 时限速查 · 阈值标准 · 不得公开与责任

> 依据：《中华人民共和国慈善法》（2024年9月5日施行）、《慈善组织信息公开办法》（民政部令第81号，2026年1月1日施行）。详细条款见 `legal-basis.md`。

## 一、时限速查表

| 时限 | 事项 | 依据 |
|------|------|------|
| **形成之日起 30 日内** | 六类基本信息公开（章程、决策/执行/监督机构成员、下设机构、重要关联方、联系方式与自有平台、三项制度） | 《办法》第四条 |
| **变更后 30 日内** | 基本信息发生变更的，在平台公布 | 《办法》第十六条 |
| **每年 5 月 31 日前** | 公开年度工作报告和财务会计报告 | 《办法》第六条 |
| **每年 5 月 31 日前** | 不具公募资格的：公开上年度**重大慈善项目**实施情况 | 《办法》第十一条 |
| **每年 5 月 31 日前** | 向登记的民政部门**报送**关联方名单及关联关系说明 | 《办法》第十五条 |
| **及时** | 章程、决策/执行/监督机构成员信息等有重大变更的 | 《慈善法》第七十八条 |
| **及时** | 定向募捐：向捐赠人告知募捐情况与款物管理使用情况 | 《慈善法》第八十条、《办法》第十七条 |
| **设立时** | 设立慈善项目时公开项目名称和内容 | 《办法》第九条 |
| **项目/活动结束后 3 个月内** | 公开募捐活动：募得款物、已使用用途、未使用计划、合作方评估监督 | 《办法》第八条 |
| **项目/活动结束后 3 个月内** | 具公募资格的慈善项目：项目实施情况（八项要素） | 《办法》第十条 |
| **项目终止后 3 个月内** | 项目终止后有剩余财产的：公开剩余财产处理情况 | 《办法》第九条 |
| **至少每 3 个月** | 公开募捐周期超过六个月的，公开募得款物情况与已使用用途 | 《办法》第八条 |
| **至少每 3 个月** | 项目实施周期超过六个月的，公开项目实施情况 | 《办法》第十条 |
| **至少每 5 日** | 为应对重大突发事件开展公开募捐：应急处置与救援阶段公开募得款物接收情况 | 《慈善法》第七十二条、《办法》第八条 |
| **发生后 30 日内** | 重大资产变动、重大投资、重大交易及资金往来：公开具体内容和金额 | 《办法》第十三条 |
| **发生后 30 日内** | 六类关联交易行为：公开具体内容和金额 | 《办法》第十四条 |
| **设立后 30 日内** | 作为委托人设立慈善信托：公开信托名称、受托人名称、委托金额等 | 《办法》第十二条 |
| **每年至少一次** | 担任慈善信托受托人：公开信托事务处理情况及财务状况 | 《办法》第十二条 |

## 二、年度固定节奏（通用日历骨架）

| 时间节点 | 动作 |
|---------|------|
| 1—3 月 | 整理上年度财务与项目数据；委托审计（具公募资格的年度财务会计报告须经审计）；核对关联方名单 |
| 3—4 月 | 形成年度工作报告；**有业务主管单位的，报业务主管单位审查同意** |
| **5 月 31 日前** | 在慈善信息公开平台公开年度工作报告和财务会计报告；不具公募资格的组织公开上年度重大慈善项目实施情况；向民政部门报送关联方名单及关联关系说明 |
| 每季度末 | 检查是否有周期超过六个月的募捐活动与项目需要按季公开 |
| 事件触发 | 重大资产变动/投资/交易资金往来、关联交易——发生后 30 日内公开；基本信息形成或变更后 30 日内公开 |
| 项目/活动结束 | 结束后 3 个月内完成全面公开；有剩余财产的项目，终止后 3 个月内公开处理情况 |

> 上述为按法定义务倒推的作业节奏，属**实务建议**，具体以本机构章程、业务主管单位要求与登记机关口径为准。

## 三、阈值标准（用于判定"要不要公开"）

| 概念 | 标准 | 依据 |
|------|------|------|
| **重大慈善项目** | 符合其一：①当年该项目捐赠收入占当年捐赠总收入 1/5 以上且超过 50 万元；②当年该项目支出占当年慈善活动总支出 1/5 以上且超过 50 万元；③持续时间超过 3 年 | 《办法》第二十八条 |
| **主要捐赠人** | ①注册资金捐赠人；②办公场所捐赠人；③年度累计捐赠额超过年度捐赠收入 5%，或年度捐赠超过 500 万元的捐赠单位、个人 | 《办法》第二十七条 |
| **重要关联方** | 发起人、主要捐赠人、管理人员、被投资方，以及与慈善组织存在控制、共同控制或者重大影响关系的个人或者组织 | 《办法》第四条第(四)项 |
| **重大资产变动 / 重大投资 / 重大交易及资金往来** | **由慈善组织依据有关法律法规规章在章程或者财务资产管理制度中规定** | 《办法》第十三条第二款 |
| 年度支出 / 管理费用 / 募捐成本 | 由国务院民政部门会同财政、税务等部门制定 | 《慈善法》第六十一条；**具体数值以最新政策文件为准** |
| 具公募资格的基金会年度支出与管理费用 | 年度支出不得低于上一年总收入的 70% 或者前三年收入平均数额的 70%；年度管理费用不得超过当年总支出的 10%；特殊情况下难以符合的，应当报告民政部门并向社会公开说明情况 | 《慈善法》第六十一条 |

⚠️ **最常见的制度缺项**：章程与财务资产管理制度中**未规定"重大资产变动、重大投资、重大交易及资金往来"的具体标准**，会导致第十三条义务无法落地。自查时必须单列此项。

## 四、不得公开的信息

| 类型 | 内容 | 依据 |
|------|------|------|
| 国家秘密 | 涉及国家秘密的信息 | 《慈善法》第八十二条、《办法》第二十一条 |
| 商业秘密 | 涉及商业秘密的信息 | 同上 |
| 个人隐私 | 涉及个人隐私的信息（含捐赠人、志愿者、受益人的隐私） | 同上 |
| 不同意公开的个人信息 | 捐赠人、志愿者、受益人、慈善信托的委托人**不同意公开**的姓名、名称、住所、通讯方式等信息 | 同上 |

**操作口径**：
- 需要公开受益人信息时，公开**受益人群及其确定方式**（选择标准与程序），不公开个人身份信息。
- 捐赠人匿名或要求不公开的，保留其不同意公开的**书面或可追溯的意思表示**，作为不予公开的依据。
- 拿不准的，出具《不予公开判定记录表》（`templates/08`），记录判定人、依据、日期。

## 五、法律后果与监管风险

| 后果 | 依据 | 说明 |
|------|------|------|
| 责令限期改正，予以警告，并没收违法所得；逾期不改正的，责令限期停止活动并进行整改 | 《慈善法》第一百一十条第(七)项 | 适用"未依法履行信息公开义务" |
| 泄露隐私或不同意公开信息的，同第一百一十条处罚 | 《慈善法》第一百一十条第(九)项 | — |
| 经依法处理后一年内再犯，或有其他严重情节的，吊销登记证书并予以公告 | 《慈善法》第一百一十条第三款 | — |
| 对直接负责的主管人员和其他直接责任人员处二万元以上二十万元以下罚款，没收违法所得；情节严重的，禁止一年至五年内担任慈善组织管理人员 | 《慈善法》第一百一十二条 | — |
| 慈善信托委托人、受托人未依法履行信息公开义务 | 《慈善法》第一百一十八条 | — |
| 记录、通报有关部门、实施联合惩戒 | 《办法》第二十五条 | — |
| 任何单位或个人可投诉、举报 | 《办法》第二十二条 | 面向社会的监督渠道 |
| 民政部门可约谈，要求说明、提出改进措施 | 《办法》第二十三条 | — |

> 上表为法定后果的**条文索引**，是否触发、如何适用需结合个案事实与主管机关口径判断。行政处罚应对、信用修复、听证陈述等具体事项，建议咨询执业律师或向办理其登记的民政部门确认。

## 六、术语表

| 术语 | 含义 |
|------|------|
| 慈善信息公开平台 | 国务院民政部门建立的**全国慈善信息公开平台**（业内通常称"慈善中国"），是履行本办法公开义务的法定主渠道 |
| 基本信息 | 《办法》第四条列举的六类信息，具公募资格的另加第五条两类 |
| 重要关联方 | 见上表阈值标准 |
| 公开募捐资格 | 慈善组织依法取得的面向社会公众募捐的资格；取得与否直接决定多项公开义务的差异 |
| 业务主管单位 | 部分慈善组织存在的主管单位，其年度工作报告和财务会计报告须经其审查同意 |
| 定向募捐 | 面向特定对象的募捐，负"及时告知捐赠人"义务而非平台公开义务 |
| 独立信息条目 | 《办法》第十六条要求为年报财报、每个募捐活动和慈善项目建立相对独立的条目 |
| 更正说明 | 平台信息需要更正时填写并公布的说明，须在相应条目下公布 |
