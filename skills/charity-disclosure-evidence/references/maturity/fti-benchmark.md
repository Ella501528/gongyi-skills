# FTI 中基透明指数指标基准

> 本文件是第三层（鼓励与公众期待）的作业基准，供「清单与依据官」与「整改方案官」使用。
> **FTI 是第三方行业评估，不是法律依据。** 引用时必须标注"非法律依据，仅供实务参考"，语气为建议性。
> 来源：基金会中心网（CFC）公开的 FTI2025 规则与指标体系、《中国基金会透明度观察报告(2025)》。
> 核对日期：2026-09-17。

---

## 一、FTI 是什么

- 全称 Foundation Transparency Index，**基金会中心网**与**清华大学廉政与治理研究中心** 2012 年联合开发。
- 反映基金会**自律透明与信息公开水平**的第三方综合指标系统；满分 100；每年发布一次，以榜单呈现。
- 设计依据：《慈善法》《慈善组织信息公开办法》《基金会信息公布办法》。
- 四维度：**组织 / 财务 / 项目 / 募捐**。
- 回答四个问题：**谁在管理？钱从哪儿来到哪儿去？在做什么？做的事情有什么用？**
- 核心原则：**"立足法规底线，倡导卓越发展"**。
- 指标与算法**完全公开**，系统基于客观数据自动计算。
- 覆盖范围：**仅基金会**（公募与非公募；含非慈善组织的基金会）。社会团体、社会服务机构不在 FTI 观测范围内——**这类机构不要套用 FTI**。

## 二、双阶段结构（FTI6.0，2024 年起）

| | 基础扫描 | 进阶观测 |
|---|---|---|
| **对象** | 全体基金会 | 通过基础扫描 + 满足准入条件者 |
| **渠道** | 慈善组织 → **慈善中国**；非慈善组织 → 民政部门相关网站 | **年度工作报告 / 官网 / 微信公众号** |
| **观测内容** | 依 81 号令**第四、五、六、八、十条**：基本信息、年报、公开募捐及相关项目 | 33 个三级指标（部分表述为 35 项信息） |
| **价值定位** | 帮助机构达到信息公开**基础要求** | 帮助机构成为信息公开**典范** |

### 基础扫描指标数量

| 机构类型 | 指标数 |
|---|---|
| 公募基金会（慈善组织） | **20 个** |
| 非公募基金会（慈善组织） | **15 个** |
| 非慈善组织基金会 | 至少公开上一年度年报 |

### 一票否决

观测期间因**"信息公开"相关原因**被列入活动异常名录或严重违法失信名单的（以全国社会组织信用信息公示平台为准），**基础扫描直接不通过**。

### 进阶观测准入（满足任一，通过基础扫描后自动纳入）

1. 在民政部登记注册的**全国性**基金会；
2. **公募**类型或具有公开募捐资格，且当年度公益支出不为零；
3. **大规模**：上一年度总收入、净资产、公益支出三项均排名全国**前 1000**；
4. **持续透明**：最近三年 FTI 均为 100 分。

其余机构可在通过基础扫描后**自主报名**（限额 100 家，先到先得）。

### 计分与评分等级

- 总分 100，由指标是否披露、权重、披露渠道、完整度参数综合计算（历史版本公式：`FTI = Σ(Ti × Wi × Si × Ci)`，其中渠道系数 `Si` = 官网 1.2 / 其他渠道 0.8，即**官网披露得分更高**——这是"为什么必须建官网披露页"的直接原因）。
- 等级徽章：

| 分数 | 徽章 |
|---|---|
| 60 ≤ FTI < 80 | 铜 |
| 80 ≤ FTI < 95 | 银 |
| **FTI ≥ 95** | **金色徽章** |
| < 60 | 不通过 |

## 五、FTI 四条使用禁忌

1. **FTI 分数不是合规结论**。它只观测"是否公开"，不评判内容真实性与质量——**FTI 只能保证观测到的数据是真的，无法确保数据本身真实**。
2. **透明 ≠ 好**。高分不等于机构运作优良，**不得**用作机构整体评价或背书。
3. **年度分数锁定后不再更改**，但机构在慈善中国与官网补齐的信息对公众**实时可见**。因此"当年度分数低"不等于"现在还是低"，报告须写明观测时点。
4. **不是所有机构都被观测**。FTI 只覆盖基金会；基金会以外的慈善组织不能套用 FTI 指标，也不要说"你们的 FTI 分数"。

## 六、FTI 导向的补齐优先级（可直接用于整改方案）

按"公开率低 × 分值权重高"排序：

| 优先级 | 补什么 | 依据 |
|---|---|---|
| 🔴 P0 | **重要关联方信息** | 全指标公开率最低 |
| 🔴 P0 | **官网年报 + 审计报告** | 权重最高（各 20 分），且超 1/3 机构未做 |
| 🟠 P1 | **理事会/监事会成员信息及背景** | 信息公开率 70% 上下但颗粒度不足（只有名字、没有面貌） |
| 🟠 P1 | **薪酬前五 + 四项费用标准**（公募机构） | 公开率仅 37% / 53% |
| 🟠 P1 | **项目成效评估** | 仅 61% 机构公开至少 1 个，行业最大短板 |
| 🟡 P2 | **信息公开荣誉 + 等级评估结果 + 税前扣除资格** | 分值各 5，易补 |
| 🟡 P2 | 避免"项目支出占比系数异常" | 年报须覆盖**全部**项目支出，不能只写"代表性项目" |

### 官方推荐动作路径

1. 打开 FTI 自测系统（`fti.foundationcenter.org.cn`）检视指标完成情况；
2. 回慈善中国补齐缺项；
3. 编制年报时多问一句"**有没有讲清楚**"；
4. 特别是**把官网建成真正的披露渠道**，不要只依赖第三方平台（官网渠道系数 1.2 > 其他渠道 0.8）。
