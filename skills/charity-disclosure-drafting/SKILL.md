# 慈善组织信息公开起草与发布

本技能聚焦"对外披露文本"产出：套模板生成年报、项目、募捐三类公开稿，自动对齐应当公开的法定要素与依据。适合要写/改机构对外披露文本的需求。

## 何时用本包
- 写年度工作报告（年报）公开稿
- 写慈善项目信息公开稿
- 写公开募捐情况公开稿
- 把已公开内容整理成规范披露文本

## 本包含什么
| 文件 | 用途 |
|------|------|
| `references/spine/legal-basis.md` | 法定依据速查（写稿时对照条款） |
| `references/spine/three-tier-checklist.md` | 事项与标准库（写稿前确认该事项的法定要素） |
| `references/spine/platform-rules.md` | 平台发布规则 |
| `references/spine/deadlines-and-thresholds.md` | 时限与阈值 |
| `templates/01-disclosure-checklist.md` | 信息公开全清单（分层版·61 项），写稿前对照应披露要素 |
| `templates/03-annual-report-draft.md` | 年度工作报告公开稿 |
| `templates/04-project-disclosure-draft.md` | 慈善项目信息公开稿 |
| `templates/05-fundraising-disclosure-draft.md` | 公开募捐情况公开稿 |

## 关键作业步骤
1. **定事项与要素**：先读 `templates/01`，确认本次要披露的法定要素
2. **套模板起草**：`templates/03/04/05` 按文稿类型选
3. **对齐依据**：引用 `references/spine/legal-basis.md` 条款号，落实三层写法
4. **核条款**：超出 references 覆盖范围必须联网核对原文后再落笔

## 本包必守铁律
1. **条款号不得凭记忆书写**；81 号令条文号以 `three-tier-checklist.md` 总表为准，61 号令已作废。
2. **三层不得混编**：L1 写"应当"、L2 写"平台要求"不写"依法"、L3 写"建议"不写"应当"。
3. **效力分层**：只有法律/行政法规/部门规章/政策文件/政府公告可作正式义务依据；其余只能作参考并标注"非法律依据，仅供实务参考"。
4. **客观陈述、零对话痕迹**：正文不写"你记忆中""上一版漏了""本轮修改"等；只客观陈述事实。仅"怎么用"类小节可留"如果你是…"。
5. **不得编造数据、案例、处罚结果**；缺失信息写"待核实"或"未检索到明确依据"。
6. **机构名称必须用登记全称**。
7. 每次交付末尾附免责声明：本成果为合规参考，不构成正式法律意见。
