## 一先分清三层"位置"

一进慈善组织，最容易晕的是"叫法"。同一个机构可能被叫三四种名，同一个人也可能被叫三种。先分开，后面才不乱。

#### 机构本身的称法（口语常混，含意有差）

| 说法 | 指的是什么 |
|---|---|
| 公益组织 / 公益机构 | 口语词，范围最宽。泛指做公益的各类主体，不严格区分类型。不是法律术语。 |
| 社会组织 | 政策文件里的统称，指社会团体、基金会、社会服务机构这几类。是统称，不是法律定义。 |
| 慈善组织 | 有明确定义，且需要认定。依法成立、以面向社会开展慈善活动为宗旨的非营利性组织。它是一种"属性"，不是第四种组织形式。 |
| 基金会 / 社会团体 /社会服务机构 | 三种组织形式。登记时选一种。登记证书上写的是这个。 |

口头常说混的三组，一次说清：

① "公益"和"慈善"——日常几乎可以互换；法律上边界清楚：慈善活动受《慈善法》规范、要有慈善组织资格；一般公益活动（社区志愿服务、环保宣传等）不一定受《慈善法》直接规范。

② "公益组织"和"慈善组织"——前者是口语泛指，后者是认定来的身份。说自己机构是"公益组织"没问题，政策文件里对应的词是"社会组织"或"慈善组织"。

③ "公益机构"和"基金会"——基金会是公益机构的一种，不是同义词。

#### 组织内部的三层

| 层 | 是什么 | 举几个 |
|---|---|---|
| 法定角色 | 法规或条例里写死的，名称全国统一，不能自己改 | 理事、理事长、副理事长、秘书长、监事、监事长 |
| 治理机构 | 由法定角色组成，管"谁拍板、谁干活、谁监督" | 理事会（决策）、秘书处（执行）、监事（会）（监督） |
| 内设部门与岗位 | 机构自己设的，叫法五花八门，法律不管名字 | 办公室（综合办）、项目部、筹资部、传播部、财务部…… |

一句话记住关系：法定角色是"身份"，治理机构是"三个机构各管一摊"，内设岗位是"活落在谁头上"。

一家机构可以只有 3 个人，也可以有 300 个人——法定角色一个都不能少，内设岗位可以一人兼几个。

### 三类组织形式下的角色差别

| 维度 | 基金会 | 社会团体 | 社会服务机构 |
|---|---|---|---|
| 最高层 | 理事会（5–25 人） | 会员大会 / 会员代表大会 | 理事会，或举办者 |
| 负责人 | 理事长、副理事长、秘书长 | 会长 / 理事长等 | 法定代表人 / 负责人 |
| 有无会员 | 无 | 有（个人或单位会员） | 无 |
| 典型 | ××基金会 | 协会、学会、商会、研究会 | 民办学校、民办医院、社工机构 |
| 登记证书上写 | 基金会 | 社会团体 | 民办非企业单位 |

关于"社会服务机构"和"民办非企业单位"：这两个名指的是同一类机构——"社会服务机构"是政策文件里用的名，"民办非企业单位"（俗称"民非"）是登记条例和登记证书上的名，官方常并列写成"社会服务机构（民办非企业单位）"。办手续、填表以证件上写的为准。

## 二分清四种规格：必须 / 要求 / 常规 / 可选

这一节为后面所有内容定规矩。同样一件事，有的错不得，有的只是习惯；混起来会白紧张，也会真踩线。

| 规格 | 含义 | 办错了会怎样 |
|---|---|---|
| 必须 | 法规明文规定的硬要求，没有余地 | 年检年报结论受影响、行政处罚、资格被取消 |
| 要求 | 法规或规范性文件有要求，但表述留了口子，或有条件、有例外 | 通常要说明情况、限期整改，严重的同"必须" |
| 常规 | 行业普遍这么做，法规没强制。不做不失分，但会被问 | 一般不影响合规，影响的是"经不经得起看" |
| 可选 | 机构自己决定，看规模和需要 | 不影响合规 |

为什么要分这四级。小机构最容易被"看起来像规定"的习惯绑住，也最容易把真正的硬要求当成"惯例"忽略掉。"理事长必须是法定代表人"是"必须"；"副理事长设几个"由章程定；"监事不能由理事兼"是"必须不行"。

还有一条要分清：登记事项 与 备案。这两者不是一回事——

· 变更登记：只针对登记事项（名称、住所、类型、宗旨、业务范围、原始基金数额、法定代表人）。

· 备案：理事、监事、负责人（除法定代表人外）的变更，一般按规定报登记管理机关备案，有业务主管单位的先经其同意。

· 另外：换届和更换法定代表人之前，应当先做财务审计。

· 因为登记事项是印在法人登记证书上的，所以变更之后要换领新的证书。改名、搬地址、调业务范围、换法定代表人，都属于这一类——要经理事会决议、有业务主管单位的先经其同意，再报登记管理机关审批并换证。

## 四决策机构：理事会

先说机构本身，再说机构里的人。

 理事会（决策机构）

 
 法定决策机构5–25 人

 
#### 它的定位

 理事会就是基金会的决策机构。章程谁定、负责人谁选、预算谁批、重大事项谁点头，都在这。它不向任何出资人负责——慈善组织没有股东，理事会向章程宗旨和捐赠人负责。

 人数：基金会 5–25 人；社会服务机构理事人数一般为 3 至 25 人。

 法规里没有"必须是单数"的硬规定，但实务中多数机构会取单数——因为表决时能减少票数对等的僵局。

 
#### 它的职权（章程规定的，法定归它的）

 
 - 决定机构的重大事项：修改章程、选举或罢免理事长／副理事长／秘书长、章程规定的重大募捐与投资活动、分立合并

 - 审议年度工作计划、预算与决算

 - 审议年度工作报告与财务会计报告（年报数据须经它审议）

 - 决定机构的内部机构设置、制度制定

 
 
#### 它怎么开会（这几条是硬要求）

 
| 事项 | 规则 |
|---|---|
| 开会频次 | 每年至少 2 次 |
| 出席人数 | 须有 2/3 以上理事出席才能开 |
| 一般决议 | 出席理事过半数通过 |
| 重大事项 | 章程修改、选举罢免负责人、重大募捐投资、分立合并 —— 须出席理事 2/3 以上通过 |
| 表决方式 | 一人一票；民主选举、民主决策，理事长（会长）末位表态，对不同意见应予记录 |
| 通知时限 | 一般会议提前 5 日、决议重要事项提前不少于 7 日书面通知（章程示范文本口径，各地要求可能不同） |
| 记录 | 制作会议记录，由出席理事审阅、签名；反对意见应记入记录 |

 
 为什么会议记录这么要紧 —— 两层原因：

 ① 决议效力：程序不合规，决议可能被质疑；未按规定办理的在法律上站不住。

 ② 理事的个人责任：决议违反法律法规或章程、给机构造成损失的，参与决策的理事要承担相应赔偿责任；但在表决时明确反对、并记载于会议记录的，可以免责。

 ——所以记录不只是"留痕"，它是保护人的东西。
 

 
 还有一条容易被忽略：机构的人、财、物、活动中按规定由会员大会（如有）或理事会决策的事项，不得由个人专断，也不得用"理事长办公会"之类的形式代为决策。
 

 

 理事（角色）

 
 5–25 人每届任期不超过 5 年，可连任

 属于：理事会 ｜ 由谁产生：第一届由业务主管单位、主要捐赠人、发起人分别提名并共同协商确定；之后按章程

 
#### 他/她要做的六件事

 
 - 到会。出席理事会，这是最基本的履职。长期不到会，本身就是问题。

 - 表决。一人一票，对议题投出自己的一票。

 - 审议与签字。审阅会议记录、年度工作报告与财务报告，签字确认。

 - 担责。决策失误造成损失的，参与决策的要担责任——这是权利背后的代价。

 - 提供资源。不是强制，但实务中理事往往带来捐赠、带来社会资源链接、带来渠道。这也是机构请他们来的原因之一。

 - 提思路、做建议。对机构方向、项目规划、发展路径提意见。理事不只是"举手的人"。

 
 
#### 要遵守的几条界限

 
 - 任职回避：遇有个人利益与机构利益关联时，不得参与相关事宜的决策。

 - 不得与本机构交易：理事、监事及其近亲属，不得与其所在的基金会有任何交易行为。

 - 领酬限制：在机构领取报酬的理事，不得超过理事总数的 1/3；未在本机构担任专职工作的理事，不得获取报酬。

 - 近亲属限制（容易忽略，但很硬）：
 
| 机构类型 | 规则 |
|---|---|
| 用私人财产设立的非公募基金会 | 相互间有近亲属关系的理事，总数不得超过理事总数的 1/3 |
| 其他基金会（公募、以及非私产设立的非公募） | 具有近亲属关系的，不得同时在理事会任职 |

 

 
 人少的时候：理事人数不能低于 5 人，这条不能合。但一个人可以同时具有多重身份：既是主要捐赠人代表，又是行业专家。要注意的是上面那条近亲属限制——安排理事人选时先查一遍。

 

 理事长

 
 必须是法定代表人不得兼任其他组织法定代表人最高任职年龄一般不超过 70 周岁

 属于：理事会 ｜ 由谁产生：从理事中选举产生

 
#### 做什么

 
 - 召集和主持理事会（这是法定职责）

 - 代表机构对外签署重要文件、参加重大活动

 - 以法定代表人身份对机构整体行为负责

 - 机构内部出现矛盾时，充分协调各方、及时组织召开会议推动达成一致；本人不能正常履职的，按章程程序推举一位负责人召集

 
 
#### 资格上的硬要求（分三层看清）

 
| 项 | 要求 |
|---|---|
| 法定代表人 | 理事长就是基金会的法定代表人（这是条例明文，不是惯例） |
| 兼任限制 | 不得同时担任其他组织的法定代表人 |
| 国籍 | 公募基金会和原始基金来自中国内地的非公募基金会的法定代表人，应当由内地居民担任；其他情形可由港澳台居民或外国人担任，但每年在中国内地居留时间不得少于 3 个月，且一般须为中国公民（以登记机关口径为准） |
| 年龄 | 负责人最高任职年龄一般不超过 70 周岁（登记实务要求；超龄超届也是年检关注点） |
| 身份 | 不得由现职国家工作人员兼任（行政机关工作人员一律不得担任负责人） |

 
#### 四种人不能担任负责人（理事长／副理事长／秘书长）

 
 - 属于现职国家工作人员的

 - 因犯罪被判处管制、拘役或有期徒刑，刑期执行完毕之日起未逾 5 年的

 - 因犯罪被判处剥夺政治权利正在执行期间，或曾经被判处剥夺政治权利的

 - 曾在因违法被撤销登记的基金会担任理事长／副理事长／秘书长，且对违法行为负有个人责任，自该基金会被撤销之日起未逾 5 年的

 
 
#### 容易踩的

 
 - 换理事长属于变更登记（法定代表人变更），必须办；且更换法定代表人之前应当先做财务审计。

 - 法定代表人任期内机构出现违法行为，法定代表人要担责；因失职造成财产损失的，要担个人责任。

 
 人少的时候：理事长通常不驻会（不在机构坐班），日常事由秘书长执行——这是常态，不是问题。但"不驻会"不等于"不履职"：该主持的会要开、该签的字要签、该担的责要担。

 

 副理事长

 
 应当设置一般 1–2 名分管什么由章程定

 属于：理事会 ｜ 由谁产生：从理事中选举产生 ｜ 是负责人三人之一

 
#### 做什么

 
 - 协助理事长工作，按章程分工分管某一方面（如项目、财务、对外联络等）

 - 理事长缺位时，按章程规定代行其职责

 - 在分管范围内对理事会负责，向理事长和理事会报告分管事项的进展

 - 出席理事会，与理事同样行使表决权

 
 
 关于设置：副理事长是负责人之一，应当设置。设几名、分管什么，由章程决定，一般 1–2 名。有些地方（如北京）在登记时明确要求有副理事长，以便三个负责人齐全。

 关于兼任：法规明文禁止的是"理事长与秘书长不得由同一人兼任"（决策与执行要分开）。副理事长兼任秘书长，法规并未禁止，实务中确实有机构这样安排——章程里写清即可。
 

 

## 五监督机构：监事（会）

先纠一个容易写错的地方：监事（会）不属于决策层。它是独立的监督机构——不归理事会管，也不归秘书处管。三者关系是：理事会决策、秘书处执行、监事（会）监督，各自向章程负责。

 监事 / 监事会（监督机构）

 
 不得由理事、理事近亲属、执行机构负责人、财会人员兼任不得领取报酬

 属于：监事（会） ｜ 由谁产生：由发起人、主要捐赠人选派；也可由业务主管单位、登记管理机关选派

 
#### 先分清"监事"和"监事会"

 
| | 怎么设 | 人数 |
|---|---|---|
| 监事 | 规模小的机构可以只设监事、不设监事会 | 至少 1–2 名 |
| 监事会 | 有 3 名以上监事的，应当设监事会 | 3 至 7 人，取单数，具体由章程定 |

 
 两条硬要求，记牢：

 ① 具有公开募捐资格的慈善组织，应当设立监事会。

 ② 在省级以上民政部门登记的基金会，也应当设监事会。

 反过来说：不是所有机构都必须设监事会；但只要监事到了 3 个人，就必须设。
 

 
#### "独立性"到底要求到什么程度（这是监事最要紧的一条）

 法规明文排除的兼任对象是：

 
 - 理事（自己不能监督自己的决议）

 - 理事的近亲属（一家人的独立性靠不住）

 - 执行机构负责人（即秘书长——不能监督自己执行的事）

 - 财会人员（不能监督自己做的账）

 
 
 还有一条更硬、也更容易被忽略：理事、监事及其近亲属，不得与其所在的基金会有任何交易行为。

 也就是说，监事不仅不能是上述那几种人，本人及近亲属也不能与本机构有生意往来。

 实务中登记管理机关对"独立性"的把握，还会往"不得是本机构工作人员、不得与本机构存在其他关联关系"这个方向靠——从严理解比从宽安全。
 

 
#### 监事不领报酬

 监事和未在本机构担任专职工作的理事，不得从基金会获取报酬。注意这条比"不领工资"更宽：以劳务费、专家费、咨询费等任何名义领取，都不行。

 
#### 监事长（设监事会才有）

 
 - 设 1 名，由监事会选举产生和罢免（全体监事过半数通过）

 - 职责：召集并主持监事会会议；决定是否召开临时监事会；检查监事会决议的实施情况；签署监事会的决议和建议；代表监事会向理事会、主要捐赠人或公众发布监事会年度工作报告

 

 
#### 监事会怎么开会（监事最该看的这一节）

 
| 事项 | 规则 |
|---|---|
| 开会频次 | 每年至少召开 2 次 |
| 出席人数 | 须有 三分之二以上监事出席方可召开 |
| 表决 | 一人一票；决议须经全体监事过半数通过才有效 |
| 谁来召集主持 | 监事长 |
| 记录 | 应制作会议记录；形成决议的当场制作会议纪要，出席监事签名确认。监事的反对意见应当记入记录 |
| 留档 | 监督检查记录、会议记录、会议纪要要妥善保管、留档保存 |

 
#### 监事（会）具体能做什么

 
 - 按章程规定的程序检查财务和会计资料；每年至少 2 次检查财务情况

 - 监督理事会遵守法律法规和章程的情况

 - 监督负责人、理事、财务管理人员的职务行为

 - 列席理事会会议，监督会议程序和决议的合法性，有权向理事会提出质询和建议

 - 对违反法律法规、章程或理事会决议的负责人，提出罢免的建议

 - 当负责人的行为损害机构利益时，要求其纠正

 - 提议召开临时理事会会议；理事会不履行召集职责时，可召集并主持

 - 履行（监督）信息公开职责

 - 向登记管理机关、业务主管单位以及税务、会计主管部门反映情况

 - 对公益项目实施情况可以实行全程监督

 

 
#### 怎么提意见：三种正式方式

 
 - 当场质询——列席理事会时口头提出，须记入会议记录

 - 书面意见——形成书面意见提交理事会；年报里的监事意见就是正式的书面出口

 - 直接反映——向登记管理机关、业务主管单位、税务或会计主管部门反映情况

 

 
#### 监事应具备什么

 
 - 应具备财务、会计、审计、法律等方面的专业知识和工作经验，或有保护机构资产安全与相关者利益的能力

 - 任期与理事相同，届满可以连任

 

 人少的时候：小机构至少设 1 名监事，但不能从理事、秘书长、财会人员里找人兼，也不能找他们的近亲属。常见做法是从外部请一位：同行、退休财务、律师、主要捐赠人代表。监督的人和干活的人，必须是两拨人；而且监事不领报酬，这一点要在请他/她就说清楚。

 

## 六执行机构：秘书处与秘书长

 秘书长

 
 负责人之一必须专职从理事中产生

 属于：秘书处 ｜ 由谁产生：从理事中选举产生（修订草案拟允许聘任制）

 
#### 做什么

 
 - 全面主持秘书处日常工作，落实理事会决议

 - 制定年度工作计划与预算方案，定期向理事会汇报执行情况、资金运用情况、人员调配及其他重大事项

 - 管理秘书处团队；对接民政部门，完成年检／年报、等级评估与合规督查

 - 主导筹资与捐赠维护；统筹项目、传播、风控与财务合规

 - 建立内部沟通渠道与工作机制，健全制度与流程

 

 
 "秘书长要不要专职"——结论是必须专职，不是"一般"。

 ① 《基金会章程示范文本》第二十三条（二）已经把"秘书长为专职"写进负责人的条件，登记机关核准章程时按此把关，实务中通常还要签专职承诺书。这是全国统一口径，不是某一地的土政策。

 ② 具有公开募捐资格的慈善组织，秘书长必须专职——《慈善组织公开募捐管理办法》第五条把它列为申请公开募捐资格的必备条件，全国适用。

 ③ 修订草案进一步明确：秘书长可以实行聘任制（不从理事中选举产生），但具有公开募捐资格的基金会秘书长应当为专职。

 那"有的地方宽一点"是怎么回事？是实际执行的松紧差异，不是法规不要求。照"必须专职"来做最稳；拿不准的以本机构登记机关的现行口径为准。

 

 
#### 容易踩的

 
 - 理事长和秘书长不得由同一人兼任（决策与执行要分开）

 - 不得由现职国家工作人员兼任；最高任职年龄一般不超过 70 周岁

 - 秘书长变更属于负责人备案事项（不是登记事项变更），要按要求报登记管理机关；有业务主管单位的先经其同意

 

 人少的时候：小机构的秘书长常常就是实际的"管家"，什么都要过手。这时更要守住一件事——该理事会决定的事必须回理事会，秘书长不能自己拍。

 

 执行秘书长（部分机构设，非法定角色）

 
 机构自设不是法定角色，法规里没有这个名称

 
#### 它出现的两种情形（很不一样）

 
| 情形 | 什么情况 | 执行秘书长做什么 |
|---|---|---|
| 一、秘书长挂名 | 秘书长是挂名的（可能是资源型、名义上的），日常管不了 | 几乎所有实际工作都由执行秘书长做。秘书长的角色主要在签字、承担责任、对外报备这一类"名义上的动作" |
| 二、大机构分工 | 机构大了，或者秘书长偏对外（管大局、引资源、代表机构露面） | 承担日常运营的具体一块或全部：团队、项目、制度、合规这一类 |

 可以类比企业的 董事长 / CEO 与 执行 CEO，或者 CEO 与 COO：一个定方向、一个保运转。

 
 用这个岗要注意三件事：

 · 登记材料、年报、公开信息里，负责人只能写理事长三人（理事长、副理事长、秘书长），不能把执行秘书长、副秘书长填上去；

 · 内部可以设，但职权要写进章程或内部制度，否则出了争议没有依据；

 · 如果实际行使秘书长职权，责任归属要提前说清。
 

 别想当然以为"人少就用不上"：有的机构就五六个人，照样会有执行秘书长——因为秘书长本人是挂名的。这个岗跟机构规模没有必然关系，跟"秘书长实际管不管事"有关系。

 

 副秘书长（部分机构设，非法定角色）

 
 机构自设法规里没有这个名称

 
#### 做什么

 
 - 多数情况：分管一块——分管项目、传播、行政等某一条线，是部门之上的一个层级；对秘书长负责，报告分管事项的进展。

 - 少数情况：承担实际上的日常管理——当秘书长和执行秘书长都偏对外时，日常那块可能落到副秘书长身上。

 - 秘书长缺位或授权时，在授权范围内代行部分职责。

 - 跨部门协调：分管范围内涉及多个部门的事，由他来推。

 
 
 它和执行秘书长的关系：层级上，执行秘书长一般略高于副秘书长——因为执行秘书长通常管全局或接近全局，副秘书长多数是分管一块。这是常规情形，具体以各机构自己的设置为准。

 使用注意（和执行秘书长一样）：登记材料、年报、公开信息里，负责人只能写理事长三人，不能把这两个岗填上去；内部可以设，但职权要写进章程或内部制度。
 

 

### 秘书处下面的活，分成哪几块

内设部门叫什么名字各机构不一样（办公室、综合办、综合部、行政部……），但活是同一套。按职能分七块，一块都不能缺：

| 职能块 | 具体做什么 |
|---|---|
| 文秘机要 | 公文、档案、印章、证照、会议、信息公开文书、新闻发布 |
| 人事行政 | 招聘、劳动合同、考勤、薪酬福利、绩效、培训、离职 |
| 治理支持 | 理事会／监事会会议组织、换届、负责人任职合规、党建 |
| 规章制度 | 制度起草、审议、归档、修订 |
| 对外联络 | 民政部门、业务主管单位、捐赠人、政府购买、涉外事项 |
| 后勤信息化 | 办公环境、设备车辆、用品、系统与账号权限 |
| 财务衔接 | 报销初审、票据管理、配合预算与资产台账 |

但秘书处不只是"这七块各干各的"。秘书长这一层的作用，其实有四种——分清这四种，才知道"秘书长到底在干什么"：

① 主责做——有些事就在秘书处这一层办（人事、公文、印章、制度）；

② 分管——把七块分给部门，自己盯结果（分给谁、什么时候交、交成什么样）；

③ 串联——跨块的事它接。比如一个项目要报年报，项目、财务、办公室三边都得对上，这个"对上"的动作通常落在秘书处；

④ 引领——方向、节奏、对外口径、风险判断。这层不完全"做事"，而是让整件事往对的方向走。

机构小的时候，这四种常常是同一个人在做。

 办公室（综合办）—— 一个容易被低估的部门

 
 叫法因机构而异规模大才独立成部

 属于：秘书处 ｜ 承接上表七块职能里的大部分

 
#### 为什么单说它

 在小机构，办公室就是"除了业务和财务，其他都是它"。而在规模大的机构、尤其是国字头的大型基金会，办公室会明显变大、变重——一个原因是有事业单位的管理惯性，另一个原因是这类机构的对外事务、会议、文件量本来就大。

 
#### 大型机构的办公室，往往承担这些

 
 - 人事、行政、考勤

 - 理事会与监事会的会议组织与档案

 - 公文、印章、证照、档案

 - 审核审批的流转

 - 后勤、采购、固定资产

 - 对外联络与接待

 
 一句话记住它的边界：业务部门管"做项目"、财务部门管"钱"、筹资部门管"募"——除此之外的，基本都归办公室。至于"传播（说）"归不归它，要看机构怎么设岗：有的机构传播是独立部门，有的就放在办公室里。

 

## 七业务线：项目、筹资、传播与外联

 项目官员 / 项目经理

 
 多数机构的核心岗位

 属于：项目部（有的叫项目办、公益部）

 
#### 做什么

 
 - 全周期管理：立项、执行、过程监测、成效评估、结项

 - 受益人管理：需求调研、名册建立、资格审核、触达与反馈

 - 项目执行：预算执行、采购与物流、物资发放、活动组织

 - 资料与归档：项目数据整理、受益人信息统筹、合规审查、资料归档

 - 合作方对接：与政府、企业、其他机构、医院、学校、社区等日常沟通协调

 - 报告：执行报告、进展反馈、结项报告

 - 传播配合：提供素材（照片、案例、故事），配合做内容

 
 
#### 最容易出问题的地方

 
 - 花了钱没留痕——每次发放、每次走访都要有记录

 - 预算科目和决算对不上——执行时随手改科目，结项时对不上账

 - 受益人名册不全或信息不实——这是检查最看重的一环

 - 合作方是关联方却不知道——要先识别、再走程序

 
 人少的时候：项目官员常常同时兼传播和筹资配合——没有单独岗位时，项目素材由他整理、项目故事由他写、发之前发给办公室或秘书长审定。关键动作是"发之前要有人审"。

 

 筹资 / 募捐与合作（含外联）

 
 对外和对内的活不一样

 属于：筹资部、合作发展部（有的并入项目部或办公室）

 
#### 这条线其实有三块

 
| | 要做什么 |
|---|---|
| 对外募 | 面向公众、企业、基金会、政府：募捐方案、活动策划、平台上线、大额捐赠洽谈、企业 CSR 对接、政府购买服务申报 |
| 对内管 | 捐赠人维护与反馈、捐赠票据衔接、财务对账、项目进展回传、平台结项与财批 |
| 外联 | 与政府部门、行业机构、同行、媒体的日常联络与关系维护；政策信息获取；参与行业交流 |

 
#### 还要分清"公开"和"非公开"

 
 - 公开募捐——必须先取得公开募捐资格；方案要报民政部门备案；互联网公开募捐要在民政部指定的平台做

 - 定向募捐——面向特定对象，不需要公开募捐资格，但也不能超出特定对象范围

 
 
 做网络募捐，还要额外懂"平台规则"。各家互联网募捐平台的规则、节奏、年度活动安排都不一样（比如某些平台的年度大型活动，一年一次、规则很细），很多机构会专门安排人研究平台规则。这不是"发个链接"那么简单——它涉及上线资质、文案规范、进展更新频率、财批、结项、审计。
 

 
#### 最容易踩的线

 
 - 没有公开募捐资格，却自己搞公开募捐——这条线不能碰。想参与，只能和有资格的机构合作，由对方开展，自己不得以任何形式自行募捐

 - 合作募捐没有书面协议、没在对方募捐方案里载明合作方信息

 - 捐来的款物没纳入有资格那一方的账户统一管理核算

 
 人少的时候：筹资常由秘书长直接牵头、项目官员配合——大额捐赠往往需要负责人出面。

 

 传播 / 品牌官员

 
 越做越吃专业

 属于：传播部、品牌外联部（有的归办公室）

 
#### 做什么

 
 - 内容生产：官网、公众号、视频号、小红书等渠道的内容策划与运营

 - 活动传播：线上线下公益活动的策划、组织与传播

 - 稿件撰写：日常传播稿、项目故事、活动纪实

 - 素材统筹：与项目部门对接，收集照片、视频、案例

 - 媒体与投放：广告投放、媒体对接、新闻发布配合

 - 品牌：统一视觉与口径，维护品牌形象

 
 
#### 这个岗位会越做越专业

 新人做传播，可能只是排版、发文。做得久了，要具备的能力会变成这些：懂不同平台的玩法差别、懂内容节奏、懂一点社会心理（什么话公众听得进去）、懂舆论传播的规律、懂合规（什么能说什么不能说）。

 人少的时候：没有专职传播岗时，通常由项目官员供稿、办公室或秘书长审定发布。统一口径这条不能省——对外只能有一个出口。

 

### 关于岗位名称：叫法真的很乱，看职责就行

慈善组织的岗位命名还没有商业公司那么统一。同一个活，不同机构叫法差很多：

| 层级感 | 常见叫法（同一件事的不同名字） |
|---|---|
| 部门负责人 | 项目部部长 ／ 部门主任 ／ 总监 ／ 高级经理 |
| 中层 / 骨干 | 项目经理 ／ 项目主管 ／ 项目办负责人 |
| 执行层 | 项目专员 ／ 项目官员 ／ 项目助理 |

还会有一些"非标准"的岗位名。比如综合岗（什么都要做一点）、创新岗（做新项目、新渠道试点）、专项岗（只跟一个专项基金或一个大项目）。这些名字在商业公司里少见，但在公益机构里很正常——因为人少、事杂。

判断办法很简单：不看名字，看职责描述。岗位说明里写"负责××的全流程"就是项目类；写"负责××的推广与内容"就是传播类。圈内人看到名字，大致也就知道是干什么的了。

## 八财务线

财务这条线通常分三个岗：财务负责人（有的机构叫财务总监）、会计（有的叫总账会计）、出纳。三个岗做的事完全不同，下面分开写。

 财务负责人 / 财务总监

 
 3 年以上财务管理经验，有民非或基金会背景优先

 属于：财务部 ｜ 通常直接对秘书长负责

 
#### 做什么

 
 - 统筹全盘账务——确保严格遵循《民间非营利组织会计制度》核算，主导全盘账务处理

 - 编报——编制年度财务预算与决算报表及报告，定期出具财务分析报告，为管理层决策提供数据支持

 - 建制度、管流程——建立完善财务管理制度，优化财务审批流程，落实资金风险管控，健全内部财会监督与内控体系

 - 税务与政策——落实非营利组织免税资格、公益性捐赠税前扣除资格等相关政策；按期完成税务申报，确保税务合规

 - 资金与资产统筹——监控现金流、提高资金使用效率；配合闲置资金的合规保值增值

 - 把关三条费用比例线——慈善活动支出、管理费用、募捐成本，要在过程中盯，不能年底才发现超

 - 审计与检查——对接会计师事务所完成年度审计；配合主管部门的财务检查

 - 带人——对会计、出纳进行业务指导与监督，定期核查资金账目，确保账实相符

 
 最容易混的一件事：把"管理费用比例"和"工资两倍"当成一回事。前者来自民政部门的财政规定，后者来自税务的免税资格认定——依据不同、算法不同、管的人不同。

 

 会计 / 总账会计

 
 初级职称以上（中级优先）2–3 年以上

 属于：财务部

 
#### 做什么

 
 - 日常核算——审核原始凭证、编制记账凭证、登记会计账簿，确保账证相符、账账相符、账实相符

 - 报表——按时编制财务报表及报表附注，准确区分限定性净资产与非限定性净资产

 - 捐赠收入与票据——捐赠收入的确认、核算与对账；公益事业捐赠票据的申领、开具、保管及核销；实物捐赠按凭据金额或以公允价值入账

 - 资产与往来——固定资产、无形资产的账务处理与协助盘点；核对清理往来款项、推进催收与结算

 - 项目辅助核算——辅助专项基金及公益项目的核算，确保资金专款专用，为项目审计提供财务资料

 - 税务——按月／季度完成纳税申报与税款缴纳，协助整理税收优惠备案资料

 - 薪酬与社保——员工薪资核算、社保与公积金增减员及缴费

 - 档案——会计凭证、账簿、报表的整理、归档、保管，执行档案借阅与工作交接流程

 - 配合审计——项目常规审计、专项审计、年度审计

 - 对外——对接捐赠人的财务咨询，如实反馈资金使用情况；配合财务信息公开

 - 配合监督——配合监事的财务监督检查

 - 配合年报——年度工作报告里财务部分的填报与核对

 
 最常出问题的地方：账、证、表对不上。多数是因为台账没及时登、或者凭证归集口径中途改过。

 

 出纳

 
 初级职称优先2 年以上出纳经验

 属于：财务部

 
#### 做什么

 
 - 资金收付——严格依据审批完备的单据办理现金、银行转账（含外币）的收付，确保支付零差错、零延误

 - 日记账——准确登记现金及银行存款日记账，日清月结；每月按时编制银行余额调节表

 - 账户业务——办理与银行的各类账户业务，维护银企关系

 - 票据开具——按规定开具公益事业捐赠票据、数电发票；及时确认到账资金并反馈至募捐部门

 - 项目资金拨付——按审批办理项目资金拨付，确保专款专用、留存完整凭证

 - 保管——保管财务印章、网银 U 盾、支票及有价证券，建立严格的领用核销登记台账

 - 社保公积金——办理申报与缴纳

 - 配合——协助会计完成月度结账、年度审计及民政部门的财务报告报送；配合公开募捐备案、慈善组织年报等合规工作；配合财务公开与捐赠人查询

 
 出纳和会计的边界（这条不能动）：会计不得兼任出纳；出纳不得兼管稽核、会计档案保管，以及收入、费用、债权债务账目的登记。机构主要负责人也不得兼会计、出纳。这不是不信任，是把关。

 

#### 实际配置：理想之外，常见这四种情况

· 没有专职财务——记账、报税整体外包给代理记账机构；机构内部只留票据初审和报销登记

· 一人兼两职——财务负责人与会计由同一人担任

· 出纳由他人兼——由行政、办公室人员兼，或干脆也交给代理记账

· 财务负责人由秘书长或执行秘书长兼——小机构里很常见

但底线不变（这几条不能合）：① 会计不得兼任出纳；② 出纳不得兼管稽核、会计档案保管和收入／费用／债权债务账目的登记；③ 机构主要负责人不得兼会计、出纳；④ 报表要有人签字负责。

财务上有两条线，很多人会混：

① 慈善活动支出、管理费用、募捐成本的比例——管"钱花在哪"，来自民政部门的财政规定。

② 工作人员平均工资不超过同类组织平均工资两倍——管"人拿多少"，来自税务的免税资格认定。

两者依据不同、算法不同、管的人不同。

## 九实习生：越来越多机构在用的一支力量

实习生做的事，本质上是"可以拆出来的那部分活"——把正式员工从重复事务里腾出来，去做判断和担责的事。所以给实习生的活，要能说清、能交代、能检查。

#### 常见的四个方向

| 方向 | 做什么 |
|---|---|
| 项目 | 走访与个案跟进；协助活动策划、筹备与现场执行；档案资料的整理、归档与保存；协助服务活动的评估与总结；在项目地开展服务活动 |
| 材料审核 | 配合项目负责人，按基金会标准流程对受助人申请材料做初步审核，确保材料完整、信息准确；电话沟通与电访调研、需求收集、项目进展反馈；项目档案分类归档与定期更新 |
| 行政 | 起草请示报告、会议纪要；协助会务工作、准备会议材料；文件归档、信息上传；协助办理内部审批流程；来访接待 |
| 传播 | 公众号、视频号、官网的日常运营维护与更新；撰写宣传文案、新闻通稿；活动现场采编、影像拍摄、后期剪辑；宣传素材库的搭建与管理；视觉物料设计对接 |

#### 通常的要求

 - 学历专业：专科／本科在读或以上；社会工作、公共管理、社会学、教育学、广告、传播、新闻、设计等专业优先

 - 时长：能保证连续实习（常见 3–6 个月、每周 3–5 天）；有留岗意向的优先

 - 技能：熟练使用 Word／Excel／PPT；传播方向要求会剪辑或设计软件

 - 态度：细致、有耐心、能沟通——这三个词在招聘启事里出现得最多

带实习生，有三件事要先说清（比教技能更重要）：

① 哪些能做、哪些不能做——比如可以整理受益人名册，但不能自己决定谁合格；可以写稿，但不能自己发出去；

② 做完了交给谁、谁检查——每件事都要有明确的验收人和验收标准，否则做完没人接；

③ 留痕的规矩——接触到的受益人信息、捐赠数据，怎么保存、能用在哪、不能带到哪。这一条从第一天就要讲。

## 十能外分的活，怎么分包、怎么选机构

能外分的坚决外分，这是小机构的生存方式。但外包不是"甩出去"，外包之后机构还要做两件事：把关和留痕。

| 工作块 | 常见处置 | 内部还要保留什么 |
|---|---|---|
| 财务（记账、报税、出报表） | 兼职会计 / 代理记账机构 | 票据初审、报销登记、对账 |
| 法律（合同审查、劳动合规、纠纷） | 外聘法律顾问（公益行业有低价或公益律师资源） | 合同台账、用印审批 |
| IT（网站、小程序、办公软件维护） | 外包或技术志愿者 | 账号与权限管理 |
| 审计、评估、专项申报 | 会计师事务所、评估机构 | 资料准备、口径确认 |

外包涉及花钱，所以走一遍比价。采购或选服务商时，做三方比价并留存比价记录，是常规的内控动作——一是把价格压到合理，二是将来有人问"为什么选这家"，拿得出依据。具体金额门槛和流程看本机构的财务制度。

#### 怎么选外包机构

 - 看资质——有没有执业资格，经营范围对不对得上（比如代理记账要有代理记账许可证）

 - 看熟不熟这行——做没做过社会组织。这一点很关键：慈善组织执行的是《民间非营利组织会计制度》，和企业会计不是一套，找错了机构，账做出来也用不了

 - 看能不能配合年检年报——很多外包机构只管记账、不管年报口径，最后还是要机构自己补

 - 合同写清——服务范围、交付物、时限、数据归属、保密条款

 - 留存过程记录——外包不等于不用留痕，机构的台账、对账单、交接记录仍要有

一个很实用、很多人想不到的办法：问同行。公益圈不大，谁家的记账做得好、哪家会计师事务所懂民非口径，同行心里都有数。而且这种评价通常比较中肯——好就是好，不好会直接说哪里不行。

比看广告、比看报价有用得多。

一条实操经验：外包机构承担的是技术活，不承担责任。报表签字、年报填报、数据核对的责任仍在机构（通常是秘书长和财务负责人）。所以外包之后，内部必须有一个"看得懂、签得下"的人——这个人可以是秘书长，也可以是外聘顾问。

## 十一一人多岗：在各个岗位上怎么合

慈善组织人少是常态。合的原则是三条，但具体怎么合，要看是哪个岗——所以下面分岗位说。

三条总原则：① 能外分的坚决外分 ② 能工具化的不靠人（考勤、审批、报销、档案、会议串成线）③ 能把文档写细的写细（让实习生照着也能办对）。

#### 三档配置

| 规模 | 怎么配 | 守的核心 |
|---|---|---|
| 一人版 | 1 名综合专员，秘书长统筹；财务、法律、IT、审计、评估全部外包 | 制度与合规档案、人事与劳动合同、印章证照、公文、会议记录、考勤汇总、薪酬核算衔接、对外对接 |
| 两人版 | A 岗「行政+人事」；B 岗「财务衔接+对外宣传联络」（或 B 岗专职财务，宣传由秘书长兼） | A 岗管文秘人事全流程；B 岗管报销初审、票据台账、预算配合、新媒体、捐赠人维护、政府事务 |
| 三四人版 | A 行政 ｜ B 人事 ｜ C 财务合规 ｜ D 宣传对外 | C 岗要额外盯：费用比例监控、年检年报填报、信息公开台账 |

#### 具体到每个岗，常见的合并方式

| 岗位 | 常见怎么合 |
|---|---|
| 监事 | 不能合。不得由理事、理事近亲属、秘书长、财会人员兼任。人少就从外部请一位（注意：监事不领报酬） |
| 副理事长 | 由理事兼任，不驻会；小机构可能只设章程规定的 1 名 |
| 秘书长 | 小机构里常常兼实际上的执行秘书长、兼筹资牵头人；但不得兼理事长 |
| 财务负责人 | 常见由秘书长兼、或与会计合并；也可能整个外包给代理记账。但不得兼出纳 |
| 出纳 | 由行政或办公室人员兼；或全部交代理记账。但经手钱的人不能同时管账，也不能兼管稽核和会计档案 |
| 项目官员 | 常兼传播（素材整理、写稿）、兼筹资配合（提供项目素材）。发稿前须有人审定 |
| 传播 | 小机构常无专职，由办公室或项目官员兼；对外口径仍要统一审定 |
| 办公室（行政人事） | 最常见的合并岗：文秘+档案+印章+会议+人事+考勤全归一个人 |

关于"机构大了会怎么样"——别把话说死。规模上去之后，确实常见综合办公被拆成办公室、人事部、财务部等几个部分，但拆不拆、什么时候拆，取决于实际需要和管理层的决定，没有"到多少人就必须拆"这条规定。

不过这七块职能始终是职责划分的蓝本：要拆的时候照着分，不会漏项。

## 十三各岗位通常要求什么

这一节给的是行业里公开招聘时常见的门槛，不是法规规定。用它来判断"这个岗位通常要什么样的人"，或者反过来——自己想往这个方向走，要补什么。

| 岗位 | 学历与专业 | 经验 | 看重的能力 |
|---|---|---|---|
| 秘书长 | 本科及以上，硕士常见 | 5 年以上管理经验，含 2 年以上基金会或大型社会组织中高层 | 全局观；熟悉《慈善法》与基金会监管规定；资源整合与政企对接；能操盘大型项目；团队管理；合规风控意识 |
| 执行秘书长 | 本科及以上 | 3–5 年以上运营管理 | 运营与流程能力强；能把制度落下去；对内管理多于对外 |
| 副秘书长 | 本科及以上 | 3 年以上 | 某一领域的专业能力（项目／传播／行政）；协调与执行 |
| 项目官员 /项目经理 | 本科及以上；社会工作、公共管理、社会学、新闻传播等优先 | 1–3 年；优秀应届生也有机会 | 项目全周期管理；调研与写作；沟通协调；能出差；细致 |
| 筹资 / 合作 | 本科及以上；市场营销、公共关系等优先 | 1 年以上；有筹资经验优先 | 方案撰写；谈判与维护关系；平台运营；数据意识 |
| 传播 / 品牌 | 本科及以上；新闻、传播、设计等 | 1–3 年；要能独立运营账号 | 内容与文案；短视频剪辑；对平台玩法和社会心理有感觉；合规意识 |
| 财务 | 财会专业，有会计职称优先 | 1–3 年；做过社会组织财务是加分项 | 熟悉《民间非营利组织会计制度》；懂费用比例口径；细致 |
| 办公室 / 行政人事 | 本科及以上；中文、行政管理、人力资源等 | 1–3 年 | 公文写作；流程与档案意识；沟通与协调；能托底 |
| 监事 | 不限，但要有财务、会计、审计或法律背景 | 不限 | 独立性；敢提意见；懂财务或法规 |

三个"越往上越重要"的能力：

· 写——项目方案、年度报告、合作协议、请示报告、对外口径，几乎每个岗位都要写

· 合规意识——不是"知道有规定"，而是做事之前先问一句"这个能不能做、要不要走程序"

· 协调——慈善组织的活几乎都要跨部门、跨机构，能推得动事比能自己做更重要

#### 想到这个岗位，先补哪几块

可以对着本站的板块看：想往秘书长走，治理、财务、资质三块都要熟；想往项目官员走，先熟项目全流程和留痕要求；想往财务走，先弄清三条费用比例线和《民间非营利组织会计制度》；想往传播走，先摸清信息公开的边界在哪。

说明　本页讲的是一般情形与常规状态下的职责划分，并尽量标注了每条要求的规格（必须 / 要求 / 常规 / 可选）。具体机构的部门设置、人员分工、章程规定各不相同，实际以本机构章程、理事会决议和登记管理机关的现行口径为准。涉及具体人事处置、行政处罚应对、重大决策时，请咨询执业律师或向登记管理机关确认。
