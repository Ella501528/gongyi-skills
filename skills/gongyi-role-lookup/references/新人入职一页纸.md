# 了解一家机构 · 新人入职一页纸

为什么要看这一页。慈善组织使命驱动、层级扁平，很多事是"靠共识推着走"的——不像公司有一张明确的组织命令链。你越早看清这家机构是什么、谁在负责什么、你的直属领导是谁、你的团队要做什么，就越能理解为什么要这么做、也越能把自己的判断放进去，而不是别人说什么就是什么。了解机构，是在这里做事的起点。

## 二、你的位置：三个必须搞清楚的

### 1. 你的直属领导是谁，往上都有谁

画一条线出来：

我（）← 直属领导： ← 再往上： ← （秘书长／理事长）

为什么要画这条线：一是报批和请示知道该找谁；二是反过来看机构——如果这条线很短、上面直接是秘书长，说明机构扁平；如果中间还有两三层，说明分工比较细。

### 3. 你的团队要做什么（今年）

这三样（领导、团队、团队的任务）为什么单列出来。因为"了解机构"不只是了解那十几项登记信息——你每天打交道的其实是自己这个小团队。团队的年度任务是什么、每个人负责哪一块、你这一小块和别人的怎么接上，这才是最实际的。

## 三、入职前能看什么，入职后看什么

很多东西在入职之前就能查到——不用等报到。入职前看的是"这家机构值不值得去、大概是什么样"；入职后看的是"具体怎么运转"。

### 入职前公开渠道就能看

| 看什么 | 在哪看 | 看什么门道 |
|---|---|---|
| 登记信息 | 慈善中国、社会组织政务服务平台 | 成立时间、原始基金、业务范围、有没有被列入异常名录 |
| 章程 | 机构官网、公众号、公开平台 | 宗旨、业务范围、治理结构——这是机构"根本大法" |
| 最近 2–3 年的年度工作报告 | 慈善中国、机构官网 | 这是信息量最大的一样，见下 |
| 理事会、监事会成员名单 | 年报里通常有 | 谁在负责；名单多久没变了 |
| 评估等级 | 民政部门公告 | 有没有等级、是几 A |
| 公开募捐资格 | 慈善中国名单 | 有没有资格——这决定它能公开募捐还是只能定向 |
| 项目公开信息 | 官网、公众号 | 在做什么项目、做了多久、做得怎么样 |
| 新闻与舆情 | 搜索引擎、行业媒体 | 有没有负面、有没有被处罚 |

年报要看什么——看三样"变化"，光看一年看不出来，要连着看 2–3 年：

① 人的变化——理事、监事、负责人有没有换。换得频繁说明治理不稳；长期不换也要留意（可能没人管）。

② 钱的变化——收入从哪来、支出花到哪去、净资产是增是减、管理费用比例有没有逼近上限。连着看能看出它是"在长"还是"在缩"。

③ 业务的变化——一直在做医疗，还是转向了教育？是一件事做深了，还是每年换方向？业务方向的稳定性，往往最能说明一家机构成不成熟。

再加一样：看工作人员数量与流动。年报里有人数与人员变动情况——离职入职多不多，反映团队的稳定性。

### 入职后这些在内部才看得到

| 看什么 | 为什么入职后才看 | 看什么门道 |
|---|---|---|
| 法人登记证书 | 原件通常在办公室或财务处保管，普通员工不一定能接触到 | 证书放在哪、有效期到什么时候、年检章有没有加盖 |
| 印章与用印登记 | 印章有专人保管，用印要审批，不是随手可看 | 有哪几枚章、谁保管、用印怎么审批 |
| 制度清单 | 文件在内网或共享盘，外部查不到 | 已有多少项制度、缺哪几项、放在哪 |
| 档案 | 涉内部资料，只能入职后按权限查阅 | 纸质档在哪、电子档在哪、谁管、怎么调阅 |
| 日常工作流程 | 是内部的运行习惯，外部看不见 | 见下 |
| 财务口径与台账 | 涉内部数据 | 费用比例怎么算、票据台账在哪、谁在盯 |

入职后最该摸清的一件事：这儿的事是怎么走完的。同样是"买一批物资"，不同机构走法完全不同：

· 是层层报批（经办人→部门负责人→秘书长→理事长）？还是线上提交就过了？

· 有没有金额门槛（多少以下部门批、多少以上要上会）？

· 要不要三方比价？谁签合同、谁验货、谁付款？

· 事后谁留痕、留到哪？

把这些问清楚，比读一遍制度管用。问谁：直属领导、办公室、还有做过同样事的同事。

## 四、要牢记的三句话

 钱物去向说得清谁给的、给了多少、给了谁、什么时候给的。

 程序手续留得全该审批的批了、该签字的签了、该备案的备了。

 档案台账找得到三个月后回头查，还能翻出来。

这三句不是标语，是这里所有工作的落点——慈善组织的一切事，最终都要"经得起查"。

## 五、和公司上班不一样的地方

先说一条最根本的：这里是靠理念和使命推动的。去一家慈善组织，首先是认同它的理念、做事方式和团队，才会留下。这不是唱高调——它决定了一件很实际的事：你要带着自己的思考做事，而不是"领导说什么就是什么"。

不是说要去反对领导，而是：你理解了机构想做什么，才能在领导布置任务、找你配合时，真正听懂他为什么这么安排；也才知道哪些做法偏离了机构的初衷，值得提出来。公益机构没有股东分红那一套激励，能让人长期做下去的，往往是"我认同这件事"。

#### 再说不一样的几条

| 层级是平的 | 有架构、有分工，但和大家常说的"公司层级"不一样——看起来有层级，实际上下之间没有那么明显的距离，通常很亲和。更像一张网：理事会、监事（会）、秘书处各是一支，网状排布、略有突出，而不是金字塔。把领导叫"老板"也没错，只是这里一般不这么叫——"老板"更多是商业公司的说法。 |
|---|---|
| 钱不是机构的 | 捐赠进来的钱属于社会公共财产，不是机构的收入，更不能私分、侵占、挪用。钱一旦进了机构账户，就是公共财产，不能用来分红。每一笔都要能对上用途。 |
| "非营利"不等于"不能有收入" | 可以有收入：提供服务、政府购买服务、投资收益、会费、捐赠……都可以。但盈余不能分配——所有收入都要用于章程规定的公益目的，不能向任何人分配或变相分配。一句话：可以赚钱，但不能分钱。 |
| 花钱有比例上下限 | 慈善活动支出有下限（钱要真花出去）；管理费用、募捐成本有上限（别都花在机构自己身上）。而且按组织类型和规模分档，不是只有一个数。超了要报告登记管理机关并向社会公开说明。 |
| 要主动公开 | 年报、募捐信息、重大事项要按规矩公开。不是"愿意公开才公开"。 |

## 六、不能轻易做的三件事

不是"第一周别做"——是一直都不能随手做。要做之前，先问清楚、想清楚。

 - 不代表机构对外发声。公众号、朋友圈、接受采访、回应用户提问——机构对外只有一个出口。要发之前先问：这个由谁审、口径是什么。个人账号也不等于"随便说"，因为别人认的是你所在机构的人。

 - 不轻率承诺。对捐赠人、受益人、合作方、政府部门，先记下来、回机构问清楚再答。一句"没问题"可能变成必须兑现的义务。

 - 不把受益人信息随便存、随便传。拍完照、记完名册，按机构规定的渠道保存和使用；别长期存在自己手机里、别随手转发。这既是合规，也是对服务对象最基本的尊重。

拿不准就问这一句："这件事，法规或我们的制度里是怎么规定的？"

如果没有人能答上来——那就先别做，去查，或者问登记管理机关（民政部门）。在这里，"先问一句"永远不会错。

想看更细的：机构里有哪些位置、每个位置做什么、以谁为主——见《公益组织岗位与职责手册》；

这些规矩是怎么来的、为什么是这样——见「为什么」栏目；
