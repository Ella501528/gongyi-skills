# 慈善组织岗位职责速查

按岗位或按事项查阅的工具。**不按顺序读**——知道要查什么就直接查。

## 什么时候会用到它

| 时机 | 查什么 |
|---|---|
| 拿不准某个岗位名称是不是法定的 | `--q 岗位名`，看它属"法定角色／治理机构／内设岗位"哪一层 |
| 某件事该谁牵头、谁配合 | `--item 事项名`，直接看主责与协办 |
| 新同事入职要交代职责 | `--role 岗位名`，列出该岗位主责与协办的全部事项 |
| 招聘前写岗位要求 | `--q 岗位名 --full`，看"通常要求什么"那一段 |
| 小机构人手少，岗怎么合 | `--q 一人多岗` |
| 在纠结某项工作该不该外包 | `--q 外包` |

## 怎么用

```bash
# 查一个岗位或章节
python scripts/lookup_role.py --q 秘书长
python scripts/lookup_role.py --q 财务            # 章节名含"财务"
python scripts/lookup_role.py --q 秘书长 --full   # 输出完整正文

# 查一件事：谁主责、谁协办
python scripts/lookup_role.py --item 章程
python scripts/lookup_role.py --item 募捐

# 按角色列事项
python scripts/lookup_role.py --role 监事
python scripts/lookup_role.py --role 办公室

# 总览
python scripts/lookup_role.py --list

# 程序调用
python scripts/lookup_role.py --item 章程 --json
```

**记法**：`●` 主责　`○` 协办　（空）不承担。

## 读之前先知道一件事

这个手册把"位置"分三层，混起来最容易出错：

| 层 | 是什么 | 能不能自己改名 |
|---|---|---|
| **法定角色** | 法规或条例里写死的：理事、理事长、副理事长、秘书长、监事、监事长 | 全国统一，不能改 |
| **治理机构** | 由法定角色组成：理事会（决策）、秘书处（执行）、监事（会）（监督） | 按法定要求设 |
| **内设部门与岗位** | 机构自己设的：办公室、项目部、筹资部、传播部、财务部…… | 叫法五花八门，法律不管名字 |

**一家机构可以只有 3 个人，也可以有 300 个人——法定角色一个都不能少，内设岗位可以一人兼几个。**

另外这套手册用四种规格标签区分要求的硬度，看的时候留意：

| 标签 | 含义 |
|---|---|
| **必须** | 法定要求，不做不合规 |
| **要求** | 法规说"应当"，有明确指向 |
| **常规** | 行业通行做法，不是法定 |
| **可选** | 机构自定 |

## 边界与降级（必读）

- **对照表是"职责清晰时的一种分法"，不是唯一正解。** 实际机构里一人可能占好几行，也可能一个角色几个人担。用它来**对表、找缺口、写岗位说明**，不要拿它当考核依据。
- **岗位名称以本机构的章程和内部制度为准。** 本手册给的是通用口径；同名岗位在不同机构职责差别可能很大。
- **法定角色的任职资格属于硬要求**（人数、任期、专职、不得兼任等），办事前**须回现行法规原文核对**——相关条例在修订中，以最新公布的文本为准。
- **本手册不替代章程、内部制度与法规原文**，也不构成法律意见。涉及任职资格、兼任限制、报酬等判断时，以现行法规与登记管理机关口径为准。
- 数据文件缺失时脚本直接报错退出，不给空结果；看到报错先查 `data/` 下两个 JSON。
