## 三层总览

### 量化标准（第二十七、二十八条）

- **主要捐赠人**（三选一）：① 注册资金捐赠人；② 办公场所捐赠人；③ 年度累计捐赠额超年度捐赠收入 **5%**，或年度捐赠超 **500 万元**。
- **重大慈善项目**（三选一）：① 该项目捐赠收入占当年捐赠总收入 **1/5 以上且超 50 万元**；② 该项目支出占当年慈善活动总支出 **1/5 以上且超 50 万元**；③ 持续时间 **超过 3 年**。

## L2 平台规则强制：慈善中国 + 互联网募捐平台

> 这一层常被漏掉。它不是"法"，但**不遵守照样挨处置**，而且触发更快。来源：全国慈善信息公开平台（二期）用户操作手册。

> **与法定事项的对应**（避免两套编号打架）：L2-1 募捐方案备案 → 清单 C1；L2-7 备案补正 → 清单 C11；L2-2 / L2-3 / L2-4 平台时限提示 → 清单 C8 / D6 的时限执行要求；L2-5 年报上传 → 清单 B1 / B5；L2-6 理事监事公示入口 → 清单 A2。**其余 L2 项（互联网募捐平台规则）属平台侧准入要求，不新增法定事项编号。**

### 慈善中国平台侧硬性要求

| 环节 | 平台要求 |
|---|---|
| 公开募捐方案备案 | 须在募捐活动开始**前 10 日**备案（不含当日）；备案提交后不可修改 |
| 备案触发提示 | 存在 **3 个月**未发布募捐情况的备案，系统自动弹窗提示超时 |
| 项目实施情况 | 存在 **3 个月**未发布项目进展的项目，系统自动弹窗提示超时 |
| 项目进展填报区间 | 周期超 6 个月的项目，起始与截止时间段**不得超过 3 个月** |
| 年报报送 | 未在"中国社会组织网"年报系统填报的组织，须在慈善中国**自行上传**年报附件 |
| 理事/监事公示 | 平台"登记信息"下有独立公示入口，需机构自行维护 |
| 平台联系方式 | 见慈善中国平台首页"联系我们"，以平台当年公布为准（本包不转抄联系方式） |

### 互联网公开募捐平台（以腾讯公益为例）

> 来源：《腾讯公益平台运营规则及指引（2026）》，取自腾讯公益机构服务平台知识库。

| 规则 | 具体要求 |
|---|---|
| 项目进展 | **近 3 个月内**须发布过实质性项目进展（延期筹款的前置条件） |
| 财务披露 | 非本年度上线的项目，**6 月 30 日前**须发布上一年度项目财务披露 |

| 处置措施 | 影响公募机构上线新项目（含合作项目）、影响公募培育相关资助等权益、终止机构与平台所有合作 |

## L3 鼓励与公众期待：FTI 中基透明指数

> FTI 是第三方评估，**只能作参考与自评工具，不得作为法律义务依据**。指标与算法完全公开，系统自动计算。

> **本层不产生法定事项编号，不计入应公开分母。** 下表的 FTI 指标属第三方观测口径；其中与法定事项重合的部分（如年度工作报告、审计报告），其公开状态仍按 `templates/01` 的对应事项判定，本层只作"做得好不好"的加分观察。FTI 分数**永远不能作为"已公开"的证明**（属 D 级证据）。

### FTI 基本口径（FTI6.0，FTI2024 起启用，FTI2025 沿用）

- 由**基金会中心网**与**清华大学廉政与治理研究中心** 2012 年联合开发；满分 100 分；每年发布一次。
- 依据：《慈善法》《慈善组织信息公开办法》《基金会信息公布办法》。
- 四维度：**组织 / 财务 / 项目 / 募捐**。回答四个问题：谁在管理？钱从哪儿来到哪儿去？在做什么？做的事情有什么用？
- 原则：**"立足法规底线，倡导卓越发展"**。

### 双阶段结构（这是 FTI6.0 的核心变化）

| 阶段 | 对象 | 观测渠道 | 观测什么 |

### FTI 三条使用禁忌

1. **FTI 分数不是合规结论**。它是"是否公开"的快照，不评判内容真实性与质量；FTI 只能保证观测到的数据是真的，无法确保数据本身真实。
2. **透明 ≠ 好**。得高分不等于机构运作优良，不得用作机构整体评价背书。
3. **年度分数锁定后不再更改**，但机构在慈善中国与官网补齐的信息对公众实时可见——所以"当年度分数低"不等于"现在还是低"。

### FTI 给出的最优行动建议（对本专家团直接可用）

- 打开 FTI 自测系统（fti.foundationcenter.org.cn）检视 → 回慈善中国补齐缺项 → 编制年报时多问"有没有讲清楚"。
- 优先补治理与关联方信息（公开率最低、失分最集中）；补薪酬前五与费用标准（公募机构仅 37%/53%）；补项目成效评估（仅 61%）。
