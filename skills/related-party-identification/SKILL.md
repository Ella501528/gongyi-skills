# 慈善组织关联方识别与登记

## 何时使用

- 要梳理本组织的关联方有哪些
- 要判断某个人或某机构是否构成关联方
- 要判定主要捐赠人
- 要建立或更新关联方台账，准备年度报送

## 何时不用本技能

- 已认定对方是关联方，要判断这笔交易怎么走程序 → 用关联交易合规审查
- 要生成公开文本、核对公开与报送时限、分析违规后果 → 用关联交易公开与责任
- 主体不是慈善组织（企业、政府采购、事业单位等）→ 口径不同，本技能不适用
- 要的是法律定性、争议代理或对外答复 → 本技能不作法律意见，交律师、登记管理机关或专业机构

## 输入输出契约

**你要准备什么**

一份按本包 `sample_data/sample_input.json` 结构填写的事实 JSON。其中 `facts.identification` 分组由本技能负责采集，字段取值三态：`true`（存在或已完成）、`false`（不存在或已完成之外的否定）、`null`（资料未取得）。

| 字段 | 采集什么 |
|---|---|
| `list_established` | 是否已形成关联方名单 |
| `three_scopes_checked` | 是否已按三套口径分别比对并取并集 |
| `key_mgmt_and_family_included` | 关键管理人员及关系密切家庭成员是否已纳入 |
| `major_donor_judged` | 主要捐赠人是否已按占比或章程重大资金标准判定 |
| `has_project_or_fund_level` | 是否设有专项基金或独立项目 |
| `project_donor_identified` | 该层面主要捐赠人是否已单独识别 |
| `update_owner_assigned` | 是否已指定更新责任人与更新频率 |
| `has_related_party` | 本组织是否存在关联方 |

**跑之前先装依赖**（只需一次）

```
pip install openpyxl
```

未安装也能跑，脚本会自动降级为 CSV 清单与 Markdown 摘要。

**跑完得到什么**

在包根目录执行：

```
python scripts/run_check.py -i 我的机构.json
```

得到 `（输入文件同级目录）/out/关联方合规体检报告_YYYYMMDD.xlsx`，四个工作表：体检摘要、缺陷清单、待确认项、评分明细。控制台同时输出 Markdown 摘要。本技能另关联方名单表，字段为：关联方名称、身份类别、与本组织的关系说明、判定依据、识别日期、更新责任人。

**什么叫成功**

1. 报告文件已生成，四个工作表均有内容；
2. 报告中的评分、命中数、待确认数与控制台摘要完全一致；
3. 「待确认项」工作表列出了需补充的字段路径，按它补齐后复评，评分上升即说明识别工作已补上。

**资料不全或跑不动时怎么办**

- 字段填 `null` 即标记为「待确认」，不计入评分分母，既不会被算作通过，也不会被算作命中；
- 未安装 openpyxl 时自动降级为 CSV 清单与 Markdown 摘要，不中断；
- 报告文件被 Excel 或 WPS 占用时，用 `-o` 指定新文件名再跑；
- 输入 JSON 语法错误会给出行列位置；缺少顶层 `facts` 会直接报错并提示补全结构。

## 三套口径（必须取并集，不能只看一套）

| 规定 | 关联方范围 |
|---|---|
| 《慈善法》第 14 条 | 发起人、主要捐赠人、管理人员 |
| 《慈善组织信息公开办法》第 4 条 | 发起人、主要捐赠人、管理人员、被投资方，以及存在控制、共同控制或重大影响关系的个人或组织（**重要关联方**） |
| 《民间非营利组织会计制度》第 89 条 | 控制/共同控制/重大影响定义 + 九项列举 |

## 九项列举（会计制度第 89 条）

1. 设立人及其所属企业集团的其他成员单位
2. 本组织控制、共同控制或施加重大影响的企业
3. 本组织设立的其他民间非营利组织
4. 由出资人或设立人及其所属企业集团其他成员单位共同控制或施加重大影响的企业
5. 由设立人及其所属企业集团其他成员单位设立的其他民间非营利组织
6. **关键管理人员及与其关系密切的家庭成员**
7. 关键管理人员或其关系密切家庭成员控制、共同控制或施加重大影响的企业
8. 关键管理人员或其关系密切家庭成员设立的其他民间非营利组织

此外：面向社会开展慈善活动的组织，与《慈善法》规定的**主要捐赠人**也构成关联方。

## 关键概念判定

**关键管理人员**：有权力并负责计划、指挥和控制组织活动的人员，一般包括负责人、理事、监事、分支（代表）机构负责人等。

**关系密切的家庭成员**：在处理与组织的交易时可能影响该个人或受该个人影响的家庭成员。

**主要捐赠人**：
- 占比角度：来自某捐赠人的资金占组织整体资金规模比例较高（实践常以 30% 为参考线）
- 数额角度：捐赠资金量高于章程规定的"重大资金"数额
- **专项基金、项目层面也有各自的主要捐赠人**，须单独识别

**控制 / 共同控制 / 重大影响**（参照《企业会计准则第 36 号》）：
- 控制：有权决定财务和经营政策并据以获取利益
- 共同控制：按合同约定共有控制，重要决策须一致同意
- 重大影响：有参与决策的权力但不足以控制或共同控制

判断要点：能否影响本组织决策，而非仅看身份名称。

## 四类角色速判

| 角色 | 是否关联方 | 要点 |
|---|---|---|
| 理事、监事 | 是 | 其近亲属不得与本组织发生任何交易；其所在机构可交易但须走程序 |
| 主要捐赠人 | 是 | 其成立的机构若能对决策产生重大影响，应保守认定为关联方 |
| 合作方 | 视控制/重大影响 | — |
| 志愿者 | 一般不构成 | 属人员管理范畴；若同时为关键管理人员或有重大影响者除外 |

## 输出：关联方名单及关联关系说明

名单应包含字段：关联方名称 / 身份类别（发起人、主要捐赠人、管理人员、被投资方、控制或重大影响方）/ 与本组织的关系说明 / 判定依据 / 识别日期 / 更新责任人。

**年度报送**：每年 **5 月 31 日**前向办理其登记的民政部门报送关联方名单及关联关系说明（《慈善组织信息公开办法》第 15 条）。即便当年未发生关联交易，只要存在关联方，该义务依然存在。

- [ ] 主要捐赠人已按占比或章程"重大资金"标准判定
- [ ] 专项基金、项目层面的主要捐赠人已单独识别
