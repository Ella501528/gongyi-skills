# 党组织形式五型判定速查卡

## 判定三问（按顺序问完即定型）

1. **有正式党员不足 3 人，或无党员？** → **A 型（工作覆盖）**：不建党组织，派驻党建指导员 / 建立群团组织，做"工作覆盖"。
2. **党员组织关系都不在本系统，且需多单位联合？** → **B 型（联合流动党支部）**：走"多家分别盖章的联合请示 → 联合党委批复 → 任命书记"。
3. **组织关系已转入本系统？** → 再看：**3 人以上单独成立 → D 型（独立党支部）**；**多单位联合 → C 型（联合正式党支部）**。
4. **有 3 名以上党员但组织关系转不进来？** → **E 型（功能型党组织）**。

## 五型横向差异（最容易混淆的五件事）

| 事项 | A 工作覆盖 | B 联合流动支部 | C 联合正式支部 | D 独立支部 | E 功能型 |
|---|---|---|---|---|---|
| 党费 | 不收 | **不收**，在原党组织交 | 收 | 收 | **不收** |
| 发展党员 | 不适用 | **不发展、不审批转正** | 可发展 | 可发展 | **不发展** |
| 民主评议 | 不适用 | **回原党组织**，本支部反馈表现 | 本支部开展 | 本支部开展 | **回原党组织** |
| 书记产生 | 不适用 | **联合党委任命**（非选举换届） | 选举换届 | 选举换届 | 依上级党组织 |
| 年度任务 | 约少 10 项党费/党员类 | 划掉党费与发展党员项 | 26 项全量 | 26 项全量 | 划掉党费与发展党员项 |

**其余频次（三会一课、主题党日、组织生活会）五型一律不打折。**

## 转型红线

| 从 → 到 | 触发条件与动作 |
| --- | --- |
| A → 任一型 | 正式党员达 3 名 → 按"组织关系可否转入"判型 → 按该型程序提出建制请示，同步更新年报与章程表述 |
| B → C / D | 组织关系转入累计 ≥3 名 → 申请成立正式支部，并做隶属变动报告 |
| E → D | 能转入的党员达 3 名 → 参照正式支部程序转建 |
| C → D 或属地 | 条件成熟时单独建党或按属地化管理转入街乡社区——均属设置变动，须报告 |
| 任何型 → 撤销 | 机构注销或建制撤销 → 报上级党组织，档案按上级要求移交 |

另：C / D 型推进属地化管理时，注册地址与实际办公地址不一致的，须出具盖公章的情况说明并尽快办地址变更。

## 各型最易踩的三个坑

- **A 型**：①以为"没党员就没党建"完全躺平（等级评估"工作覆盖 3 分"白白丢）；②有党员不报告、不更新党员情况调查表；③误设党费账户——无建制不收党费，党员在原组织关系所在党组织交纳。
- **B 型**：①把流动支部当正式支部——收党费、发展党员、开展民主评议（三项都不属本支部权限）；②书记未走批复自行产生；③联合请示漏写"组织关系均不在本系统"这一关键表述。
- **C / D 型**：①换届超期（每 3 年一次，超期是最常见问题）；②把"任命"当"选举"（独立支部必须党员大会选举＋上级批复）；③党费台账与党建经费台账混记。
- **E 型**：①按正式支部口径收党费、办发展、办评议（三项均越界）；②只挂牌不开展组织生活；③与 B 型混淆——B 型针对"组织关系不在本系统"且多为多单位联合，E 型针对"有 3 名以上党员但转不进来"的单一机构，实务中两者可能重叠，以属地批复形式为准。

## 依据与免责

判定门槛（3 / 7 / 50 / 100 人、联合建制、"两个覆盖"）为**党内法规口径**：党章 §29、《党支部工作条例（试行）》、中办发〔2015〕51 号、国工发〔2016〕11 号、2024 中办《关于进一步加强和改进流动党员管理工作的意见》。

建制体系为**地方口径**：北京市"综合党委—联合党委—社会组织党组织"三级体系（54 家联合党委）；中共北京市委办公厅实施意见（2016）。

**形式参考（一手实证，非全国规范）**：京社服三联党发〔2024〕15 号批复——4 家基金会联合请示、联合党委研究决定同意成立第九联合流动党支部委员会并任命书记；京社服三联党发〔2022〕4 号——第三联合党委辖 3 个正式联合支部＋10 个联合流动支部。**联合流动支部的命名、书记任命制为北京综合党委系统做法，各地程序以属地党委 / 上级党组织规定为准。**

**留白（不作推断）**：功能型党组织中央层面尚无统一专名规范；党费 20%（中央和国家机关口径）与 5%（社会组织上缴中央）的适用边界本卡不作裁决。
