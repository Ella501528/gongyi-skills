
# 党组织形式分型作战清单
配套《慈善组织党建工作手册》第 2 章使用 · 先判定本单位属于哪一型，再只看对应清单 · 各型可单独打印
本单位型别：____ 型
## 〇、先判定：三个问题定型别
```
① 本单位（含专职人员与负责人）正式党员有几名？
② 这些党员的组织关系，能转入 / 已转入本系统（联合党委或属地）吗？
③ 机构加入了联合党委，还是由属地（街道/园区）或业务主管单位党组织兜底？
```
| 型别 | 判定条件 | 组织形式 |
| --- | --- | --- |
| A 型 | 无党员，或正式党员不足 3 人且未加入任何联合建制 | 不设党组织 → 工作覆盖（党建指导员 / 群团组织 / 区域化党建） |
| B 型 | 有流动党员（组织关系均不在本系统）≥3 名，多家单位联合 | 联合流动党支部（隶属联合党委，北京综合党委体系最常见） |
| C 型 | 正式党员 ≥3 名且组织关系已转入本系统，多家单位联合 | 联合（正式）党支部，作为联合党委成员单位 |
| D 型 | 正式党员 ≥3 名，单独建制 | 独立党支部（7 人以上设支部委员会；50 人以上党总支；100 人以上基层党委） |
| E 型 | 正式党员 ≥3 名，但能转入组织关系的不足 3 名 | 功能型党组织（一方隶属、参加多重组织生活） |
上级建制说明：多家未单独建党组织的机构，可按"业务相关、地域相近"依托较大较好的支部组建联合党委（国工发〔2016〕11 号）；北京为"综合党委—联合党委—社会组织党组织"三级体系，54 家联合党委。党内法规地方口径
## 五型横向差异总表（最容易混淆的五件事）
| 事项 | A 工作覆盖 | B 联合流动支部 | C 联合正式支部 | D 独立支部 | E 功能型 |
| --- | --- | --- | --- | --- | --- |
| 党费在哪交 | 在党员原组织关系所在党组织交，本建制不收缴 | 本支部收缴（4 月底前 5% 上缴） | 本支部收缴（同左） | 在原党组织交，本建制不收缴 |
| 民主评议党员 | 不适用 | 原则上由原党组织开展，本支部年底反馈党员表现 | 本支部开展 | 本支部开展 | 原则上不开展，年底向原党组织反馈 |
| 发展党员 | 不适用 | 可发展（C 型在本支部办理） | 可发展 | 不发展、不审批转正（可培养积极分子，转正回原党组织） |
| 书记产生方式 | — | 联合党委批复任命（北京实证） | 党员大会选举 ＋ 上级批复 | 党员大会选举 ＋ 上级批复 | 一般由机构负责人中的党员担任，参照正式支部程序 |
| 评估得分路径 | 工作覆盖 3 分 | 组织覆盖 12 分 ＋ 工作覆盖 3 分（合计 15 分） | 属组织覆盖（以属地口径为准） |

## A 型 · 工作覆盖作战清单（无党员 / 未建制）
> [!NOTE]
> 核心认知：没有党组织 ≠ 没有党建任务。"工作覆盖"是等级评估中独立于组织覆盖的 3 分得分路径——很多无党员机构完全不做，白白丢分。
### A-1 一次性设置动作
- [ ] 成立登记 / 变登记时已提交党建工作承诺书＋党员情况调查表（北京口径，存档备查）
- [ ] 章程含党建条款（按手册 3.1 现行第三代表述，勿抄 2018 旧模板）
- [ ] 与上级（属地街道 / 园区 / 业务主管单位 / 联合党委）对接，确认党建指导员人选与联系方式
- [ ] 组建或挂靠群团组织（工会 / 共青团 / 妇联），或纳入区域化党建（社区党组织）
### A-2 年度动作
- [ ] 年报"党建工作"模块如实勾选，同时写明工作覆盖做法（指导员 + 群团），不空栏
- [ ] 等级评估时备齐"工作覆盖 3 分"佐证：指导员派驻 / 沟通记录、群团组织活动记录
- [ ] 每季度排查一次党员情况（新入职、离职），更新党员情况调查表
- [ ] 参加上级党组织开放的活动（培训、党课、区域化共建），留签到与影像
### A-3 触发升级的红线
| 触发情形 | 动作 |
| --- | --- |
| 正式党员达到 3 名 | 应当申请建立党组织——先判组织关系能否转入：能 → D 型或加入 C 型联合正式支部；不能 → B 型或 E 型 |
| 党员不足 3 名但同领域可联合 | 牵头或加入联合建制（B / C 型） |
| 员工党员异地长期执行项目（外出 6 个月以上） | 提示其向流入地党组织报到（2024 流动党员管理意见） |
易错点：①以为"没党员就没党建"而完全躺平（丢 3 分）；②有党员不报告；③误以为要设党费账户——无建制不收党费，党员在原组织关系所在党组织交纳。
## B 型 · 联合流动党支部作战清单（组织关系均不在本系统）
一手实证（北京）：京社服三联党发〔2024〕15 号批复——4 家基金会（广明灯、绿色阳光、爱思开幸福、母爱联盟）联合请示，联合党委研究决定同意成立"第九联合流动党支部委员会"，任命王志清为党支部书记，支部隶属于第三联合委员会，依据党章和《党支部工作条例（试行）》开展支部工作。2022 年优化调整后第三联合党委共辖 13 个支部：3 个正式联合支部 ＋ 10 个联合流动支部。
### B-1 成立路径（一次性，依实证模板）
```
① 摸底：各成员单位逐一填写基本情况（成立时间、业务、从业人员、流动党员数），
关键句——"单位现有流动党员×名，组织关系均不在综合党委系统"
② 联合请示：多家单位共同署名、分别盖章，报联合党委
（拟推荐书记人选；临时负责人须写清所在社会组织名称）
③ 联合党委研究决定并下发批复（如京社服三联党发〔2024〕15 号）
④ 批复中任命书记；支部隶属联合党委
⑤ 命名规范：中共××（上级全称）第×联合（流动）党支部/支部委员会
上级全称须用"中共××委员会"正式全称，简称另注
```
- [ ] 请示正文每家单位情况逐段写全，落款分别盖章（漏盖章退回重报）
- [ ] 收存批复原件（入台账"组织建设"卷）
- [ ] 按上级要求填报支部党员信息表（每名党员注明组织关系所在党组织）
- [ ] 领取 / 开通党员 E 先锋等系统账号（流动党员管理模块）
### B-2 年度动作（与正式支部的差异已标红）
- [ ] 三会一课照常：支委会每月、党员大会每季度、党课每季度、主题党日每月（频次不打折）
- [ ] 党费：本支部不收缴——每名流动党员在原组织关系所在党组织交纳；支部每年核对一次交纳情况提醒
- [ ] 民主评议：原则上由原党组织开展；本支部年底向各原党组织反馈党员表现（一年一反馈，留函件/记录）
- [ ] 发展党员：不在本支部发展、不审批转正；可培养入党积极分子，转正由原党组织办理
- [ ] 党员学习学时照常记录（党员 ≥32 学时/年，支委 ≥56 学时/年）
- [ ] 支部书记由联合党委任命/调整，走批复，不走选举换届程序
- [ ] 参加联合党委统一活动（讲座 / 主题党日 / 红色研学：佩戴党徽、签到、心得体会）
- [ ] 年底配合联合党委党支部考核评议
### B-3 转型红线
| 触发情形 | 动作 |
| --- | --- |
| 某单位党员组织关系转入本系统 ≥3 名 | 应申请成立正式党支部（转 C / D 型）——2022 年综合党委已部署正式支部和党员属地化管理，转入是方向 |
| 成员单位注销 / 新增 | 报联合党委调整支部组成（设置变动属重大事项报告范围） |
| 注册地址与实际办公地址不一致 | 属地化对接前需出情况说明盖公章，并尽快办登记地址变更 |
易错点：①把流动支部当正式支部——收党费、发展党员、开展评议（三项都不属于本支部权限）；②书记未走批复自行产生；③请示漏"组织关系均不在本系统"的关键表述；④党员长期不参加任何组织生活两头落空。
## C 型 · 联合正式党支部作战清单（组织关系已转入的联合建制）
> [!NOTE]
> 与 B 型的本质区别：党员组织关系已转入联合党委系统——因此党费在本支部收缴、评议在本支部开展、可以在本支部发展党员，年度任务即主清单 26 项基本全适用。书记单位牵头。
### C-1 一次性 / 结构性动作
- [ ] 成立请示 → 联合党委批复 → 党员大会选举支委会/书记 → 报上级组织部门备案（程序四步留痕）
- [ ] 明确书记单位（通常党建基础较好、规模较大的一家）与各成员单位职责
- [ ] 开通党费专户（六家指定银行之一），建立党费台账与党建经费台账两本账
- [ ] 按属地化管理部署：梳理本支部及机构可向属地（街乡社区、楼宇、园区、党群服务中心）提供的资源和服务清单（不少于 100 字，报联合党委汇总）
- [ ] 注册地址与实际办公地址不一致的，出情况说明并尽快办变更登记
### C-2 年度动作（联合建制特有项加粗）
- [ ] 执行主清单 26 项（三会一课、主题党日、组织生活会、民主评议、谈心谈话全量）
- [ ] 4 月底前：上年度党费总额 5% 上缴（收缴台账＋专户流水＋上缴凭证）
- [ ] 跨单位活动协调：党员大会/党课时间需协调各成员单位，提前 1 周发通知
- [ ] 每名党员组织关系介绍信、转接记录归档（转入本系统的凭证是"正式"身份的根）
- [ ] 向各成员单位理事长/秘书长年度通报支部工作（双向进入、交叉任职的落点）
- [ ] 换届每 3 年 1 次：党员大会选举＋联合党委批复＋备案
易错点：①只有书记单位一家在干活，其他成员单位"挂名"——支部记录里体现不出成员单位参与；②党费误按 B 型口径让党员回原单位交；③属地化转移隶属关系时未做重大事项报告。
## D 型 · 独立党支部作战清单
> [!NOTE]
> 适用：本单位正式党员 ≥3 名（单独建制）。7 人以上设支部委员会（3–5 人）；50 人以上可升党总支；100 人以上可升基层党委。年度任务＝主清单 26 项全量适用，此处只列成立与易错。
### D-1 成立路径（依党支部工作条例 §6）
```
① 本机构提出书面请示（模板见手册第 12 章）
② 上级党委（属地街道党委 / 业务主管单位党组织 / 联合党委）
研究决定并批复——批复一般不超过 1 个月
③ 召开党员大会：选举产生支部委员会；不设委员会的选举书记、副书记
④ 批复与选举结果由上级党委报上级党委组织部门备案
※ 上级党委也可直接决定在基层单位成立党支部
```
- [ ] 书记人选：一般由本机构主要负责人中的党员担任（人选不合规是常见扣分点）
- [ ] 选举"三件套"齐备：选举记录、选票、批复
- [ ] 成立后 30 日内核对：章程党建条款、年报勾选、评估指标口径同步更新
### D-2 年度与周期红线
- [ ] 执行主清单 26 项 ＋ 12 个月节奏表（不再重复列出）
- [ ] 换届每 3 年 1 次，超期不换届是最常见问题——任期倒排提前 6 个月启动
- [ ] 党员达 50 / 100 人时研究升格党总支 / 基层党委（设置变动须报上级党组织）
- [ ] 设置及隶属关系任何变动（成立 / 撤销 / 升格 / 转隶 / 书记变更）→ 重大事项报告
易错点：①3 人支部不设支委会但长期不开党员大会；②书记由非负责人、非党员担任；③换届时把"任命"当"选举"（独立支部必须选举产生）。
## E 型 · 功能型党组织作战清单（一方隶属、参加多重组织生活）
> [!NOTE]
> 适用：机构负责人和专职人员中有 3 名及以上正式党员，但能转入正式组织关系的不足 3 名。核心规则：党员组织关系均不转入，保留在原单位 / 居住地。⚠️ 中央层面尚无统一专名规范，具体以属地党委 / 上级党组织规定为准。
### E-1 权利义务边界（对照表，勿越界）
| 事项 | 本建制的处理 |
| --- | --- |
| 正式组织关系 | 不转入 |
| 党费 | 不收缴，党员在原党组织交纳 |
| 发展党员 | 不发展、不审批转正；可培养积极分子，转正回原党组织 |
| 民主评议党员 | 原则上不开展；年底向原党组织反馈表现 |
| 组织处理 / 纪律处分 | 原则上不进行；提供情况、提建议，由原党组织办理 |
| 党内选举 | 党员有表决权、选举权、被选举权，可选本支部书记、委员 |
| "三会一课" | 照常开展（按"一方隶属、参加多重组织生活"原则） |
依据：中办发〔2015〕51 号第 15 条；国工发〔2016〕11 号"理顺党员组织关系五种情况"；重庆市社科联社会组织综合委员会功能型特设党支部工作规范（2023，最详细专门规范）地方口径。
### E-2 一次性设置
- [ ] 核点"两个数字"：正式党员 ≥3 名；能转入的不足 3 名（这是功能型 vs 正式支部的分界线）
- [ ] 设置及组建程序参照正式党支部规定执行（请示 → 批复 → 选举/任命）
- [ ] 书记一般由机构负责人中的党员担任
- [ ] 每名党员登记其原组织关系所在党组织全称（反馈、党费核对都要用）
### E-3 年度动作
- [ ] 三会一课、主题党日照常开展并留痕（这是本建制存在的核心价值）
- [ ] 学时台账照常（32 / 56）
- [ ] 年底逐人向原党组织反馈党员表现（函件或统一表格，留底）
- [ ] 积极分子培养记录单独归档（转正时移交原党组织）
- [ ] 不设党费账户、不做收缴台账——检查时如实说明"一方隶属"口径
- [ ] 动态复核：一旦能转入的党员达到 3 名，即申请转为正式支部（转 D / C 型）
易错点：①按正式支部口径收党费、办发展、办评议（三项均越界）；②只挂牌不开展组织生活（功能型不是"注册一个名头"）；③与流动支部混淆——流动支部针对"组织关系不在本系统"的党员且多为多单位联合，功能型针对"有 3 名以上党员但转不进来"的单一机构，实际案件中两者可能重叠，以属地批复形式为准。
## 附：转型路径速查
| 从 → 到 | 触发条件与动作 |
| --- | --- |
| A → B / C / D / E | 正式党员达 3 名 → 按组织关系可否转入判型 → 提出建制请示 |
| B → C / D | 组织关系转入 ≥3 名 → 申请成立正式支部；同步做隶属变动报告 |
| E → D | 能转入的党员达 3 名 → 参照正式支部程序转建 |
| C → D（或属地） | 条件成熟时单独建党或按属地化管理转入街乡社区——均属设置变动，须报告 |
| 任何型 → 撤销 / 注销 | 机构注销或建制撤销 → 报上级党组织，档案按上级要求移交 |
依据与免责：本清单与《慈善组织党建工作手册》同源。判定门槛（3/7/50/100 人、联合建制、两个覆盖）为中央党内法规口径；联合流动支部的成立文本、命名、任命制为北京综合党委系统一手实证形式参考，各地程序以属地党委 / 上级党组织规定为准；功能型党组织中央无统一专名规范地方口径。B 型批复实例：京社服三联党发〔2024〕15 号；支部构成实证：京社服三联党发〔2022〕4 号。
