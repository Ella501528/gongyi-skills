# 慈善组织合作募捐合规与对账

合作募捐是慈善组织最容易踩线的一块：**它看起来只是"和别人一起募捐"，但法律把它当成一个专门事项来管**。核心就一句——**不具公开募捐资格的组织或个人，要与具有公开募捐资格的慈善组织合作，并把这个合作"评估、签约、载明、公开、监督、入账"全走完**。

## 什么时候会用到它

| 时机 | 你要做的事 |
|---|---|
| 决定与企业或其他组织开展联合募捐前 | 先确认**资格前提**（见第一节） |
| 签约前 | 用第二节做合作方评估、对齐协议载明事项 |
| 上线募捐前 | 用第三节确认方案公开 |
| 募捐过程中 | 用第四、五节管款物入账与监督 |
| 使用款物时 | 用第六节确认未超方案范围 |
| 检查、审计、评估前 | 把合作募捐台账交给 `scripts/check_cofundraising.py` 跑一遍 |

## 一、资格前提：谁能与谁合作（第一道关）

**法定要求**（《慈善法》第二十六条）：**不具有公开募捐资格的组织或者个人，可以与具有公开募捐资格的慈善组织合作开展公开募捐**；合作开展公开募捐的，应当**依法签订书面协议**，**募捐款物由具有公开募捐资格的慈善组织管理**。

判断两步：
1. **合作里至少有一方是"具有公开募捐资格的慈善组织"**——没有，则不能开展公开募捐；
2. **不具有资格的一方，必须"依托"具有资格的一方**——由具资格方管理募捐款物、承担相应义务。

## 二、评估与协议：先评后签，签约要载明

**合作方评估**：合作前应对合作方进行评估（主体情况、过往记录、履约能力），并形成评估依据。

**协议载明事项**（建议四项齐备）：
1. **募捐目的**与**募捐方案**；
2. **募得款物的用途**；
3. **各方的权利与义务**；
4. 剩余财产处理、信息公开与监督方式。

## 三、方案公开：募前公开

**公开募捐方案**应在募捐活动开始前，按公开募捐的相关规定进行备案与公开，接受社会监督。**未公开即开募**是常见问题。

## 四、款物入账：全部纳入本机构账户

**硬要求**：募捐所得款物，**应当全部纳入具有公开募捐资格的慈善组织的账户**，统一管理、单独核算、专款专用。

**不得**：由合作方自行收取后"部分上交"；以现金、个人账户等体外循环方式留存。

## 五、监督：不是签完就完

**法定要求**：慈善组织应当对合作开展的公开募捐活动进行**监督**，确保募得款物按方案与协议使用。

监督留痕建议：阶段进展报告、款物使用记录、对账确认。

## 六、支出范围：不超方案

募得款物的使用**不得超出募捐方案与协议约定的范围**。需要变更用途的，应履行相应程序（涉及募捐方案规定用途变更的，应报原备案的民政部门备案；涉及捐赠协议约定用途的，应征得捐赠人同意）。

## 七、脚本用法

```bash
python scripts/check_cofundraising.py --input sample_data/sample_input.json --out ./合作募捐体检报告.xlsx
```

- **输入**：一份 JSON，合作募捐项目清单（`cofundraisings`）+ 机构资格（`org`）。
- **输出**：Excel 四表——**汇总 / 募捐明细 / 异常清单 / 待补材料**；无 openpyxl 时降级 CSV。

## 八、判定口径（八条）

| 编号 | 判什么 | 严重度 |
|---|---|---|
| C1 | 参与方均无公开募捐资格，或具资格方缺位／不具资格方未依托 | 高 |
| C2 | 未签书面协议 | 高 |
| C3 | 协议未载明募捐目的／方案／款物用途／各方权利义务 | 中 |
| C4 | 未对合作方进行评估 | 中 |
| C5 | 未履行监督义务 | 中 |
| C6 | 募得款物未全部纳入本机构账户 | 高 |
| C7 | 募捐方案未按规定公开 | 中 |
| C8 | 支出超出募捐方案与协议范围 | 高 |

规则编号与 `references/判定规则索引.md` 一一对应。

## 九、边界与降级（必读）

1. **命中项是待核项，不是违规结论**。如"未评估"可能是评估材料未归档，须核实。
2. **含真实机构与个人信息时**：脚本只读输入、不联网；报告对机构名与**人名**做打码处理。
3. **缺关键字段时不猜**：无募捐方案、无资格标记时，相关规则报"无法判定"。
4. **本技能不判合作方的一般准入与协议要素**（用「合作方准入与协议」），只判**公开募捐合作**的专门合规。
5. **本技能不替代法律意见**：涉及大额募捐、跨境或复杂结构的，应请专业律师判断。

## 十、什么时候不该用本技能

- 合作方的一般准入、协议四要素（权责／资金走向／成果归属／宣传口径）→ 用「合作方准入与协议」。
- 志愿者管理 → 属志愿者主题。
- 关联方识别与关联交易审查 → 属关联方专题。
