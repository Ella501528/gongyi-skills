# 判定规则索引（check_archive.py 的五条规则）

> 脚本只判**是否归集**，不判**要素是否合格**。要素完整性须人工按 SKILL.md 第三节判据复核。
> 命中的是**待核项**，不是违规结论。

| # | 规则名 | 触发条件 | 严重度 | 处置建议 |
|---|---|---|---|---|
| A1 | 必要材料缺失 | 必要项未在已收清单中 | 高 | 按第四节补件顺序补齐；结项前必须补完 |
| A2 | 建议材料缺失 | 尽量有项未在已收清单中 | 低 | 视情形补；能显著增强举证的说服力 |
| A3 | 整类空白 | 某一类 8 项全部未收 | 高 | 该类对应的业务环节可能整段没留痕，重点核查 |
| A4 | 结项前置不足 | 结项类（8 类）必要项缺 ≥ 1 | 高 | 不得结项；先补完 8.1 结项报告与 8.2 验收结论 |
| A5 | 未识别材料 | 输入的名称匹配不上清单与别名表 | 中 | 人工确认：属清单外材料（填入 `extra_items`）还是填错名称 |

---

## 判定口径

| 项 | 口径 |
|---|---|
| 必要项判定 | 只要未出现在已收清单中即算缺失，**不看补正情况** |
| 要素不全 | 脚本不判；人工复核（例：签收单无签字＝等于缺） |
| 一类提交多份 | 只要该序号有任一对应件即算已收 |
| 名称匹配 | 精确名 → 别名表 → 模糊包含；三级都匹配不上才计入"未识别" |
| 特殊材料 | 由 `extra_items` 补入，只计入汇总，不改变八类主结构 |

| 规则 | 手册节 | 说明 |
