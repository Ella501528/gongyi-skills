# 保值增值投资合规（民政部令第 62 号）

> 《慈善组织保值增值投资活动管理暂行办法》（民政部令第 62 号，2018-10-30 公布，2019-01-01 施行），共 20 条，是投资活动的唯一专项规章。上位条款为《慈善法》第五十五条。

## 一、投资活动三类情形（第四条）

| 类 | 情形 |
|---|---|
| （一） | 直接购买银行、信托、证券、基金、期货、保险资产管理机构、金融资产投资公司等金融机构发行的**资产管理产品** |
| （二） | 通过**发起设立、并购、参股**等方式直接进行**股权投资** |
| （三） | 将财产**委托**给受金融监督管理部门监管的机构进行投资 |

## 二、可投资财产范围（第五条）

```
可投资财产 ＝ 非限定性资产 ＋ 投资期间暂不需要拨付的限定性资产
```

| 财产 | 可否投资 |
|---|---|
| 非限定性资产 | ✅ 可以 |
| 限定性资产（投资期间暂不需拨付） | ✅ 可以 |
| 限定性资产（投资期间需拨付） | ❌ 不可以 |
| **政府资助的财产** | ❌ **禁止**（无条件） |
| **捐赠协议约定不得投资的财产** | ❌ **禁止**（无条件） |

⭐ 判据：政府资助的财产 + 捐赠协议约定不得投资的财产，**一律不得用于投资**，是无条件禁止，不因"暂不需拨付"而豁免。

## 三、八项禁止投资活动（第七条）

| 序号 | 禁止事项 |
|---|---|
| （一） | **直接买卖股票** |
| （二） | **直接购买商品及金融衍生品类产品** |
| （三） | **投资人身保险产品** |
| （四） | **以投资名义向个人、企业提供借款** |
| （五） | 不符合国家产业政策的投资 |
| （六） | 可能使本组织**承担无限责任**的投资 |
| （七） | 违背本组织宗旨、可能损害信誉的投资 |
| （八） | 非法集资等国家法律法规禁止的其他活动 |

⭐ **坑**：禁止的是"直接买卖股票"和"直接购买商品/金融衍生品"，**不是**禁止通过资管产品间接投资。慈善组织不得自己开户炒股，但可购买符合规定的资管产品。

## 四、制度要件（第八条）——财务和资产管理制度八项必备内容

1. 投资遵循的基本原则
2. 投资决策程序和管理流程
3. 决策机构、执行机构、监督机构的职责
4. 投资**负面清单**
5. **重大投资的标准**
6. 投资风险管控制度
7. 投资活动中止、终止或退出机制
8. 违规投资责任追究制度

## 五、关键操作要点

- **重大投资方案须经决策机构组成人员三分之二以上同意**（第九条），会议纪要须明确载明表决比例。
- **专项档案保存不少于 20 年**（第十二条），远超一般会计档案年限，须单独立卷。
- **负责人、理事、工作人员不得在被投资企业兼职或领取报酬**（第十五条），但可受托作股东代表、董事、监事（须有受托文件）。
- **未被认定为慈善组织的基金会同样受本办法约束**（第十九条），不能以"我不是慈善组织"为由规避。
- 财务和资产管理制度、重大投资情况应**向社会公开**（第十八条）。

## 六、投资收益税务

- 国债利息：免税（企业所得税法第二十六条）
- 银行存款利息：免税（122 号（四），源于免税/不征税收入）
- **理财/基金/股票/信托收益：应税**
- 增值税：金融商品转让有专门规定；贷款服务利息属应税。
