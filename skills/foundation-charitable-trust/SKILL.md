# 慈善信托与保值增值合规

基金会「闲钱怎么保值增值」的合规判断。核心依据：民政部令第 62 号（保值增值）+ 银监发〔2017〕37 号（慈善信托）+ 民发〔2024〕76 号（慈善信托支出与管理费）。

## 铁律

1. **机构中立**：正文写「某基金会 / 本机构」，不出现具体机构名、人名、金额。
2. **逐条引用**：结论落到「民政部令第 62 号第 X 条」等具体条款。
3. **无依据如实说**：拿不准的写「存在不确定性，建议向备案民政部门确认」。

## 核心速查（三问三答）

**① 什么钱能投？**
可投资财产 = 非限定性资产 + 投资期间暂不需拨付的限定性资产。
⚠️ **无条件禁止**：政府资助的财产、捐赠协议约定不得投资的财产（62 号第五条）。

**② 能投什么？**
三类：金融机构资管产品 / 发起设立并购参股股权投资 / 委托受监管机构投资（62 号第四条）。
⚠️ **八项禁止**（62 号第七条）：直接买卖股票、直接购买商品及金融衍生品、投资人寿保险、以投资名义向个人企业借款、不符合产业政策、承担无限责任、违背宗旨、非法集资。

**③ 收益要不要交税？**
国债利息免税（企税法 26 条）；银行存款利息免税（122 号（四））；**理财/基金/股票/信托收益应税**。

## 时效提醒

⭐ **慈善信托过渡期至 2026-12-31**：2025-01-01 前已备案的存量慈善信托设 2 年过渡期，过渡期内支出与管理费可按信托文件约定执行；过渡期满后应按 76 号执行。**2026 年是唯一可用于调整信托文件的完整年度。**
