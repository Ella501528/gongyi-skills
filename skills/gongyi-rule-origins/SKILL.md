# 慈善组织规矩来龙去脉

回答的是**"为什么"**，不是"是什么"。同一个问题，这本给背景，不给定论。

## 什么时候会用到它

| 场景 | 典型问题 |
|---|---|
| 写材料要解释一句"为什么这么规定" | 管理费用为什么分档、理事会为什么 5–25 人 |
| 同行或新同事问"这规定哪来的" | 慈善组织身份要不要申请、秘书长为什么必须专职 |
| 看到两种说法打架 | 年检还是年报、公募／非公募还叫不叫 |
| 判断某个口径是不是已经过期 | 每条都有"它变过没有"一段，直接看 |
| 内容创作找选题 | 每条都是一个完整的"规定—由来—变迁"故事 |
| 给决策层讲背景 | 用"对我们意味着什么"那一段 |

## 怎么用

```bash
# 查一条
python scripts/lookup_origin.py --q 管理费用

# 只看某一段（规定 / 为什么 / 变过 / 意味着）
python scripts/lookup_origin.py --q 年检 --seg 变过
python scripts/lookup_origin.py --q 秘书长 --seg 意味着

# 列出全部主题与四段标题
python scripts/lookup_origin.py --list

# 不截断
python scripts/lookup_origin.py --q 管理费用 --full

# 程序调用
python scripts/lookup_origin.py --q 监事 --json
```

## 每条的四段结构

| 段 | 回答什么 | 怎么用 |
|---|---|---|
| **规定是什么** | 现行规定与依据 | 引用时的依据来源 |
| **为什么会这样** | 这条规定当初是为了解决什么 | 写解释段、讲背景 |
| **它变过没有** | 口径是否调整过、在往哪走 | **判断手头材料是否过期** |
| **对我们意味着什么** | 落到机构动作上是什么 | 给决策层、给同事讲 |

**第三段是这本材料最大的用处**：行业里不少说法是从老文件传下来的，看着有理，其实口径已经变了。看这一条就知道该不该继续用。

## 十一个主题

1. 「两倍工资」这条线到底在跟谁比
2. 为什么有三种组织形式，「慈善组织」是第几种
3. 「公募／非公募基金会」与「公开募捐资格」的关系
4. 「慈善组织」这个身份哪来的、要不要申请
5. 基金会的秘书长为什么必须专职
6. 管理费用为什么有比例上限、而且不止一个数
7. 理事会为什么 5–25 人、领酬理事为什么不超过三分之一
8. 监事为什么不能由理事兼任
9. 年检和年报为什么有两个时间点、为什么还在改
10. 慈善组织为什么要有新闻发言人
11. 党建为什么重要、为什么成立登记时就要同步开展

## 边界与降级（必读）

- **这本是"理解的入口"，不是法规检索工具。** 文中出现的比例、时限、资格条件，**写进正式材料前必须回发布机关官网核对现行原文**。
- **政策在动。** 相关条例正在修订过程中，部分口径已调整、部分仍在调整。凡涉及具体数字，一律以最新公布的文本为准。
- **它讲的是"通用口径"。** 地方可能有单独规定，具体办事以属地要求为准。
- **不构成法律意见。** 涉及权利义务判断时，以现行法规与主管机关口径为准。
- 有查不到的问题时脚本会列出它覆盖的全部主题，**不要据此推断答案**。
- 数据文件缺失时脚本直接报错退出，不给空结果。
