# 善查查 · 公益机构尽职调查（方法框架版）

把一家公益机构，从一堆公开披露的审计报告与年报，变成一份能被别人复核的机构调查报告。

## 这一版给你什么

- 这套流程解决的三件事：**资金链网状追踪、灰色合规地带定级、实质性社会成效**
- 核心方法：审计报告给「名字」、工商穿透给「身份」、招采公告给「价格」，三者叠加才是完整资金链
- 三个阶段各在解决什么问题、产出什么，以及**为什么顺序不能颠倒**
- 报告必须覆盖的三块重点，与贯穿全报告的几条写作纪律
- 完整性靠什么保证：三层自证机制的思路
- 一份能力边界清单：哪些事这套流程做不到、取数会卡在哪

读完你能判断：这次核查适不适合用这条路子，值不值得投入。

## 这一版不给你什么

以下几类内容保留在完整版里：

- 三阶段十五个子步骤的完整命令
- 成套可执行工具（资料抓取、扫描件文字还原、工商穿透、关键人交叉、底稿生成、报告渲染、完整性自证）
- 报告七章骨架与写作纪律原文、风险分级规则、必查清单
- 交付包说明模板
- 三层自证的完整校验项与回归评测基线

**这一版讲清路怎么走；完整版提供把路走完的执行能力。**
