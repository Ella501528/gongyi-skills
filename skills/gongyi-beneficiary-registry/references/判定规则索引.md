# 判定规则索引（check_roster.py 的八条规则）

> 每条规则给出：规则名 → 触发条件 → 严重度 → 处置建议。
> **重要**：脚本命中的是**待核项**，不是违规结论。所有"高"严重度条目须人工确认后再写入正式报告。

| # | 规则名 | 触发条件 | 严重度 | 处置建议 |
|---|---|---|---|---|
| R1 | 追溯字段缺失 | 缺「姓名／标识」或「发放去向」或「发放方式」 | 高 | 补齐后方可发放；已发放的补签收或流水 |
| R2 | 资格依据缺失 | 缺「资格类别」或「认定依据」 | 高 | 补审核表或评审记录，说明"为什么是他" |
| R3 | 最小必要越界 | 采集了标记为超范围字段（证件全号／账号全号／家庭明细），或采集了未写用途的字段 | 中 | 删除或脱敏；保留的须写明用途与保管方式 |
| R4 | 未成年人未尽从严 | `minor=true` 但 `guardian_consent` 非 true | 高 | 补监护人同意记录；未补前不得发放 |
| R5 | 签收缺失 | `signed` 非 true 且无等价凭证（流水／签到） | 高 | 当日补签；补不出的写情况说明 |
| R6 | 给付凭证不匹配 | 发放方式为现金但无流水也无签收；实物但无签收 | 高 | 按给付形态补对应凭证（见 SKILL 第三节表） |
| R7 | 人群／区域分布偏离 | 名册的性别／年龄／区域分布与立项目标人群差异超出提示阈值 | 中 | 人工确认是否属客观原因；属执行的履行变更审批 |
| R8 | 变更无审批 | 对象状态为「退出／替换」但 `change_approved` 为空或 false | 中 | 补原因记录与审批；在报告如实反映 |

## 阈值与口径（R7）

| 项 | 口径 |
|---|---|
| 性别构成 | 目标为单一性别而该性别占比 < 60%，提示"人群可能偏离" |
| 年龄区间 | 超出立项目标年龄区间的对象占比 > 20%，提示"标准可能偏离" |
| 区域 | 出现立项目标区域之外的对象，逐条列出 |
| 提示阈值可调 | 脚本参数 `--threshold` 默认 0.6 / 0.2，可按机构实际调整 |

> 分布偏离来自客观原因（如目标人群自然减少）是常见情形，**提示不等于违规**。要的是：能说清原因、有审批、报告如实。

## 从严场景清单（R3、R4 补充）

出现下列任一情形，个人信息处理从严：

1. 受益人为未成年人（尤其不满十四周岁）；
2. 涉及健康、残障、家庭困境等敏感信息；
3. 涉及影像、声音等可识别信息；
4. 需向第三方（含宣传渠道、合作方）提供个人信息。

从严做法：能不带出的不带出；必须带出的，最小范围 + 明确用途 + 取得同意 + 留痕。
