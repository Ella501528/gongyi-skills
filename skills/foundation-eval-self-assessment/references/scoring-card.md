# 逐项打分预演表（模板与判定规则）

## 一、表格字段

| 字段 | 说明 |
|---|---|
| 指标编号 / 考查要点 | 来自清单底表 |
| 分值(满分) | 来自清单底表 |
| 类型 | 客观 / 主观 / 客观+主观 |
| **证据状态** | `齐备` / `部分` / `缺失` / `不确定` |
| **痕迹状态** | `成链` / `有痕不成链` / `无痕` / `不适用`（客观项填"不适用"） |
| **自评档** | 满分 / 部分得分 / 可能不得分 / 争议项 |
| **自评得分** | 数值（可为 0.5 分档，按机构内部约定） |
| **判定依据** | 一句话说清凭什么这么判（材料名 或 缺什么） |
| **风险等级** | 低 / 中 / 高（高风险=现场易被翻案） |
| **补救动作** | 具体动作 + 谁去做 |

## 二、判定规则

### 客观项（纯材料）

| 证据状态 | 自评档 |
|---|---|
| 齐备且形式合规 | 满分 |
| 齐备但形式有瑕疵（如无签章、无日期） | 部分得分 |
| 缺失 | 可能不得分 |

### 主观项 / 客观+主观

材料与痕迹**双条件**判定，取较低者：

| 证据 | 痕迹 | 自评档 |
|---|---|---|
| 齐备 | 成链 | 满分 |
| 齐备 | 有痕不成链 | 部分得分 |
| 齐备 | 无痕 | 可能不得分 |
| 部分 | 任意 | 部分得分 |
| 缺失 | 任意 | 可能不得分 |

### 数值/阈值项

**必须先算数**。步骤：

1. 确定法定或指标口径（分子、分母、是否含限定性、是否按年度均值）；
2. 用**同一数据源**计算（优先审计报告口径）；
3. 与阈值比较，得出达标 / 临界 / 不达标；
4. 临界项标"争议项"，并写明两种口径下的结果。

> **常见错误**：直接采用机构自算数，未核对口径。口径错误的"达标"在现场被翻案的风险极高。

## 三、区间来源标注（强制）

打分表完成后，选出**对总分影响最大、且最不确定的 5–10 项**，标注为"区间变量项"。最终给出的预估区间必须能由这些项解释：

> 中性情形 82 分（4A）；若"公益支出比例"按更严口径计算（−2.5）、"信息公开完整性"缺 2 项（−1.5），则保守情形约 78 分（3A 上沿）。

**不能出现"区间靠感觉给"的情况。**

## 四、输出形态

- 默认落地为 **xlsx**（字段如上，按板块分色、风险等级着色），或 md 表格；
- 对话中只给**摘要**：总分区间、等级落点、高风险项数量与前 5 项；
- 若机构要求简洁版，只输出"高风险清单 + 最小必要动作"。

## 五、举证方式建议

打分表应能回答："如果专家问'你凭什么自评满分'，机构能当场翻出什么？"
凡答不上来的项，**不要给满分**——这正是需要提前补的动作。
