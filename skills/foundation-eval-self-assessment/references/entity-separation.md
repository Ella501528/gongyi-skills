# 资料主体区分规则（强制）

> 适用范围：全部涉及机构资料的环节——存量盘点、指标匹配、自评打分、整改、答辩准备。
> **主体混淆是本项目最高等级的偏差来源**，因为它不会报错，只会安静地把分算错。

## 一、为什么必须区分

等级评估考查的是**参评机构自身**的治理、财务、项目与合规状况。合作方、执行方、关联方、母/子机构的材料，反映的是**别人的情况**：

- 合作机构的项目总结 → 证明**对方**做过，不能证明本基金会的项目管理与绩效；
- 执行方的财务票据 → 资金流向的旁证，**不是**本基金会的会计凭证；
- 关联方的制度文本 → 拿来套用属于**袭用**，实际是本机构制度缺失的自证；
- 上级单位或理事单位的荣誉 → 与参评主体无法律上的归属关系。

**核心原则：参评机构的自证材料不可替代。** 外部资料只能证明"这件事发生过"，不能证明"本机构建立了相应机制"。

## 二、四类归属

| 归属 | 代号 | 定义 | 用途 |
|---|---|---|---|
| 参评主体 | `SELF` | 以参评机构名义形成/持有，且其自身为权利义务主体的材料 | **唯一可用于指标对标与得分判定** |
| 关联方 / 合作方 | `AFFILIATE` | 关联方、合作机构、执行机构、供应商、受益单位等非主体的材料 | 仅用于关联风险识别与资金穿透核查，**不得计入主体评分** |
| 共有 / 联合 | `JOINT` | 联合发文、共建协议等双方共同署名的材料 | 可作主体参与的事实旁证，**不足以单独支撑**得分项；需配套主体自身的履职痕迹 |
| 归属不明 | `UNKNOWN` | 无法判定的材料 | **默认不计入主体**；进人工确认队列由用户指派 |

## 三、判定顺序（先硬后软，命中即停）

1. **主体清单硬匹配**：文件名或正文首部出现 `entity_rules.json` 中 `self.aliases` 任一词语（机构全称、简称、公章名称、统一社会信用代码后四位）→ `SELF`。
2. **关联方名单硬匹配**：出现 `affiliates[].aliases` 任一词语 → `AFFILIATE`。
3. **公章/落款/域名/账户线索**：落款单位、邮箱域名、银行开户名、合同甲方 —— 任一项指向第三方 → `AFFILIATE`。
4. **联合署名**：主体与关联方同时出现且均为主语 → `JOINT`。
5. **资源型旁证**：报告/照片/视频中出现场面、人群但无任何主体标识（如活动照片、合影、第三方媒体报道）→ `JOINT`，且**禁止**据此判"已归位"。
6. 以上均不成立 → `UNKNOWN`。

**冲突规则**：`SELF` 与 `AFFILIATE` 线索同时出现时，**不自动判 SELF**，降为 `JOINT` 并进人工确认。

## 四、用途边界（硬约束）

| 环节 | SELF | JOINT | AFFILIATE | UNKNOWN |
|---|---|---|---|---|
| 指标匹配 / 已归位判定 | 可用 | 仅作候选，标"待确认" | **禁用** | 禁用，进人工队列 |
| 自评打分与等级判定 | 唯一依据 | 不得单独支撑 | **禁用** | 禁用 |
| 迎评材料清单 / 归档树主体部分 | 可入库 | 可入库但标 `JOINT` | **必须分离目录** | 待指派后再定 |
| 关联关系与交易核查 | 参考 | 核心素材 | **核心素材** | 参考 |
| 资金穿透核查 | 起点 | 交叉 | 核心素材 | 参考 |
| 答辩口径与案例素材 | 可用 | 有限使用（须说明合作性质） | 谨慎使用 | 禁用 |

**AFFILIATE 资料唯一被允许参与的正式用途**就是关联方 Matrix 与穿透核查——且核查结论只进「整改行动方案」与「答辩风险提示」，不进主体得分。

## 五、物理隔离要求

- 主体归档树与关联方目录**分目录存放**，不得混在同一末级文件夹里：
  `archive/<机构简称>-归档/` 与 `archive/90-关联方资料-仅供风险核查/`
- 关联方资料生成独立索引 `affiliate_index.json` / `关联方资料索引.csv`，表头含：文件名、归属方、与本机构关系、涉及指标、用途限制。
- **任何由 AFFILIATE 材料支撑的表述，必须在输出中显式标注归属**，例如："【关联方材料·非主体自证】"。

## 六、穿透核查三条线（仅在用户要求或识别出关联风险时执行）

1. **人员线**：理事/监事/负责人/关键岗位在关联方的任职情况 → 交叉任职、决策独立性。
2. **资金线**：资金往来金额、频率、定价依据、审批层级、是否履行关联交易回避程序 → 是否被认定为利益输送。
3. **业务线**：业务依赖关系、采购是否公允、有无排他或非市场化安排 → 业务独立性。

每条线必须落到**证据链**：事项 → 证据文件名 → 归属方 → 缺口。缺任一段就写【证据不足】，不得补全。

## 七、禁止事项

- 禁止把关联方成果直接顶替主体自证（**不可替代**）；
- 禁止在缺少机构确认的情况下把 `UNKNOWN` 判为 `SELF`；
- 禁止因"看起来差不多""反正一起干的"而放宽判定；
- 禁止把穿透核查中的疑似结论写成定论——定性一律标注**以民政部门或审计机构认定为准**；
- 禁止把"AFFILIATE 有"改写汇报为"有"。缺项清单汇报时必须写明归属。
