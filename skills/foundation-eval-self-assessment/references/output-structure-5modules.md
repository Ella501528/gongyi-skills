# 固定输出结构（五模块）

> **任何一次面向用户的评估类最终输出，一律套这五个模块。**
> 顺序固定、标题固定、可以压缩篇幅但**不可以省略模块**。
> 用户-visible 标题用中文；内部中间产物不受此约束。

## 模块清单

### 模块一 · 指标匹配清单
官方指标 → 本机现状的逐条对照。

必需字段：指标编号 / 考查要点（原文口径）/ 分值 / 类型（客观·主观·复合）/ 规定依据（文件名+条款号或文号）/ 当前佐证（材料名+归属 SELF·JOINT·AFFILIATE）/ 状态（已满足·部分满足·不满足·待核验）/ 备注。

硬性要求：依据必须是正式文件名称，查不到写【待核验】，**不得留白或编造**；状态为"待核验"的项单独统计行数，不混进"已满足"。

### 模块二 · 现存短板梳理
从模块一提炼的问题清单，按**失分严重度 × 发生确定性**排序。

每条必须写清：涉及指标编号 / 问题描述（现状 vs 官方要求的具体差距）/ 影响分值 / 为什么会发生（根因一句）/ 归属（本机内部缺位 · 材料缺失 · 证据链不完整 · 口径存疑）。

**不允许只写"材料不全"**——必须指出差的是哪一份材料、对应哪一条要求。

### 模块三 · 整改行动方案
把短板转成可执行动作。

每条含：动作（动词开头，做什么文件/开什么会/补什么程序）/ 责任人（岗位或姓名）/ 时点（绝对日期或 T-N 天）/ 产出物（具体到文件名）/ 验证方式（谁来查、查什么）/ 优先级（P0 必做 · P1 应做 · P2 选做 · 战略性放弃）。

加急场景下：优先级与时点不得省略，且须明确哪些 P2 项被放弃及放弃代价。

### 模块四 · 迎评材料清单
要凑齐的文件级清单。

含：文件名 / 年度范围 / 格式 / 份数 / 来源部门或负责人 / 是否已具备 / 存放路径 / 是否为必备（必备 vs 加分佐证）/ 注意事项（如须盖章、须原件、须连续年度不可缺年）。

注意区分**必备**与**加分佐证**：写反会让用户在低价值材料上耗尽考前时间。

### 模块五 · 答辩风险提示
现场可能被问到且答不利的问题。

含：风险点 / 专家组可能追问角度（治理/党建/财务/项目/合规归组）/ 为什么危险（触发什么条线）/ 建议应答口径（一句话立场+支撑事实）/ 需携带的佐证 / 是否涉及敏感问题（关联交易、资金使用效率、信息公开滞后等）。

**风险不许只列一条**；最低覆盖治理、财务、项目各一条。涉及关联方的一条必写出处与口径。

**关联风险的分流**：关联关系与资金穿透核查（见 `references/entity-separation.md`）发现的**关联风险**结论，**同时进模块三（整改行动方案）与模块五（答辩风险提示）**——整改侧写清程序补正动作（回避程序、定价依据、关联方清单公示），答辩侧写清解释口径与携带佐证。两侧编号一致，便于交叉索引。

## 交付前言（五模块之前，必写）

四段，各一两句：

1. **版本与口径**：指标版本号、发文依据、核验日期；若发现版本落后须写明差异。
2. **证据边界**：本次基于哪些材料/是否用了公开信息/哪些结论属"未证实"。
3. **主体口径**：本次参与判定的材料归属分布（SELF/JOINT/AFFILIATE 各多少条），关联方资料已隔离至何处。
4. **免责声明**：本产出为迎评准备参考，**不构成法律意见、审计意见或对评估结果的承诺**；最终以民政部门/评估机构认定为准。

## 裁剪规则

| 场景 | 裁剪方式 |
|---|---|
| 完整迎评 | 五模块全展开 |
| **增量复盘**（已有基础、冲级） | 模块一压缩为"差异表"，模块二写深；模块三保留 P0/P1；模块四只列缺口；模块五全写 |
| **专项**（如只要答辩） | 非目标模块**标注"本次未覆盖"并写明盲区**，目标模块写深；不得假装全套已做 |
| **加急**（≤7 天） | 全部模块保留但各压到表格形态；模块三必须带责任人与时点；明确列出被放弃项 |
| **缺资料** | 模块一/四照给框架（标未核验），模块二/三只给通用风险，模块五保留——**禁止输出分值结论** |

裁剪只关乎**篇幅与深度**，不关乎模块是否存在。宁可每个模块三行字，也不能少一个模块。
