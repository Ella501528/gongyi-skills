# 等级区间反推与得分配置策略

## 一、三步反推

```
基准分（材料齐备即可得）  = 全部客观项满分之和
变量分（需要争取）        = 主观项 + 痕迹项 + 数值阈值项 + 争议项
目标等级线 − 基准分        = 必须争取到的变量分
```

**结论形态**：

> 基准分 68 分；4A 线 80 分 → 必须拿到 12 分变量分。
> 变量分共 32 分，其中"高概率可得"18 分 → 4A 可达，但**依赖 3 项关键动作**：……

## 二、得分配置的四象限

以"分值权重"为横轴、"补救难度"为纵轴，所有变量项落入四象限：

**战略性放弃**：对"低权重 × 高难度"与部分"低权重 × 中难度"项，明确建议放弃并写清放弃代价（丢几分、是否影响等级线、是否留下诚信记录的观感问题）。放弃是成本决策，不是偷懒——**必须由机构拍板**，我只提供代价分析，并在输出中标注"最终由机构决策"。

| | 低难度 | 高难度 |
|---|---|---|
| **高权重** | ① **立即做**（最高优先级） | ② **尽早启动**（可能跨月，需立项） |
| **低权重** | ③ 顺手做（批量补材料时一起处理） | ④ **战略性放弃**（除非时间充裕） |

**放弃是可选项**：资源有限时，明确放弃第④象限的项，把人力集中到①，是理性决策——但必须**显式记录放弃理由**，让决策层知情。

## 三、目标等级对应的动作强度

| 目标 | 特征 | 资源投入 | 风险 |
|---|---|---|---|
| 保底（如保住现有等级） | 只保客观项与硬指标 | 低 | 若竞争对手执行力强，相对位次下降 |
| 争取（如 3A→4A） | 主攻高权重主观项 | 中高 | 需要 3–6 个月准备期 |
| 冲刺（如 4A→5A） | 全项拉满 + 现场呈现 | 高 | 边际收益递减，最后几分成本最高 |

> **实务建议**：先确认"从当前基准分到目标线的差距"，再判断强度。**差距 ≤5 分**：补材料即可；**5–12 分**：需机制性改进；**>12 分**：需提前一年布局。

## 四、时间倒排（以参评日为基准）

| 时点 | 必须完成 |
|---|---|
| 参评日前 6 个月 | 指标版本核对、基准分测算、识别"实质不符型"问题（这类最慢） |
| 参评日前 3 个月 | 补齐证据与台账、数值口径复核、信息披露完整化 |
| 参评日前 1 个月 | 现场物料准备、应答口径演练、材料交叉印证检查 |
| 参评日前 2 周 | 归档定稿、责任人确认、现场演示路径走查 |
| 评估当日 | 按分组对应接待、材料随时可调取 |

## 五、给决策层的一句话

**"不投入资源能拿到的分（基准分）是多少，离目标差几分，差的分要靠哪三件事补——这是需要您拍板的。"**

把诊断结论压缩成这一句，是这个技能最有价值的输出。
