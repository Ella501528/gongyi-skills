# 基金会等级评估·自评预演与失分诊断

按现行评估指标逐项打分预演，给出三档等级区间、高风险失分清单与整改优先级矩阵

## 能力

面向基金会/社会组织等级评估的自评模拟与失分诊断。按末级考查要点逐项打分预演，输出乐观/中性/保守三档总分与对应等级区间、按「必然丢分/高风险丢分/边界争议」三类归集的高风险失分清单（含丢分原因、补救动作、补救成本），以及按「分值权重 × 补救难度」排序的整改优先级矩阵。含五板块常见失分点库、等级线反推策略、打分卡与优先级矩阵规则。

## 触发方式

在对话中直接描述需求即可，例如：

- 「把我们今年的评估指标表拆成逐项资料清单」
- 关键词：公益慈善、等级评估、自评诊断、失分分析、以评促建
