# 自评模拟与失分诊断

不做"我们大概能得多少分"的模糊判断——把每一分落到**具体条目、具体证据、具体风险**上。

## 一、产出物

一次完整的诊断输出四样东西：

1. **逐项打分预演表**：每个末级考查要点给出 `自评得分 / 满分 / 判定依据（证据是否齐备）` 与 `风险等级`；
2. **得分预估区间**：给出"乐观 / 中性 / 保守"三档总分与对应等级，并说明区间来源（哪些项是区间的主要变量）；
3. **高风险失分清单**：按"必然丢分 / 高风险丢分 / 边界争议"三类归集，每项写明**丢分原因 + 补救动作 + 补救成本**；
4. **整改优先级矩阵**：按"分值权重 × 补救难度"排出动手顺序（见 `references/priority-matrix.md`）。

**输出结构**：以上四样必须并入固定五模块（见 `references/output-structure-5modules.md`）——预演表对应**指标匹配清单**，高风险失分清单对应**现存短板梳理**，优先级矩阵对应**整改行动方案**，并补出**迎评材料清单**与**答辩风险提示**。**冲级/增量场景**下模块一压成"差异表"，模块二写深，五模块一个都不能少。

**打分只认主体材料**：判定依据必须来自参评机构自身资料（`SELF`）。联合材料（`JOINT`）只能作旁证，关联方材料（`AFFILIATE`）**不得计入本技能的任何得分判定**——发现候选证据为关联方材料的，该要点改判"不满足/待补"，不得给分。

## 二、打分方法

### 逐项判定的四档法

| 自评档 | 含义 | 判定依据 |
|---|---|---|
| **满分** | 材料齐备、执行痕迹完整、指标口径完全满足 | 能当场指出对应文件与条款 |
| **部分得分** | 材料齐备但执行痕迹不足，或标准未完全达到 | 说明缺口在哪一环 |
| **可能不得分** | 缺少关键证据，或存在明显不符情形 | 写明缺什么、不符在哪 |
| **争议项** | 是否达标存在解释空间 | 写明双方可能的口径，提示"最终以评估机构认定为准" |

> **禁止行为**：不要在证据不明时"默认给满分"。**自评预演的价值恰恰在于暴露不确定项**；若用户要求"往高里报"，明确说明：高估会导致迎评资源错配，现场被翻案反而更被动。

### 判定依据的锚点

判定必须锚定**指标原文口径 + 法规条款**，不能凭印象。以逐项清单（末级要点 / 分值 / 类型）作为打分底表，无现成清单则先按官方指标表逐项展开：

- 客观项：看材料是否存在且形式合规；
- 主观项：看**执行痕迹**（会议记录、签到、照片、沟通留痕、成效数据、受益方反馈）是否形成了可核查的链条；
- 比例/数值类：**先算数再判断**（如公益支出比例、管理费用比例、信息公开条数、理事会到会率）。

## 三、失分诊断的三个高发层面

详见 `references/common-deductions.md`（按内部治理、党建、发挥作用、遵章守规、诚信建设五板块整理）。归纳起来，失分很少来自"没做事"，绝大多数来自三类断层：

1. **做了但没留痕**——事项办了，记录不全，主观项直接掉档；
2. **留了痕但不成链**——决策、执行、结项各自有记录，但无法互相印证（如立项决议有、执行过程缺、结项无评估）；
3. **口径不一致**——同一事实在不同材料里表述不一致（决算与明细账不符、年报数与财务账不符、公开信息与内部台账不符）。**这类问题杀伤力最大**，因为它同时损害真实性与可信度。

## 四、等级区间的反推策略

见 `references/grade-strategy.md`。核心思路：

1. 先算**基准分**（所有"材料齐备即可拿"的客观项之和）——这是不投入资源也基本能拿到的分；
2. 再算**变量分**（主观项、执行痕迹项、数值阈值项）——这是策略空间；
3. 用"目标等级线 − 基准分 = 需要争取的变量分"，反推**必须拿满哪些项、可以放弃哪些项**；
4. 给出"若目标是 X 级，最小必要动作清单"。

## 五、工作流程

1. **确认口径**：机构、年度、指标版本（版本号、文号、施行日期须逐条核验，不得凭记忆）；
2. **确认底表**：有逐项清单（含末级要点 / 分值 / 类型）则直接复用；否则先按官方指标表逐项展开；
3. **收集证据状态**：按板块逐项问用户"这份材料有没有 / 执行痕迹有没有"——用**结构化提问**（是/否/部分/不确定），不要开放式空问；
4. **逐项打分**：输出打分表（默认落地为 xlsx 或 md，不刷屏）；
5. **汇总区间与等级**：给出乐观/中性/保守三档；
6. **输出失分清单与优先级矩阵**：按分值权重排序，标注补救动作与责任角色；
7. **落到整改台账**：把失分项转为六字段台账（问题 / 整改动作 / 责任角色 / 时限 / 证据形式 / 复查时点），字段规范见 §七。

> 若机构希望保持匿名或不做完整预演，可只对**分值最高的前 20% 条目**做重点诊断——投入产出比最高。

## 六、注意事项

- **诊断不是审计**：本技能基于机构自述与自备材料做**管理判断**，不做财务审计与法律定性；
- **区分事实与推断**：打分表里明确标注哪些是"已核实"，哪些是"待核实（据机构自述）"；
- **不承诺结果**：预估等级是**规划工具**，不是评估结果预测；表述始终为"中性情形下大致落在某区间"；
- **敏感性**：失分清单可能涉及内部管理问题，输出前提示用户注意分发范围（对外版本应删去内部责任表述）。

## 七、整改台账字段（失分项落地用）

每一条失分项转一行台账，六字段缺一不可，否则无法验收：

| 字段 | 填写要求 |
|---|---|
| 问题描述 | 对应指标编号 + 缺什么，不写笼统结论 |
| 整改动作 | **必须可验证**——写"补齐 2023–2025 年理事会签到表并扫描归档至 0102 文件夹"，不写"加强理事会管理" |
| 责任角色 | 落到岗位，不到人；一人多岗时合并 |
| 时限 | **具体日期**，不写"尽快""近期" |
| 证据形式 | PDF / 照片 / 台账 / 说明函 / 备案回执，缺形态不验收 |
| 复查时点 | 完成后 X 个月回头看，尤其针对"执行不足型"问题 |

> 整改闭环材料（整改方案、完成证明、制度修订件）应主动归档到对应指标文件夹，
> 直接成为下一轮迎评的现成证据。
