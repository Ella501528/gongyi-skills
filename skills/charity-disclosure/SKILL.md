# 慈善组织信息公开合规作业工具箱

本技能是慈善组织信息公开合规的通用作业工具箱，供任意 Agent 即取即用。使用前先读取本目录下的 `references/`（按 spine/evidence/maturity 三类聚类），输出时套用 `templates/`。

## 三种工作模式（先判模式，再开工）

> 在原有「两种工作模式」（内部自查 / 外部评查）基础上，把内部自查细分为 A 体系搭建与 B 合规体检，形成三模式。两内部模式与外部评查的口径红线不变。

| 模式 | 服务对象 | 信息源 | 产物 | 工序序列 |
|---|---|---|---|---|
| **A 体系搭建** | 从零建体系的机构（内部） | 机构自持材料 + 平台后台 + 对外渠道 | 全清单 + 责任分工 + 整改行动方案（按需附资料盘点） | 0→1→2→S(按需)→5 |
| **B 合规体检** | 已有机制、查缺口的机构（内部） | 机构自持材料 + 平台后台 + 对外渠道全检 | 上述 + 数据核查 + 缺口诊断 + 整改台账 | 0→1→2→3→4→S(按需)→5 |
| **C 外部评查** | 外部使用者（捐赠人、媒体、评估方、同行、拟合作方） | **仅对外可检索到的公开内容** | 公开度评查报告、公开度比例、逐项四态判定、核验盲区清单 | 0→1R→2R→(按需 3R)→4R |

两内部模式（A/B）不得走模式 C 的外部口径；模式 C 不得走内部「盘家底」（现为按需支撑工序 S）。**两模式不得混用口径**：内部自查的评分卡（`templates/06`）问"你履行了没有"；外部评查（`templates/09` + `maturity-rating-rubric.md`）只能问"外部看得见什么"。把内部口径套到外部评查上，会得出又虚又假的结论。

## 作业顺序

### 内部自查（模式 A 体系搭建 / 模式 B 合规体检）

1. **读依据**：`references/spine/three-tier-checklist.md` —— **依据与标准库（必读）**；**事项编号的唯一真源是 `templates/01`（61 项）**
2. **定时限**：`references/spine/deadlines-and-thresholds.md` —— 时限速查、阈值判定、责任与红线
3. **补平台层**：`references/spine/platform-rules.md` —— 慈善中国与互联网募捐平台规则（L2，最易漏）
4. **搭框架**：`templates/01` 出分层全清单（61 项；层标 L1 法定 53 / L2 平台 3 / L3 鼓励 4 / 非机构义务 1）
5. **查公开状态（工序 2「现状核查」，核心）**：按清单逐项核对**对外渠道上实际公开了什么**，落四态并留痕。信息公开的作业对象只有一个——这家机构对外公开了什么，**本步不可后置、不可省略**。内部自持材料不是公开证据
6. **给方案**（模式 A/B）：`templates/13` 缺口诊断 + `templates/14` 整改行动方案；FTI 自评加 `templates/10`
7. **盘家底（按需支撑工序 S，非必经）**：仅当需要分清"材料没做 vs 做好了没发"或需归档规范时启动 → `templates/11` 本地资料盘点 + `templates/12` 归档规范。**其结论不得回填公开状态、不得进评分**
8. **核条款**：超出 references 覆盖范围或与用户材料冲突时，**必须联网核对原文**后再落笔；核对不到写"未检索到明确依据"

### 外部评查

1. **读口径**：`references/evidence/maturity-rating-rubric.md` —— 判定四态、公开度比例算法（完整分母口径）、盲区率、只给百分比不设等级、五条计分纪律
2. **定渠道**：`references/evidence/external-evidence-sources.md` —— 检索顺序、证据等级 A–D、留痕要求、"查不到"的四类处理
3. **套清单**：`templates/01-disclosure-checklist.md` —— 61 项真源，逐项落四态并留痕
4. **出报告**：`templates/09-org-disclosure-review-report.md` —— 15 章报告模板（`templates/10` 是 FTI 内部自评表，**外部评查不用**）
5. **必查依据原文**：判定"未公开"前，回 `references/spine/legal-basis.md` 确认该项的法定要素与时点
6. **FTI 辅助**：可用 `references/maturity/fti-benchmark.md` 作行业水位对照，但**FTI 是 D 级证据，不得作为"已公开"的证据**

## 使用铁律

1. **条款号不得凭记忆书写**。references 中已核对的条款可直接引用；未覆盖的必须联网核对原文。**81 号令条文号以 `three-tier-checklist.md` 的总表为准**，61 号令条款号已作废。
2. **三层不得混编**。L1（法定，写"应当"）/ L2（平台规则，写"平台要求"，**不写"依法"**）/ L3（鼓励，写"建议"，**不写"应当"**）。L3 不计入合规分母。
3. **效力分层**：只有法律、行政法规、部门规章、政策文件、政府公告可作正式义务依据；平台规则属合同/准入约束；解读、指南、问答、标准、模板、案例、FTI 等只能作参考，引用时标注"非法律依据，仅供实务参考"，语气改为建议性。
4. **地方规则**：用户未明确地区时只用全国性依据；明确地区后可引用地方规则并标注"仅适用于该地区"。
5. **鼓励 ≠ 应当**：《办法》第十八条第二款、第二十九条为鼓励性规定，不得写成强制义务；外部评查中不计入应公开分母。
6. **FTI 只观测基金会**。社会团体、社会服务机构不适用 FTI，不得对这类机构说"你们的 FTI 分数"。FTI 是第三方评估（D 级证据），**不得作为"已公开"的证明**，也不得用作机构整体评价背书。
7. **不得编造数据、案例、处罚结果**。缺失信息写"待核实"或"未检索到明确依据"。
8. **外部评查第一铁律：无法核实 ≠ 未公开**。二者必须分表分列，任何情况下不得合并计数。
9. **完整分母**：无法核实项**保留在分母内、分子记 0**，另列盲区清单。不得把"查不到"从分母剔除（会让比例虚高），也不得把它计成"未公开"。**分母是"法定应当公开多少条"，不是"本次检索覆盖了多少条"。**
10. **只给百分比，不设等级**。外部评查不得输出 A–E 等级、分档、星级或徽章，也不得使用"完备／良好／薄弱"这类档位词。
11. **机构名称必须用登记全称检索**。简称（如"XX""某某"这类常见词）会混入大量无关主体，导致判定全盘失真。
12. 每次交付末尾附免责声明：本成果为合规参考，不构成正式法律意见。

## 常见误判（作业前扫一眼）

| 误判 | 正确做法 |
|---|---|
| 第三方透明度评分高 → 认定已公开 | 第三方（D 级，含 FTI）只能作线索，只用平台原始条目（A 级）作证 |
| 官网没找到 → 认定未公开 | 转"无法核实"，说明仅检索了自有渠道 |
| 用"这类机构一般都会公开"补分 | 惯例不是证据，无证据即无法核实 |
| 未公开 → 直接写成违规 | 公开度≠合规结论，违法与否由登记机关依个案认定 |
| 用旧年度条目充当本年度已公开 | 逐年度分列，标明覆盖年度 |
| 把平台规则写成法律义务 | L2 依据写"平台规则"，后果写"下架/停止合作"，不写"依法处罚" |
| 把 FTI 指标写成法定要求 | L3 只写"建议/鼓励"，不计入合规分母 |
| 对非基金会套用 FTI | FTI 只观测基金会，社团与民非不适用 |
| 把无法核实项剔出分母算比例 | 无法核实保留在分母内、分子记 0；剔除会让比例虚高、越难查越占便宜 |
| 给公开度打 A–E 等级 | 只给百分比；等级容易被读成对机构的优劣背书 |
