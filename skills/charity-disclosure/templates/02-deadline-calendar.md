# 【年度】信息公开时限日历

**机构名称**：【待填】　**是否具公开募捐资格**：【待填】　**是否有业务主管单位**：【待填】
**制表日期**：【待填】

> 本日历按法定义务倒推作业节奏。**固定节点**来自法条明文期限；**建议节点**为实务倒排，属建议性安排，非法律义务。

## 一、固定法定期限（不可调整）

| 期限 | 事项 | 依据 | 责任岗位 | 状态 |
|------|------|------|---------|------|
| 每年 5 月 31 日前 | 公开年度工作报告和财务会计报告 | 《办法》第六条 | | |
| 每年 5 月 31 日前 | （不具公募资格）公开上年度重大慈善项目实施情况 | 《办法》第十一条 | | |
| 每年 5 月 31 日前 | 向民政部门报送关联方名单及关联关系说明 | 《办法》第十五条 | | |
| 事项发生/形成后 30 日内 | 基本信息公开与变更公开 | 《办法》第四条、第十六条 | | |
| 事项发生后 30 日内 | 重大资产变动、重大投资、重大交易及资金往来 | 《办法》第十三条 | | |
| 行为发生后 30 日内 | 六类关联交易 | 《办法》第十四条 | | |

| 项目终止后 3 个月内 | 剩余财产处理情况（有剩余的） | 《办法》第九条 | | |
