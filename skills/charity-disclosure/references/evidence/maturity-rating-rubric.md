# 机构信息公开程度评查口径（外部评查用）

> 本文件是「公开度评查官」的**唯一判定与计算口径**。内部自查（我方即被评机构）不走本口径，走 `templates/06-self-audit-scorecard.md`。
> 本口径为**实务方法论，非法律依据**。它不创设义务；每一项义务的成立仍以 `three-tier-checklist.md` 与 `templates/01-disclosure-checklist.md` 中的条款为准。
> 文件名沿用历史（`rubric`），但本口径**已不设等级、不评分档**，见第四节。

## 一、评查与自查的根本区别

| | 内部自查 | 外部评查 |
|---|---|---|
| 信息源 | 机构自持材料（章程、台账、系统后台） | **只能依靠公开可检索到的内容** |
| 已知前提 | 知道该公开什么、实际公开了什么 | **不知道**，只能从外部逐项核实 |
| 结论性质 | 合规状态判定 + 整改 | 公开度画像 + 缺口提示 |
| 最大风险 | 漏项 | **把"我没检索到"误判成"它没公开"** |

**因此外部评查的第一铁律：无法核实 ≠ 未公开。** 二者必须分别标注，绝不能合并计数。

**第二条铁律：内部自持材料不是公开证据。** 手上有没有材料，只决定"能不能发"，不决定"发了没有"。

## 二、判定四态

对每一个法定公开事项，只能落到以下四态之一：

| 态 | 含义 | 成立条件 |
|---|---|---|
| **已公开** | 检索到该项内容，且形式要件满足 | 有可访问的公开证据，且内容要素齐全 |
| **部分公开** | 检索到该项，但内容不全 | 缺少法定要素之一（如项目公开缺受益人群确定方式） |
| **未公开** | 有足够证据表明该项不存在 | **须同时满足**：①已检索全部 A 级渠道；②无任何 C 级渠道提及；③检索时点明确记录 |
| **无法核实** | 证据不足以下结论 | 渠道不可访问、条目被删、需登录、平台故障、内容过旧、属定向告知型义务等 |

**"未公开"是重结论，必须写清检索范围与检索时点**，否则只能落到"无法核实"。

**逐事项独立判定**：四态是对「每一个法定公开事项」分别落态，不得跨事项合并。例如某机构「年度工作报告=已公开」但「重要关联方=无法核实」，是两个独立判定，不是给该机构贴一个"部分公开"标签。报告须按事项分列四态，再汇总。

### 2.1 "查不到"的四种类型（取证阶段即须定类型）

无法核实时，必须同时写明**属于哪一类**，这决定补证路径与读者该不该采信：

| 类型 | 含义 | 典型项 |
|---|---|---|
| **A 线下实物型** | 内容在线下或实物载体，须到场才能看 | 募捐现场公示、住所纸质文本 |
| **B 定向告知型** | 义务本身只要求向特定对象告知，外部天然无从核 | 向捐赠人、受益人告知类事项 |
| **C 内部动作型** | 属内部动作，不产生对外条目 | 制度与专人、归档留存 |
| **D 常规不在网络展示型** | 常规不通过网络展示、或属报送件 | 关联方名单报送件、备案受理过程 |

**D 类是"常规查不到"，不是"机构有问题"**——报告须如此表述，不得暗示机构未履行。

## 三、公开度比例怎么算（完整分母口径）

### 3.1 单一主指标

只给一个数：**公开度比例 = 分子 ÷ 分母 × 100%**

- **分母 = 该机构按画像筛出的应公开项数。** 从 `templates/01` 的 61 项出发，按机构画像（是否具公募资格、是否开展公开募捐活动、是否涉慈善信托、是否开展定向募捐、是否招募志愿者、有无业务主管单位）筛出适用项，再扣除"不适用"与"非机构义务"项。**分母不是检索到的项数，也不是"能确认的项数"。**
- **分子 = 已公开项 × 1 + 部分公开项 × 0.5。**
- **未公开项记 0。**
- **无法核实项：保留在分母内，分子记 0。**

### 3.2 无法核实项为什么不从分母中剔除

这是本口径与旧版口径**最重要的差别**。

把无法核实项剔出分母，等于让"查不到"变成"不用查"：**机构越难被核到，分母越小、比例越高**。这既违反直觉，也会系统性地虚高。

分母的意义是"这家机构按法定要求**应当**公开多少条"，而不是"本次检索**覆盖**了多少条"。所以无法核实项必须留在分母里，并在分子上记 0（保守下限），同时另列盲区清单说明是哪几项、为什么查不到。

### 3.3 两个参照值（只作灵敏度检查，不得当结论）

| 参照值 | 算法 | 用途 |
|---|---|---|
| **上界** | 假设全部无法核实项都已公开 | 说明"最乐观能到多少" |
| **已核实范围内比例** | 分母只算已核实的项 | 说明"在查到的部分里"公开得如何 |

三个数并列出现时，**必须明确标注主指标是哪一个**（即 3.1 的公开度比例），且说明另两个不能当结论用。

### 3.4 核验盲区率

**盲区率 = 无法核实项数 ÷ 应公开项数 × 100%**

- **> 40%** 时，须在报告开头**置顶声明**：本次公开度无法可靠判定，主要原因是证据不足。
- 盲区率**不改变**主指标的计算方式（无法核实始终保留在分母内），它只影响读者对主指标的采信度。

### 3.5 算例

应公开 48 项；已公开 37、部分公开 4、未公开 0、无法核实 7。

- 分母 = 48（含那 7 项无法核实）
- 分子 = 37×1 + 4×0.5 = 39
- **主指标 = 39 ÷ 48 = 81.3%**
- 上界 =（39 + 7）÷ 48 = 95.8%（参照）
- 已核实范围内 = 39 ÷ 41 = 95.1%（参照）
- 盲区率 = 7 ÷ 48 = 14.6%（< 40%，主指标可采信）

## 四、呈现方式：只给百分比，不设等级

**不得给出 A / B / C / D / E 之类的等级、分档、星级或徽章。也不得使用"完备 / 良好 / 基本 / 薄弱 / 严重不足"这类定性档位词。**

理由：分档容易被读成对机构的分类评价或质量背书，而本口径只测"**公开覆盖了多少**"，不测"**公开得好不好**"，更不测机构整体运作水平。

呈现要求：

- 主指标以百分比呈现，并附表项数明细：应公开 N ／ 已公开 X ／ 部分公开 Y ／ 未公开 Z ／ 无法核实 W。
- 参照值与盲区率可并列，但须标明性质（参照值不作结论）。
- 不得把百分比换算成等级、分数段、排名或推荐结论。

## 五、五条计分纪律

1. **不得用"惯例"补分。** 某类机构一般都公开了某事项，不构成该机构已公开的证据。
2. **不得用"缺失即违规"下结论。** 未公开只说明公开度不够，是否构成违法须另行判断（涉及时限、主观状态、是否属豁免情形），这属法律判断，不在评查结论内。
3. **不得把"无法核实"从分母中剔除**，也不得把它计成"未公开"——两者都会扭曲结论。
4. **不得用内部台账或机构自述抬高外部比例。** 外部评查只能采信外部可检索到的证据。
5. **不得用第三方评分、排行榜、透明指数（FTI）作为"已公开"的证据**（属 D 级证据，永远不能作已公开证明）。

## 六、报告必须交代的五件事

1. **检索范围**：查了哪些渠道、各自检索时点、哪些渠道不可用。
2. **分母构造**：应公开项数怎么来的、按什么画像筛的、哪些项被排除及理由。
3. **核验盲区**：无法核实事项清单、原因，以及**"查不到"的类型**（A/B/C/D 四类）。这是评查的质量声明，不是免责套话。
4. **证据等级**：每条判定注明证据来源等级（见 `external-evidence-sources.md`）。
5. **口径声明**：本评查只评价"公开程度"，不评价机构整体运营水平，也不构成合规结论或法律意见；比例只是"事项覆盖度"，不是透明度总分。
