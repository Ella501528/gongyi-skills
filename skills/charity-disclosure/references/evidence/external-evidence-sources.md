# 外部取证手册：渠道、证据等级与作业方法

> 供「公开度评查官」使用。本文件是**外部评查链的作业手册**：讲清"去哪儿查、按什么顺序查、查到什么算证据、查不到怎么办"。
> **含时效性风险**：平台域名、栏目路径与开放程度会变，使用前须实际访问确认；本文件记录的路径若已失效，标"渠道已变更，需重新确认"，不得沿用旧结论。

---

## 一、证据等级（每条判定必须标注）

| 等级 | 来源 | 可否单独支撑"已公开" | 可否单独支撑"未公开" |
|---|---|---|---|
| **A** | 全国慈善信息公开平台原始条目；民政部门官网公告；中国社会组织政务服务平台登记与年报信息 | 可以 | 可以 |
| **B** | 机构官网、机构官方公众号、机构自办公开专栏 | 可以 | 不可以 |
| **C** | 权威媒体、行业媒体报道；政府文件转载 | 可以（需注明为转载） | 不可以 |
| **D** | 第三方数据库、排行榜、评估机构评分、他方汇编 | **不可以**，仅作检索线索 | 不可以 |

### 关键规则

- **D 级永远不能作为"已公开"的证据**。第三方给了该机构一个不错的透明度分数，不等于该机构公开了某项法定内容。拿 D 级充数是最常见的方法论错误。
- **B 级不能单独支撑"未公开"**。官网没找到，只能说明官网没有，不能说明平台没有。
- **内部自持材料不是公开证据**。机构手里的台账、底稿、系统后台记录，只说明"能不能发"，不说明"发没发"。
- 判定"未公开"必须**A 级渠道检索无果 + 无 C 级提及 + 检索范围与时点已记录**，否则落到"无法核实"。

---

## 二、检索顺序（固定，不要跳步）

1. **全国慈善信息公开平台（慈善中国）** —— 第一顺位。《慈善组织信息公开办法》第三条指定的法定公开平台，也是评查的主战场，**绝大多数法定事项只在这里才构成 A 级证据**。
2. **中国社会组织政务服务平台** —— 核查登记信息、年报公示、是否被列入活动异常名录或严重违法失信名单；验证机构性质与慈善组织认定状态。
3. **民政部门官网** —— 地方民政部门公告、行政处罚公示、年检结论、备案公开。
4. **民政部指定互联网募捐平台** —— 该机构在平台上线的项目与财务披露情况。
5. **机构自有渠道** —— 官网、公众号、微博，用于渠道一致性比对。
6. **媒体与第三方** —— 仅作线索与补充，标注 C/D 级。

## 三、作业方法：按渠道走，不按清单顺序走

### 3.1 为什么要按渠道走

清单是**事项维度**（61 项，A1–I6），检索是**渠道维度**。按清单逐项去查，意味着在 8 类渠道之间来回跳几十次——同样的页面要打开很多遍。

**正确做法：进一个渠道，把这个渠道能出的事项一次性全部取到；渠道走完，再比对清单找缺口。**

### 3.2 渠道分配（通例，按机构画像会变）

| 渠道 | 覆盖事项数 | 说明 |
|---|---|---|
| 慈善中国 | 43 | 绝大多数法定事项的 A 级来源 |
| 其他渠道合计 | 16 | 现场/载体、互联网募捐平台、登记机关、机构住所、机构自有渠道、定向告知、跨渠道一致性核对 |
| 不产生对外条目 | 2 | 内部动作类（制度与专人、归档留存），进盲区清单 |

**逐项渠道归属见 `templates/01-disclosure-checklist.md` 的"渠道"列；变动事项集合时该列须同步维护。**

## 四、慈善中国作业要点

### 4.1 栏目结构

机构主页下逐栏读取：**基本信息**（下设十余个子标签）/ 年度工作报告和财务会计报告 / 公开募捐情况 / 慈善项目有关情况 / 慈善信托有关情况 / 重大事件 / 其他公示信息。

逐子栏目记录：**条目是否存在、条目数、最新条目年度、内容要素是否齐全**。

### 4.2 六个实测坑

| 坑 | 表现 | 应对 |
|---|---|---|
| **子标签要逐个点开** | 基本信息下有十多个子标签，只读默认页会漏掉理事会、监事、重要关联方、本组织制度、费用标准等 | 按子导航文字逐个点击，不要试图用 URL 参数切换子栏目 |
| **列表只读第一页会丢数据** | 理事会、关联方、关联交易、重大事件等列表分页 | 必须翻完所有页；重大事件可达数百条 |
| **年报只挂近几年 ≠ 机构只存在几年** | 平台年报栏通常只保留近六年 | 结合成立日期判断，不得据"没有更早年报"下结论 |
| **成立时间 ≠ 慈善组织认定日期** | 两个日期不同，且认定日期决定部分义务的起算 | 分别记录，注明来源 |
| **站外无会话直连会被滑块拦截** | 首次直接访问可能被重定向到滑块验证页 | 用持久化浏览器会话（保留 cookie）后不再反复触发；仍被拦时落"无法核实"，**不是"未公开"** |
| **平台条目 ≠ 全部内容** | 页面只展示汇总表，正文细节在附件里 | 见第六节"穿透式取证" |

## 五、机构自有渠道：先找全账号，再判公开

### 5.1 四来源交叉找全账号

1. 平台登记信息里机构自己填报的渠道（A5）
2. 年报正文中的渠道说明
3. 机构官网页脚与"联系我们"（**最省事的来源，常被漏**）
4. 搜索引擎与认证主体反查

### 5.2 检索词原则：宽进严出

- **宽进（找）**：至少换 4 组词各检索一遍——登记全称 / 简称或去通名核心词 / 品牌项目名 / 发起人姓名 + 机构类词。
- **严出（认）**：候选账号须查"账号主体"，**主体为该机构登记全称**（或其分支、专项基金）才计入。
- **边界**：机构自己发布的算公开（账号名不含全称、要多轮关键词才找到，都不影响其"已公开"性质）；媒体、第三方转述、排行榜只作 C/D 级线索。
- **"不好找"与"没公开"分开记**：渠道显著性单列一栏，不进四态判定、不进分母，只写进建议。

## 六、穿透式取证：三条已验证有效的路径

平台页面往往只给汇总，法定要素藏在附件里。以下三条路径实测能把多项从"无法核实"转为确定判定：

1. **穿透年报正文**。年报 PDF 正文内嵌大量法定字段——关联方关系及其交易、业务主管单位审查意见（含结论与签章日期）、志愿者情况、募捐方案备案时间、机构住所。**只读平台页面的汇总表会误判为"未公开"。**
2. **取回制度原件并 OCR**。机构常把制度以**图片形式**挂在官网（非 PDF、无文字层、可能带水印）。取回后做 OCR，可恢复制度全文，其中往往含应急募捐备案、募捐方案变更补正、现场公示要素、合作方信息公开等条款——直接决定多项的判定。
3. **多源交叉印证**。机构住所、联系方式等可用"平台登记 + 年报 + 官网页脚 + 制度文件页脚 + 开户信息 + 主管部门/属地线索"交叉核对，多源一致即可支撑判定。

## 七、「查不到」的四类处理

无法核实时，必须写明属于哪一类，这决定补证路径与读者该不该采信：

| 类型 | 含义 | 典型项 | 报告怎么写 |
|---|---|---|---|
| **A 线下实物型** | 内容在线下或实物载体 | 募捐现场公示、住所纸质文本 | 说明"已核到制度规定与执行旁证，但不构成现场公示证据"；如条件允许提示可到场核验 |
| **B 定向告知型** | 义务本身只要求向特定对象告知 | 向捐赠人、受益人告知类事项 | 单独成章说明外部评查天然失能；**不得判"未公开"** |
| **C 内部动作型** | 属内部动作，不产生对外条目 | 制度与专人、归档留存 | 说明不进分母、单列盲区 |
| **D 常规不在网络展示型** | 常规不通过网络展示、或属报送件 | 关联方名单报送件、受理过程 | 说明"常规查不到≠机构未履行"，不得暗示机构有问题 |

## 八、取证与留痕要求

外部评查的结论会被拿去对话，所以过程必须留痕。

1. 每条判定记录：**渠道 / 检索 URL 或路径 / 检索时点（精确到日） / 证据等级 / 原文关键片段**。
2. **直链为主，下载可选**：日常项只记"链接 + 检索时点"；**支撑"未公开 / 已公开"结论的关键项**才另存快照。链接会失效、会被改版，快照不会。
3. 检索时点必须写进报告。公开度是**时点结论**，隔一个月可能不成立。
4. 渠道不可用（打不开、要登录、栏目为空、平台故障）时，**如实写成"本次检索未能访问，原因：……"**，并落到"无法核实"。禁止猜测补齐，禁止用往期印象代替本次检索。

## 九、取证成本提示

以下几类项工作量显著更大，排期时须预留（也应向使用者说明）：

- **图片形式公示的制度**：须逐页 OCR，无法直接检索与复制。
- **扫描件年报**：部分年度的年报是纯扫描件、零文本层，须逐页识别。
- **年报逐份穿透**：机构存续年份越多，须打开的年报越多。
- **线下项不可压缩**：募捐现场、机构住所类必须到场，无法远程替代。
- **分页长列表**：重大事件、关联交易等列表可达数百条，须翻完。

## 十、禁止事项

1. 不得用 D 级证据（第三方评分、排行榜、透明指数）支撑"已公开"。
2. 不得用 B 级渠道（自有官网）单独支撑"未公开"。
3. 不得用内部自持材料证明"已公开"。
4. 不得把"无法核实"写成"未公开"，也不得反过来。
5. 不得用往期检索印象代替本次检索。
6. 不得因平台被拦（滑块、登录、故障）而判机构"未公开"。
7. 不得凭常规印象补填缺失条目。
8. 不得把外部评查结论写成合规结论或法律意见。

---

## 十一、检索能力的边界（必须在报告中声明）

- 平台若要求登录或验证码，未能取得内容的渠道一律计入核验盲区。
- 条目被删除或页面被改写，无法回溯历史版本的，记"无法核实（页面状态已变更）"。
- **不采信任何未实际访问的成功印象**。不确定就写不确定。
- 未覆盖的渠道须逐条列出，并说明因此哪些项落入"无法核实"而非"未公开"。

## 十二、常见误判清单（评查官自查用）

| 误判 | 后果 | 正确做法 |
|---|---|---|
| 第三方透明度评分高 → 认定已公开 | 结论虚高 | 只用 A/B 级原始条目作证 |
| 官网没有 → 认定未公开 | 冤枉机构 | 转"无法核实"，并说明仅检索了自有渠道 |
| 平台条目存在 → 认定已公开 | 漏掉要素与时限核查 | 继续核要素齐备性与时限执行情况 |
| 平台页面的汇总表没有 → 认定未公开 | 漏掉附件 | 穿透年报正文与制度原件再判 |
| 搜到旧年度条目 → 认定本年度已公开 | 年度错位 | 逐年度分列，报告标明覆盖年度 |
| 用"应该公开过"填坑 | 编造 | 无证据即"无法核实" |
| 把"无法核实"从分母剔除 | 比例虚高、越难查越占便宜 | 保留在分母内、分子记 0，另列盲区清单 |
| 平台被拦 → 判"未公开" | 结论不成立 | 落"无法核实"，并写明被拦原因 |
