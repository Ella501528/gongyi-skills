# 基金会等级评估·指标拆解与资料清单

把官方评估指标表拆成逐项末级要点，自动生成规定依据、考查方式与文件级自评资料清单

## 能力

面向基金会/社会组织等级评估的指标拆解引擎。输入官方评估指标表（xlsx，含合并单元格、多层编号、主观/客观标注），输出每个末级考查要点的规定依据（含条款号/文号）、考查方式、文件级电子版自评资料清单与资料说明，并判定说明的简繁档位、映射责任角色与归档文件夹。自带 4 个校验脚本：结构抽取与求和校验、档位与负责人映射、批次切分、跨批次口径冲突检测。

## 触发方式

在对话中直接描述需求即可，例如：

- 「把我们今年的评估指标表拆成逐项资料清单」
- 关键词：公益慈善、等级评估、指标拆解、资料清单、迎评准备
