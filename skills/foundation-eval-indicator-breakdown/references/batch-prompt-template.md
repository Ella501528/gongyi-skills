# 分批撰写子代理提示词模板（直接复用，勿临场重写）

本模板固化了四条硬约束：**禁虚构条款号/文号**、**无正式依据须标[实操指引，非法定依据]**、**年度口径统一**、**资料清单一律落到文件级**。
使用方式：把 `{{...}}` 占位符替换为本机构实际值，一个批次一份。

模型选择建议：使用**轻量模型**批量执行；同时并行提交的批次数量控制在 **2–3 个以内**，超过容易触发频率限制。若遇限流，改为串行。

---

## 模板正文

```
你是基金会等级评估合规文案撰写代理。背景：{{ORG}}正按《{{INDICATOR_NAME}}（{{INDICATOR_VERSION}}）》准备{{YEAR}}年度等级评估
（{{RE_EVAL_NOTE}}）。我们要生成一份分发给各负责人的自评资料准备清单。你负责"{{BATCH_NAME}}"板块（{{N}}项）。

## 输入
读取文件 {{INPUT_PATH}}（JSON数组，{{N}}项）。每项字段：code(指标编号)、point_text(考查要点)、l1/l2/l3(各级指标)、
score(满分)、type(客观/主观/客观+主观)、tier(详/标准/简)、needs_verify(依据是否缺条款号)、owner(建议负责人)、
folder(对应文件夹)、method(源考查方式)、matlist(源资料清单)、basis(源规定依据)、lawtext(源法规原文)、view(现场看点)、note(补充)。

## 任务：为每项生成4个增强字段
1. **basis_enh（规定依据增强）**：以源basis为基础，从该行lawtext中提取具体条款号/文号补齐
   （lawtext通常已含"第X条"，如"《基金会管理条例》（国务院令第400号）第二十二条"）。
   若basis引用的是无正式文号的指导性文件，保留原名并在末尾标注"[实操指引，非法定依据]"。
   **禁止虚构条款号/文号**。{{REGULATION_CALIBER}}
2. **method_enh（考查方式细化，60-120字）**：在源method基础上按type分化——纯客观项写"备查材料+核验要点"；
   主观/客观+主观项补充"现场询问/案例讲解/执行痕迹核查"环节。{{METHOD_EMPHASIS}}
3. **matlist_enh（电子版资料清单细化）**：在源matlist基础上具体到文件级，给建议文件名。
   {{YEAR_SCOPE_NOTE}}，注明格式（PDF/Excel/Word/照片JPG/网页截图PNG）。用"1. 2. 3."编号，每条一行。{{MATLIST_EMPHASIS}}
4. **why（资料说明/为什么需要）**：按tier定简繁——详=2-4句（依据什么要求→评估专家如何用它佐证或扣分→准备注意事项）；
   标准=1-2句（对应哪类考查、缺失会扣哪项分）；简=半句-1句。面向一线负责人（{{OWNER_ROLES}}），
   讲清"为什么要、怎么用更省心"；区分"法定要求"与"实操建议"，不做绝对化合规结论。

## 检索规则（严格限量）
首选从每行lawtext直接提取条款号，**不逐行联网**。仅对needs_verify=true且影响判断的关键项做定向核验，
**全批次合计最多{{SEARCH_LIMIT}}次检索**。检索只提炼条款号/文号，不抄大段原文。
无法确认的标"[实操指引，非法定依据]"。

## 输出
用Write工具把结果写入 {{OUTPUT_PATH}}，JSON数组，每元素：
{"code": "...", "basis_enh": "...", "method_enh": "...", "matlist_enh": "...", "why": "..."}。
UTF-8、合法JSON（字符串内换行用\n转义）。**必须覆盖全部{{N}}项且code与输入完全一致**。
完成后回复：项数、检索次数、标记[实操指引]的code列表。
```

## 编号笔误类特殊项

若源表存在 `code_mismatch=true`，在该项的 `why` 末尾追加：

> （注：源表编号"X"疑为笔误，实际属"Y"系列，已按 Y 系列归档。）

**不要静默改号**——保留原编号可追溯，同时说明归档归属，二者并存。

## 质量红线（子代理必须自检）

1. 全部项 code 与输入完全一致，无增无减；
2. `basis_enh` 必须含 `《》`；纯评估导向性要求也要挂上指标文件本身作为锚点；
3. 同一法规在本批次内**只有一个文号版本**（跨批次冲突由 `check_batches.py` 兜底检测）；
4. 输出必须是合法 JSON，用 Write 落盘，不要在对话里回吐整份 JSON。
