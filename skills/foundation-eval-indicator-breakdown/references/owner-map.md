## 二、调整规则

### 机构规模适配

| 机构情形 | 调整方式 |
|---|---|
| 专职人员 ≥ 8 人 | 直接用默认映射 |
| 专职 4–7 人 | 合并"办公室主任"与"党务工作者"为**综合管理岗**；财务独立保留 |
| 专职 ≤ 3 人 | 合并为**秘书长 + 财务（可外聘代账）**两个角色；秘书长兜底全部治理类 |
| 财务外包 | "财务负责人"替换为**代账机构对接人**，但**质量责任仍在机构**，说明中须注明 |

### 自定义映射（推荐做法）

复制默认表，生成本机构的映射 JSON 后传给脚本：

```json
{
  "1.1": "张三（综合部）",
  "1.2": "李四（秘书长）",
  "1.4": "王五（财务）",
  "...": "..."
}
```

```bash
python tier.py --work "<工作目录>" --owner-map "owner-map.json"
```

未映射的二级段会回退为 `秘书长` 并打印告警——**看到告警就说明映射不完整，需补全**。

## 三、分工表生成原则（供分发版工作簿使用）

1. **按二级段归口**，不按末级项分配——末级项太细，容易造成责任碎片化；
2. 每段写明：建议负责人、涉及末级项数、分值合计、职责简述；
3. 职责简述必须含三件事：**收集整理 → 按清单备齐并放入对应文件夹 → 更新备齐状态**；主观项追加"同步准备现场讲解口径与案例素材"；
4. 分值合计用于**校验资源投入**：分值高的段应配更资深的人，而不是相反。
