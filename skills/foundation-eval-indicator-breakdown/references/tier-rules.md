# 简繁档位规则与撰写深度标准

档位只决定**说明文字（why）与清单细节**的撰写深度，**不改变评分口径**。目的是让负责人的注意力按分值权重分配，避免"所有项都写成长文"导致重点淹没。

## 一、判定规则（`tier.py` 已实现）

| 条件 | 档位 | 含义 |
|---|---|---|
| 分值 ≥ 1.0 分 | **详** | 重点项，无论如何都要详写 |
| **纯主观项** 且 分值 ≥ 0.3 分 | **详** | 纯主观项几乎全靠现场呈现，备料价值最大 |
| 分值 ≥ 0.3 分 | **标准** | 常规项（含"客观+主观"项） |
| 分值 < 0.3 分 且 纯客观 | **简** | 低分值纯材料项，备齐即可 |
| 分值 < 0.3 分 且 非纯客观 | **标准** | 分值小但需执行痕迹，仍需交代清楚 |

**为什么"客观+主观"项不按主观项升档**：这类项靠材料即可取得基础分，现场只影响上限；而"纯主观项"若材料不备、痕迹不成链，几乎无法得分。把"详"集中在纯主观项与高分值项上，档位才有区分度——否则"详"会膨胀到 50% 以上。

**反例（禁止）**：把"依据缺条款号"当作升档理由。缺条款号是**核验问题**（标 `needs_verify`），与撰写深度无关；一旦按此升档，会造成"详"项从 40% 暴涨到 67%，档位失去区分度。

## 二、各档位的撰写深度标准

### 详（重点项）

`why` 写 **2–4 句**，必须包含三段信息：

1. **依据什么要求** —— 法定条款或指标明文（含文号/条款号）；
2. **评估专家怎么用** —— 这份材料会如何被佐证或被扣分（专业性体现在这里）；
3. **准备注意事项** —— 最容易被退回的细节、归档建议、口径提醒。

### 标准（常规项）

`why` 写 **1–2 句**：对应哪类考查 + 缺失会扣哪一项分。不必展开专家视角。

### 简（低分值纯客观项）

`why` 写 **半句–1 句**：一句话说清"备齐即可"或"缺这份材料该项即不得分"。

## 三、档位参考分布（健康区间）

| 档位 | 健康占比 |
|---|---|
| 详 | 20%–35% |
| 标准 | 50%–65% |
| 简 | 10%–25% |

超出区间说明判定规则被污染（常见：把核验问题、机构特殊情况当升档理由）。此时应先修正规则，再重新生成，而不是接受分布。

## 四、与 `matlist_enh` 的关系

档位**不影响**资料清单的完整度——所有档位都要求清单落到文件级（名称＋年度＋格式）。档位只影响：

- 清单条目是否需要**拆得更细**（详项的清单宜拆到"送审版/审定版""汇总表/明细表"这一级）；
- `why` 的解释长度；
- 是否需要在说明中提示**现场演示路径**（详项通常需要）。
