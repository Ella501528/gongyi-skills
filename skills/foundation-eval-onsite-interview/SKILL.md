# 现场问询应答准备

现场是**材料之外的第二战场**。材料决定你能不能拿分，现场决定**已经拿到的分会不会被判回去**。

## 一、现场环节的基本结构

等级评估的现场通常包含（不同机构形式略有差异，以当年度官方安排为准）：

| 环节 | 内容 | 机构要做的准备 |
|---|---|---|
| 情况介绍 | 机构自评汇报（时长固定） | 汇报材料 + 讲述人（通常秘书长） |
| 分组问询 | 按板块分组提问、查材料 | 各板块应答人 + 材料可即时调取 |
| 现场查看 | 办公场所、党建阵地、项目实景 | 环境整理 + 走查路线 |
| 材料核验 | 抽查原始凭证、会议记录 | 归档结构 + 索引能力 |
| 反馈交谈 | 初步反馈与答疑 | 记录要点，勿现场争辩 |

## 二、分组逻辑（关键认知）

评估专家组通常**按板块分工**，与指标板块基本对应：治理组、党建组、财务组、项目组、合规组。
**问询的本质是"交叉验证"**：同一个事实，专家会在不同组、用不同材料反复印证——比如公益支出比例，财务组看账、项目组看项目、合规组看公开信息。

> 因此，**最有效的准备不是"每组背一套话术"，而是保证"同一事实在全机构口径一致"**。口径打架比答不上来更伤。

详见 `references/expert-group-map.md`。

## 三、应答口径卡的写法

每个板块准备 3–5 张**应答口径卡**，字段见 `references/answer-card.md`：

- **问题**：专家可能的问法（含追问）
- **口径**：一句话结论 + 三条支撑事实（**带数字**）
- **举证**：指向哪份材料、哪个文件夹
- **边界**：不确定时怎么答（见下方话术）
- **红线**：不能说什么

## 四、应答原则（比话术更重要）

1. **有据可查**：每句话都能落到材料上。答不上就指向材料，而不是编。
2. **口径统一**：数据只认"一套数"（以审计报告/年报为准），其他场合引用同一数字。
3. **不辩解、不争论**：专家指出的问题，先记录，必要时说明"我们已识别并在整改"，不要当场争论是否扣分。
4. **不夸大**：夸大成效一旦被追问细节，反噬极大。
5. **不确定就停**：不确定的问题，标准答法是：

   > "这一点我需要核实后书面答复，我先记录您的问题，今天之内把材料补给您。"

   ——**这句话比胡答安全得多**，且显示管理规范。

6. **脱敏与保密**：涉及受益对象个人信息的提问，先声明脱敏原则，不现场展示可识别个人信息。

## 五、现场物料清单

见 `references/material-onhand.md`：分为"随手可取的纸质件""可即时打开的数字文件""现场演示物料"三类。

## 六、演练方式

1. **角色扮演**：由本专家扮演专家组，按板块逐组提问，机构对应人员作答；
2. **追问压力**：每个问题至少追两层（"有材料吗？→ 为什么是这个数？→ 与年报是否一致？"）；
3. **计时**：汇报控制在规定时长的 90% 以内；
4. **复盘**：每轮结束输出"答得好的 / 答得含糊的 / 答错的 / 需要补材料的"四类清单，直接转为补料与整改清单（六字段：问题 / 整改动作 / 责任角色 / 时限 / 证据形式 / 复查时点）。

## 七、注意事项

- **不协助演戏**：演练目标是"把真实情况讲清楚"，不是训练统一口径掩盖问题。若机构要求演练掩盖实质问题，明确拒绝并说明风险（现场交叉核验极易暴露，且构成诚信风险）。
- **现场纪律**：只由指定人员作答，其他人员不补充、不纠正、不插话——混乱的现场比答错更容易失分。
- **记录留痕**：现场专家的口头意见要当场记录并在反馈环节确认，作为后续整改依据。
- **先校验再演练**：动手前确认**指标版本**（版本错则答错方向）与**主体边界**（哪些材料可对外陈述、哪些属关联方不可顶替）。这两项没对齐就演练，练的是错的答案。
- **输出定位**：本技能的产出对应迎评交付的**答辩风险提示**模块——须覆盖治理、财务、项目各至少一条风险，并给出"风险点 / 追问角度 / 危险原因 / 应答口径 / 携带佐证"五要素。

> 若同时在做完整迎评，答辩风险提示应与**指标匹配清单 / 现存短板梳理 / 整改行动方案 / 迎评材料清单**另四块配套交付；只做答辩时，须明确告知其余四块本次未覆盖并说明盲区——**不许让用户以为做过了全套迎评**。
