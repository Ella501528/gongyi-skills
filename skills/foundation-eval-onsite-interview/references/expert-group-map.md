# 专家组分组与问询逻辑

> 说明：分组名称与人数因评估机构、批次、规模而异，以下是**常见分工逻辑**，用于准备时的"对手盘推演"，不代表官方固定编制。

## 一、分组与关注点

| 组别 | 对应指标板块 | 核心关注 | 主要动作 |
|---|---|---|---|
| **治理组** | 内部治理（办公条件/组织机构/内部规范） | 决策机制是否真实运转、章程与制度是否落地 | 查会议记录、看换届材料、问决策流程 |
| **党建组** | 党的建设 | 组织覆盖与工作覆盖、台账真实性 | 查台账、看阵地、问党建与业务结合 |
| **财务组** | 内部治理中的财务资产 + 公益收支 | 比例合规、账表一致、凭证真实 | 抽凭证、穿行测试、算比例 |
| **项目组** | 发挥作用（公益项目/重大任务） | 项目链条完整性、成效可核查 | 问项目细节、看结项、要反馈 |
| **合规组** | 遵章守规 + 诚信建设 | 报备与公开是否到位、有无失信 | 查备案、查公开页面、查信用 |

## 二、各组典型问询逻辑（推演用）

### 治理组

1. "最近一次理事会什么时候开的？议题是什么？决议如何执行？"
2. "章程最近一次修订是什么时候？依据什么修订？备案了吗？"
3. "监事/监事会怎么运作？提出过什么意见？"
4. "重大事项的决策程序？请举一个具体例子。"
5. **交叉验证**：会议决议中提到的事项，是否在其他组的材料里出现。

### 党建组

1. "党组织什么时候成立的？党员几人？"
2. "今年'三会一课'开了几次？记录能看一下吗？"
3. "党建经费从哪出？怎么用？"
4. "党建怎么带动业务？举一个例子。"
5. **交叉验证**：党建活动日期与人员是否与理事会/项目记录冲突。

### 财务组

1. "公益支出比例是多少？怎么算的？"（会追：分母口径、限定性资产如何处理）
2. "管理费用比例多少？哪些费用归入了管理费用？"
3. "这笔支出的审批单在哪？"（随机抽凭证）
4. "报表与审计报告、年报是否一致？差异怎么解释？"
5. **交叉验证**：项目支出与项目组提供的项目清单是否对应。

### 项目组

1. "这个项目从立项到结项，中间有哪些关键节点？"
2. "受益人数怎么统计的？有名单吗？"（注意脱敏）
3. "项目效果怎么评估的？有没有第三方或受益方反馈？"
4. "这个项目的资金全部到位了吗？结余怎么处理？"
5. **交叉验证**：项目数与财务账中的项目支出是否匹配。

### 合规组

1. "年报报了吗？公开了吗？在哪公开的？"
2. "重大事项有没有报备？有回执吗？"
3. "公开募捐资格有吗？募捐方案备案了吗？"
4. "有没有收到过行政处罚或整改要求？整改完成了吗？"
5. **交叉验证**：公开信息与年报、财务数据是否一致。

## 三、"交叉验证"应对法

专家最有力的手段是**用A材料问B问题**。准备时做一次"互证检查"：

1. 列出**关键事实清单**（约 20–30 条：成立时间、届次、人数、比例、项目数、金额、处罚记录……）；
2. 对每条事实，找出**至少两份互相印证的材料**；
3. 任一条只有单一来源的，标为**脆弱事实**，优先补证；
4. 任一条在不同材料中数值不同的，**必须先内部统一口径**（这属于实质性风险，不能靠现场解释）。

> **可交付成果**：一张"关键事实—证据来源—一致性"对照表。这张表是现场最实用的东西——它让任何人在任何组被问到，都能立刻翻到对应材料。

## 四、现场分工建议

| 角色 | 谁 | 职责 |
|---|---|---|
| 总协调 | 秘书长 | 开场汇报、跨组协调、统一口径 |
| 分组应答 | 各板块负责人 | 本板块作答，不越界回答其他板块 |
| 材料调取 | 办公室主任/综合岗 | 按专家要求即时调取材料（**按编号索引**） |
| 记录 | 指定记录人 | 记录所有提问与专家口头意见 |
| 后勤 | 行政 | 场地、设备、饮水、打印 |

**铁律**：非指定人员不主动发言。
