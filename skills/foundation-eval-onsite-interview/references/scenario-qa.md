# 高频问询问答库（演练用）

> 用途：作为演练的"题库"。使用时按板块抽题、逐层追问。答案部分给出**作答策略**而非固定话术——话术必须由机构根据自己的真实材料填写。

## 通用类

| 问题 | 作答策略 |
|---|---|
| 请用三分钟介绍机构情况 | 结构：是谁 → 做什么 → 成效（数字）→ 治理与合规 → 下一步。**不要照读 PPT** |
| 你们最大的困难是什么？ | 如实说一个具体困难 + 已采取的措施。**不要答"没有困难"** |
| 上一次评估发现的问题整改了吗？ | 直接给整改台账与闭环证据。这是**加分项**，务必准备好 |
| 自评打了多少分？哪几项没满分？ | 只答客观事实：自评 X 分，未满分项为 X（并说明原因与整改）。**不要掩饰** |

## 治理类

| 问题 | 作答策略 |
|---|---|
| 理事会成员怎么产生的？任期几年？ | 回到章程条款 + 换届材料 |
| 理事有没有在机构领薪？关联关系如何？ | 关联方与关联交易台账 + 回避程序；**这是高风险问题，必须口径清楚** |
| 秘书长怎么聘任的？考核吗？ | 聘任决议 + 考核材料 |
| 制度这么多，执行得怎么样？ | 举一个具体制度的执行例子（附审批单/执行记录） |

## 党建类

| 问题 | 作答策略 |
|---|---|
| 党组织怎么建的？党员几人？ | 批复文件 + 名册 |
| 党建活动有没有照片？ | 拿出带时间地点参与人的活动档案，**不要只给一张合影** |
| 党建和业务怎么结合？ | 讲一个具体案例，说清党员在其中起的作用 |
| 党建经费怎么保障？ | 预算 + 使用明细 |

## 财务类

| 问题 | 作答策略 |
|---|---|
| 公益支出比例？管理费用比例？ | **只给审计口径数字**；准备好计算表 |
| 这笔支出的审批流程是什么？ | 指出制度中的权限表 + 该笔支出的审批单 |
| 有没有关联交易？怎么定价？ | 关联交易台账 + 决策程序 + 定价依据；**回避记录必查** |
| 票据合规吗？ | 抽取样本，说明票据管理制度 |
| 净资产管理、保值增值怎么做的？ | 投资决策材料 + 风险控制说明（涉及投资须符合专门规定） |

## 项目类

| 问题 | 作答策略 |
|---|---|
| 项目怎么选的？需求怎么来的？ | 需求调研记录 + 立项决议 |
| 受益人数怎么统计？ | 台账 + 统计口径说明（**说明"人次/人数"口径**） |
| 项目效果谁来评估？ | 第三方评估/自评材料 + 受益方反馈 |
| 项目款拨付了但项目没做完，怎么办？ | 说明结转安排与后续计划，附书面说明 |

## 合规类

| 问题 | 作答策略 |
|---|---|
| 信息公开在哪公开？公开了什么？ | 打开平台/官网页面现场核验；备截图（含日期） |
| 重大事项报备了吗？ | 报备文件 + 回执 |
| 有没有被投诉或处罚？ | 如实回答；有则重点是**整改闭环** |
| 年报数据和审计报告一致吗？ | 打开两份文件当场对照——**准备时就该是一致的** |

## 边界/压力问题

| 问题 | 作答策略 |
|---|---|
| 你们这项明显不符合要求，怎么解释？ | **不辩解**。标准答法："我们已识别这一问题，原因是 X，目前采取的措施是 X，预计 X 月前完成。" 附整改台账 |
| 这个数字和年报不一致 | 先核实再答，标准答法："我需要核实后书面答复，今天之内把说明补给您。" |
| 这个人是谁？名单能看吗？ | 先声明脱敏原则，不现场展示可识别个人信息 |

## 演练组织建议

1. 每轮抽 **12–15 题**，覆盖五个组，含至少 3 道压力问题；
2. 每题**追问两层**；
3. 每轮 40 分钟，其中 10 分钟复盘；
4. 复盘输出四类清单：答得好 / 含糊 / 答错 / 需补材料 → 后者转补料台账。
