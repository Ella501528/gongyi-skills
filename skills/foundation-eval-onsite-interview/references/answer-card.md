# 应答口径卡（模板与示例）

## 一、卡片字段

| 字段 | 要求 |
|---|---|
| **板块 / 指标编号** | 对应清单条目，便于回溯材料 |
| **问题** | 专家可能问法（含 1–2 层追问） |
| **口径（一句话）** | 30 字内的结论，**必须含关键数字** |
| **支撑事实** | 3 条以内，每条带数字或时间 |
| **举证材料** | 材料名 + 文件夹路径 |
| **边界处理** | 不确定/不利情形怎么答 |
| **红线** | 不能说的话 |

## 二、示例卡片

### 卡片 1 · 财务组｜公益支出比例

| 字段 | 内容 |
|---|---|
| 指标编号 | 3.1.1 系列 |
| 问题 | "你们上一年度公益支出比例是多少？怎么算的？"（追问：分母怎么定的？限定性资产怎么处理的？） |
| 口径 | 上一年度公益支出比例为 XX%，达到法定要求（**数字以审计报告为准**）。 |
| 支撑事实 | ① 上一年度公益支出 XXX 万元；② 上年末净资产 XXX 万元；③ 计算口径与审计报告一致，见审计报告附注第 X 条。 |
| 举证材料 | 《20XX年度审计报告》（PDF）、《公益支出比例计算表》（Excel）、科目余额表 |
| 边界处理 | 若专家采用更严口径：如实说明"我们按审计报告口径计算，若按另一种口径为 XX%，我们已记录并会进一步核实"。**不当场争辩**。 |
| 红线 | 不得口头给与审计报告不一致的数字；不得说"大概""差不多"。 |

### 卡片 2 · 治理组｜理事会运作

| 字段 | 内容 |
|---|---|
| 指标编号 | 1.2 系列 |
| 问题 | "去年开了几次理事会？议题是什么？决议落实情况？" |
| 口径 | 上一年度召开理事会 X 次，审议 X 项议题，决议事项均已在 X 月前落实。 |
| 支撑事实 | ① 会议时间与议题清单；② 签到与表决记录；③ 决议落实对应材料（如某制度修订已备案）。 |
| 举证材料 | 理事会会议档案（通知/签到/记录/决议，按年度归档） |
| 边界处理 | 若某次记录不全，直接承认并说明补录安排——**比含糊带过安全**。 |
| 红线 | 不得把"未召开"说成"已召开"；不得用"通讯方式"掩盖无记录。 |

### 卡片 3 · 项目组｜项目成效

| 字段 | 内容 |
|---|---|
| 指标编号 | 3.2 系列 |
| 问题 | "这个项目帮了多少人？怎么证明有效果？"（追问：名单能看吗？效果谁评估的？） |
| 口径 | 该项目覆盖 X 人，主要成效为 X，已通过 X 方式验证。 |
| 支撑事实 | ① 受益人数 X 人（来源：X 台账）；② 成效数据 X（来源：X 报告）；③ 受益方反馈 X 份（已脱敏）。 |
| 举证材料 | 项目结项报告、成效评估材料、受益方反馈（**脱敏版**） |
| 边界处理 | 涉及个人信息：先声明"名单已按脱敏要求处理，完整原始记录可按规定程序提供"。 |
| 红线 | 不得展示含有受益对象姓名、身份证号、联系方式、无授权肖像的材料。 |

## 三、卡片准备量建议

不必给每个指标都做卡片。**聚焦 15–25 张**：

- 分值最高的 10 项；
- 全部主观项中的高风险项；
- 全部数值/比例类项；
- 现场最喜欢问的"制度执行"类项。

## 四、演练记录表

每轮演练后，对每张卡片记录：

| 卡片 | 作答人 | 表现（清晰/含糊/答错） | 需要补的材料 | 需要改的口径 |
|---|---|---|---|---|

"需要补的材料"直接转入补料台账。
