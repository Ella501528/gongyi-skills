# 现场物料清单

## 一、纸质件（随手可取，按板块装订）

| 物料 | 用途 | 份数建议 |
|---|---|---|
| 自评汇报稿 | 开场汇报 | 专家组人数 + 2 |
| 指标–材料对照索引表 | 专家问"这项有材料吗"时秒答 | 每组 1 份 |
| 关键事实一致性对照表 | 应对交叉验证 | 每组 1 份 |
| 应答口径卡（分板块） | 分组应答人手持 | 按人 |
| 章程、理事会成员名册 | 治理组常问 | 2 份 |
| 近三年审计报告（摘要页） | 财务组常问 | 2 份 |
| 项目清单总表 | 项目组常问 | 2 份 |
| 现场人员分工表 | 内部用 | 内部每人 |

## 二、数字文件（当场可即时打开）

要求：**能在 30 秒内定位并打开**。做法：

- 用与指标编号一致的归档文件夹树，专家报编号即可定位；
- 准备一个"**快捷入口**"页面（或表格），把最高频的 20 份材料做成超链接；
- 所有 PDF 统一命名规则（年度+材料名），避免"最终版最终版2"。

| 类别 | 内容 |
|---|---|
| 治理 | 章程、理事/监事名册、会议档案、换届材料、制度汇编 |
| 党建 | 组织批复、党员名册、三会一课台账、活动档案、经费台账 |
| 财务 | 审计报告、财务报表、明细账、凭证样本、比例计算表、关联交易台账 |
| 项目 | 立项/执行/结项材料、成效评估、受益方反馈（脱敏） |
| 合规 | 年报、年检结论、备案回执、公开页面截图、信用查询截图 |

## 三、现场演示物料

| 物料 | 说明 |
|---|---|
| 汇报 PPT | 控制在时长的 90% 内；**数据页必须与口径一致** |
| 党建阵地布置 | 党旗、制度牌、活动照片（含日期地点） |
| 办公场所走查动线 | 提前走一遍：门口→办公区→会议室→党建阵地→档案柜 |
| 档案柜标签 | 与归档编号一致，专家随手抽一份能对得上 |
| 投影/打印设备测试 | 前一天测试；备 U 盘与转接线 |
| 案例素材（2–3 个） | 项目组可能要求"讲个具体例子"，提前定人定稿 |

- [ ] 所有纸质件份数齐备、无错页

- [ ] 现场人员知晓自己的角色与作答边界

- [ ] 场所整洁、无与材料矛盾的陈列（如过期牌匾、旧制度牌）
