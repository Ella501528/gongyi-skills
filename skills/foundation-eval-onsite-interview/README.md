# 基金会等级评估·现场问询与答辩准备

按评估专家分组逻辑准备各板块应答口径卡，含高频追问、现场物料清单与答辩风险提示

## 能力

面向基金会/社会组织等级评估现场环节的应答准备。解析评估专家组的分组与问询逻辑（交叉验证机制），为治理/党建/财务/项目/合规各板块生成 3–5 张应答口径卡（问题、口径、举证、边界、红线），并给出高风险追问的两层压力问法、现场物料三类清单、汇报计时建议与演练复盘方式。含专家分组映射、口径卡规范、高频场景问答与现场物料清单四份规则文件。

## 触发方式

在对话中直接描述需求即可，例如：

- 「把我们今年的评估指标表拆成逐项资料清单」
- 关键词：公益慈善、等级评估、现场答辩、专家问询、迎评准备
