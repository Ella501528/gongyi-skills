# 民非会计 vs 企业会计差异

> 给「有企业财务经验、转做非营利组织」的会计。核心差异一句话：**企业围着"利润"转，民非围着"受托责任"转——不图赚、不能分、要披露。**

## 一、会计目标与基础

| 维度 | 企业 | 民非 |
|---|---|---|
| 目标 | 反映利润，服务股东 | 反映受托责任，服务捐赠人/公众/监管 |
| 出资人回报 | 获取经济回报 | **不得取得经济回报** |
| 剩余财产 | 股东分配 | 注销时转同宗旨机构，**不得私分** |

## 二、会计要素对照

| 企业 | 民非 | 说明 |
|---|---|---|
| 资产、负债、**所有者权益** | 资产、负债、**净资产** | 无"所有者"概念，出资不形成股权 |
| 收入、费用、**利润** | 收入、费用 | **无"利润"要素**，差额即净资产变动 |

## 三、收入确认差异

- **捐赠收入**：企业无此科目；民非按「是否受限」分限定性/非限定性，按「交换 vs 非交换」确认（要不要交付对价是核心判据）。
- **会费收入**：会员缴纳的会费，企业无对应。
- **政府补助收入**：区分「政府补助」（非交换，免所得税）与「政府购买服务」（交换，应税）——判据仍是"要否交付对价"。
- **受托代理业务**：代收代付**不确认收入费用**，只在附注披露——企业无此概念，最容易搞错。

## 四、费用分类差异（七分类）

民非费用按功能分七类（25 号第七十六条）：

| 科目 | 编号 | 对应 |
|---|---|---|
| 业务活动成本 | 5101 | ②域「慈善活动支出」的会计底座 |
| 税金及附加 | 5201 | 印花税、房产税、城建税、教育费附加等 |
| 管理费用 | 5301 | 理事会经费、行政薪酬、办公差旅、中介机构费等 |
| 筹资费用 | 5401 | ②域「募捐成本」的底座 |
| 资产减值损失 | 5501 | 独立于管理费用 |
| 所得税费用 | 5601 | |
| 其他费用 | 5901 | |

- **共同费用须按合理方法分摊**到业务/管理/筹资，不得整笔塞管理费用（否则拉高管理费用比例、踩红线）。

## 五、资产减值差异

- 民非已计提减值准备的资产，价值**以后期间恢复的，可转回**（25 号第十八条）；企业长期资产减值**一经计提不得转回**。
- 民非「资产减值损失」**单设 5501 科目**，独立于管理费用——既不计入管理费用比例，也不再走管理费用科目。

## 六、企业会计转民非的十个注意

1. **忘掉"利润"**：没有利润表，只有业务活动表；没有"本年利润"，只有"净资产变动"。
2. **净资产要分两栏**：限定性/非限定性必须分清，且限制只能来自捐赠协议或法律法规。
3. **受托代理别当收入**：代收代付的钱不进业务活动表。
4. **捐赠按"交换/非交换"确认**：付了对价的不是捐赠，是提供服务收入/商品销售。
5. **政府资金先辨"补助 vs 购买服务"**：涉税结论完全不同。
6. **费用按功能七分类**：尤其是共同费用的分摊，直接影响费用红线。
7. **投资理财收益一般要交税**：122 号只免银行存款利息，理财/基金/股票收益应税。
8. **实物捐赠按公允价值入账**：无公允价证明不能随意估值。
9. **三张报表口径**：业务活动表权责发生制、现金流量表收付实现制，别混。
10. **会计制度已切换**：财会〔2024〕25 号自 2026-01-01 施行，旧制度（财会〔2004〕7 号）废止，按新旧衔接规定切换。

## 关键坑（旧制度→新制度）

- 管理费用等三个费用科目编号**整体前移 100 号**（旧 5201 管理费用 → 新 5301；旧 5301 筹资费用 → 新 5401；旧 5401 其他费用 → 新 5901）——信息系统科目表未同步会串号。
- 「受托代理资产」编号从 1701 变为 **1801**，新 1701 变成「长期待摊费用」——旧系统按编号取数会误读。
- 「文物文化资产」（1506）改名「文物资源」，需重新分类为文物资源/固定资产/存货。
- 旧制度权益法长期股权投资**改为统一成本法**，属会计政策变更，需按第八十三条判断是否追溯调整。
