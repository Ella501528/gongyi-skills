# 三张报表逐表拆解

> 依据：财会〔2024〕25 号《民间非营利组织会计制度》（2026-01-01 施行）财务会计报告章节及附录。
> 本章讲三张表各是什么、怎么看、常见误读。读表顺序、异常信号、自检清单见 `04-读表实操与自检清单.md`。

## 一、三张表总览对照

| 民非 / 慈善组织报表 | 企业对应表 | 回答的问题 |
|---|---|---|
| 资产负债表 | 资产负债表 | 「家底」有多少？受限多少？ |
| 业务活动表 | 利润表（损益表） | 「钱从哪来、花到哪去」？净资产怎么变？ |
| 现金流量表 | 现金流量表 | 「真金白银」怎么流入流出？ |

**读表口诀**：资产负债表看「能不能兜底」，业务活动表看「钱花得对不对」，现金流量表看「账上到底有没有钱」。三句话分别对应最常被问的三个问题。

## 二、三张表之间的三条勾稽关系

1. 业务活动表的「本期净资产变动额」= 资产负债表「净资产」期末数 − 期初数。这是两张表之间的主链接。
2. 现金流量表的「现金及现金等价物期末余额」= 资产负债表「货币资金」期末数（口径一致时）。
3. 现金流量表把业务活动表从权责发生制还原为收付实现制，解释「本期现金为什么增加或减少」。

**怎么用这三条**：三条都能串上，说明三张表内部一致、可以放心引用；**对不上，先查口径而不是先下结论**——最常见的原因是受托代理业务是否单列、合并范围是否一致、现金及现金等价物的界定是否包含受限资金。

## 三、拿到一份报表，按什么顺序看

读表有先后，顺序错了容易在细节里打转、看不出全局。推荐五步：

1. 先看资产负债表的**净资产总额与「受限 / 自由」比例**——先知道家底有多厚、有多少是专款专用的。
2. 再看业务活动表的**收入结构与费用结构**——钱主要从哪来，又主要花到哪去。
3. 看**本年净资产变动是正是负**——是收支平衡、略有结余，还是动用存量。
4. 用现金流量表的「**业务活动现金流量**」验证——账面上有结余，不等于手上有现金支撑。
5. 回头核对第二节的**三条勾稽关系**——确认前面看的数字彼此自洽。

## 四、资产负债表：看家底与受限程度

**结构**：左边资产，右边「负债 + 净资产」。核心公式——**资产 = 负债 + 净资产**。

| 企业 | 民非 / 慈善组织 |
|---|---|
| 资产 = 负债 + 所有者权益 | 资产 = 负债 + 净资产 |
| 所有者权益归股东，可分配利润 | 净资产归组织，不可分配，机构注销时转给同宗旨机构 |

**看懂净资产（核心）**：净资产分**限定性**和**非限定性**两栏。

- **限定性净资产**：有「时间限制」或「用途限制」的钱（捐赠协议约定、政府指定用途等）——不能自由支配，须专款专用。
- **非限定性净资产**：可自由支配的钱——机构真正「能动」的家底。

**判断一笔钱是不是「限定性」——依次追问三个问题，任一为「是」即为限定性**：

1. 这笔钱的用途或使用时间，是**捐赠人（或拨款方）明确指定**的吗？是 → 限定性；不是 → 看下一个。
2. 是**法律法规**规定了它的用途或时间吗？是 → 限定性；不是 → 看下一个。
3. 只是**本机构理事会或内部制度**做的安排吗？是 → **不算限定性**，仍归非限定性净资产。

**解除与重分类**：限定条件满足后（用途实现、时间到期）应转为非限定性净资产。

**这张表能说明什么**：①机构总资产规模；②「受限 vs 自由」的比例——受限比例过高，说明财务弹性差；③偿债能力（流动资产 vs 流动负债）；④资产结构——货币资金、投资类资产的占比，反映资产是否过度金融化。

| 常见误读 | 正确理解 |
|---|---|
| 把「限定性净资产」当成「不能用的死钱」 | 它是专款专用，不是不能用——用途实现或期限届满后即转为非限定性净资产 |
| 看到净资产大就认为「钱很多」 | 要看其中多少是受限的；自由支配的部分才是机构能灵活安排的家底 |
| 把「受托代理资产」算进机构自己的资产 | 代收代付的钱只是过手，不属于机构可支配的资产 |

## 五、业务活动表：看钱从哪来、花到哪去

**结构**：收入 − 费用 = 净资产变动额，且按**限定性 / 非限定性**分列两栏。

| 项目 | 内容 |
|---|---|
| 收入 | 捐赠收入、会费收入、提供服务收入、政府补助收入、商品销售收入、投资收益、其他收入（收入七类） |
| 费用 | 业务活动成本、税金及附加、管理费用、筹资费用、资产减值损失、所得税费用、其他费用（费用七分类） |
| 差额 | 本期净资产变动额（收入 − 费用） |

**与企业利润表的关键区别**：

- 企业利润表算「**利润**」归股东；业务活动表算「**净资产变动额**」归组织，**没有「利润」概念，不能分配**。
- 业务活动表按**限定性 / 非限定性**分列——同一笔捐赠收入，受限的进限定性栏，自由的进非限定性栏。
- **受托代理业务不计入**：代收代付的钱（如代其他机构转交），不是本机构的收入费用，只在附注披露。

**收入七类逐项说明**（科目编号见 `03-关键科目账务速查.md`）：

| 收入类别 | 说明 |
|---|---|
| 捐赠收入 | 接受捐赠形成的收入，按是否受限分限定性 / 非限定性 |
| 会费收入 | 会员缴纳的会费（社会团体常见） |
| 提供服务收入 | 提供服务并收取对价形成的收入 |
| 政府补助收入 | 政府给予的无偿补助，属非交换交易 |
| 商品销售收入 | 销售商品形成的收入 |
| 投资收益 | 对外投资取得的收益 |
| 其他收入 | 上述以外的收入 |

另设「**总部拨款收入**」：基金会向其分支机构、代表机构、专项基金等拨付资金时，需区分「总部拨款」与「对外捐赠」，避免同一笔资金在合并层面重复计入收入。

**费用七分类**：业务活动成本（5101）、税金及附加（5201）、管理费用（5301）、筹资费用（5401）、资产减值损失（5501）、所得税费用（5601）、其他费用（5901）。

**受托代理：最容易搞错的一点**

> **陷阱**：代收代付的钱，不进业务活动表。机构受委托代为转交的资产属受托代理业务，只在资产负债表中以「受托代理资产」（1801）与「受托代理负债」（2601）对应列示，不确认为本机构的收入与费用，并在附注中披露。
> 把受托代理的钱当成自己的收入，是民非会计核算中最典型的一类错误，会直接虚增机构规模。

**这张表能说明什么**：①收入结构（捐赠占比多少、政府资金占比多少、服务收入占比多少）；②费用效率（业务活动成本占比越高，钱越花在「事」上；管理费用 / 筹资费用占比高，则要看年度支出与管理费用比例要求是否超标）；③年度结余是正还是负。

| 常见误读 | 正确理解 |
|---|---|
| 把「净资产变动额」当成「利润」 | 它不是可供分配的利润，只是本期的净资产变动，不能分配 |
| 把受托代理的钱计入收入 | 受托代理不确认收入，只作对应资产负债列示并在附注披露 |
| 看到收入规模不小就认为财务健康 | 还要看费用结构与现金状况——收入不等于效率，也不等于现金 |

## 六、现金流量表：看真金白银

**结构**：三分类——业务活动、投资活动、筹资活动产生的现金流量。

- **业务活动现金流量**：日常慈善业务收支（收到捐赠、支付项目款、发工资等）。
- **投资活动现金流量**：买卖理财、基金、长期股权等（对应保值增值投资）。
- **筹资活动现金流量**：借入 / 偿还借款等。

**与业务活动表的关键区别**：业务活动表按「权责发生制」，现金流量表按「收付实现制」。同一事项，两张表处理不同——

- 已经确认、但尚未收到的捐赠收入：业务活动表有、现金流量表没有；
- 已收到、但属于以后期间的款项：现金流量表有、业务活动表可能尚未确认收入。

**所以两张表对不上是正常的**——它们回答的是两个不同的问题：一个问「业务做成了什么」，一个问「现金进出多少」。

**两个关键信号**：

- **业务活动现金流量是否为正**。长期为负，意味着日常业务本身不产生现金净流入，机构靠消耗存量资产或借款维持运转。
- **「账上有」不等于「手上真有钱」**。业务活动表显示有收入，但若应收款项挂账多，现金并未到账；现金流量表能揭示这一点。

| 常见误读 | 正确理解 |
|---|---|
| 把「结余」当成「现金」 | 结余是权责层面的差额，现金要看现金流量表 |
| 把投资活动现金流量当成经营成果 | 投资收益带来的现金流入属投资活动，不能等同于业务本身产生了现金 |
