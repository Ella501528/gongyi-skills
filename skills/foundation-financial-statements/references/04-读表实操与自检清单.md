# 读表实操与自检清单

> 这份是把三张表「串起来用」的部分：五步读表法、异常信号对照、报表之外必须看的两处、看表与编表的自检清单。

## 一、五步读表法

| 步 | 看哪里 | 判断什么 |
|---|---|---|
| ① | 资产负债表 · 净资产、货币资金 | 家底规模；受限与自由的比例；能自由支配多少 |
| ② | 业务活动表 · 收入结构 | 钱主要从哪来；单一来源是否占比过高（抗风险能力） |
| ③ | 业务活动表 · 费用结构 | 业务活动成本占比；管理费用、筹资费用是否偏高 |
| ④ | 业务活动表 · 净资产变动额 | 本期收支是结余还是动用存量 |
| ⑤ | 现金流量表 · 三分类 | 业务活动现金流是否为正；账面的结余有没有现金支撑 |

五步走完，再回到三条勾稽关系做一次自洽核对，一份报表的整体判断就成型了。

## 二、异常信号对照表

下列各项是「提示」而非「结论」，作用是把注意力引到需要进一步核实的地方。

| 看到的信号 | 可能的含义 | 下一步看什么 |
|---|---|---|
| 限定性净资产占比很高 | 财务弹性偏弱，大量资源是专款 | 这些限定资金是否按期限、按用途在使用 |
| 管理费用占比偏高 | 可能触及管理费用比例要求 | 对照现行规定的比例，核对共同费用分摊依据 |
| 业务活动成本占比很低 | 钱没有主要花在「事」上 | 费用明细，看资金流向 |
| 业务活动现金流量长期为负 | 日常业务不产生现金支撑，靠存量或借款 | 投资、筹资活动现金流量；存量资产的消耗速度 |
| 收入来源高度集中 | 抗风险能力弱，单一来源中断即受冲击 | 捐赠来源结构，是否逐年变化 |
| 应收款项长期挂账 | 回款或核销存在问题 | 应收款账龄与附注说明 |
| 货币资金与投资类资产占总资产比例极高 | 公益支出能力存疑，资金可能长期沉淀 | 是否有对应的支出计划 |

**看报表的一条原则：先看结构，再看数字。** 同一个数字，放在不同的结构里意义完全不同——收入增长是「来源扩大」还是「单一来源突然放大」，净资产大是「家底厚」还是「钱花不出去」，都要结合结构与支出进度判断。

## 三、三表联动速览

| 看什么 | 在哪张表 | 判读要点 |
|---|---|---|
| 家底厚度与受限比例 | 资产负债表 · 净资产 | 非限定性净资产才是可灵活支配的部分 |
| 资产是否过度金融化 | 资产负债表 · 货币资金 / 投资类资产 | 占比极高时，要问资金是否有对应的支出计划 |
| 钱从哪来 | 业务活动表 · 收入 | 来源单一则抗风险能力弱 |
| 钱花到哪去 | 业务活动表 · 费用 | 业务活动成本占比，反映「花在事上」的程度 |
| 本年是否结余 | 业务活动表 · 净资产变动额 | 连续为负，要看是否在消耗存量资产 |
| 有没有现金支撑 | 现金流量表 · 业务活动现金流量 | 长期为负是需要关注的提示 |

## 四、报表之外必须看的两处

三张表不是孤立存在的。判断一份报表，还有两处不能跳过。

**一是财务报表附注。** 附注是报表不可分割的组成部分，许多关键信息只出现在附注里：会计政策与会计估计、重要科目的明细说明、受限资产情况、或有事项、期后事项、关联方及其交易。只看三张主表不看附注，容易漏掉影响判断的信息。

**二是审计报告的意见类型。** 审计意见分四种：无保留意见、保留意见、否定意见、无法表示意见。无保留意见表示报表在重大方面公允反映；其余三种都指向报表存在需要关注的问题，其中「无法表示意见」意味着审计范围受到重大限制、无法获取充分适当的证据。看一份报表，先看审计意见属于哪一种，再看导致该意见的具体事项。

**两处易错点**：①附注中对某个数字的说明，可能改变对主表数字的理解——读到异常数字，先回附注找解释；②审计意见类型只是提示，实际影响取决于导致该意见的事项是什么、是否已在本期内解决。

## 五、读表自检清单

### 看别人的报表（阅读者）

- [ ] 已看清净资产总额，以及限定性与非限定性的比例
- [ ] 已看收入结构，判断单一来源是否占比过高
- [ ] 已看费用结构，判断业务活动成本与费用类支出的比例关系
- [ ] 已看本期净资产变动额，判断是结余还是动用存量
- [ ] 已看现金流量表的业务活动现金流量，判断是否有现金支撑
- [ ] 已核对三条勾稽关系，确认三表内部自洽
- [ ] 已区分「受托代理」与机构自身业务，未把过手资金计入规模
- [ ] 涉及比例的判断，已确认口径，未套用单一数值

### 编自己的报表（编制者）

- [ ] 净资产已按限定性 / 非限定性分列，限制来源核对过（提供者 / 法律法规）
- [ ] 限定条件已满足的，已及时转为非限定性
- [ ] 受托代理业务已单列，未混入收入费用
- [ ] 费用已按功能七分类，共同费用按合理方法分摊并在附注说明
- [ ] 实物捐赠已按公允价值入账，价值证明齐备
- [ ] 投资收益等应税项目已按现行规定判断税务处理
- [ ] 已核对新旧科目编号，信息系统科目表已更新
- [ ] 已核对三条勾稽关系，三表内部一致
