# 关键科目账务处理速查

> 从 25 号附录第三部分「会计科目使用说明」提炼公益基金会最常用科目的账务处理。
> 分录以「借方科目 → 贷方科目」记。

| 科目 | 编号 | 主要账务处理（分录要点） | 实务提醒 |
|---|---|---|---|
| **受托代理资产** | 1801 | 收到：借 1801 → 贷 2601 受托代理负债；转赠/转出：借 2601 → 贷 1801 | 受托代理业务**不确认收入**；现金/存款形式可不经本科目，设「受托代理资产」明细；须设登记簿 |
| **受托代理负债** | 2601 | 与 1801 反向对应，按受托代理资产金额确认 | 按指定受赠/转交对象设明细 |
| **捐赠收入** | 4101 | 接受捐赠：借 现金/银行存款/存货/长期股权投资/固定资产/无形资产 → 贷 4101（限定性/非限定性） | 受托代理资产**不在此核算**；服务捐赠：借 5101/5301 → 贷 4101 |
| **业务活动成本** | 5101 | 发生：借 5101 → 贷 现金/银行存款/存货/应付账款；退回捐赠：反向 | ②域慈善活动支出归集处；作委托人设慈善信托须设「**设立慈善信托支出**」明细 |
| **管理费用** | 5301 | 折旧/摊销/职工薪酬/预计负债：借 5301 → 贷 累计折旧/累计摊销/应付职工薪酬/应交税费/预计负债 | 范围极广（理事会经费、行政薪酬、办公差旅、中介机构费、因本机构原因应偿还的受赠资产/政府补助等） |
| **税金及附加** | 5201 | 发生纳税义务：借 5201 → 贷 应交税费 | 核算印花税、房产税、城建税、教育费附加、城镇土地使用税、车船税、消费税等 |
| **长期股权投资** | 1401 | 接受捐赠：借 1401 → 贷 4101；持有（成本法）被投资方宣告股利：借 其他应收款 → 贷 投资收益；处置差额记投资收益 | **统一成本法**（不再权益法）；减值计提后可**转回**（在已计提范围内） |
| **非限定性净资产** | 3101 | 期末收入/费用转入；限定性限制完全解除：借 3102 → 贷 3101 | — |
| **限定性净资产** | 3102 | 与 3101 对应 | 理事会内部决议的限定**不构成**限定性净资产 |
| **以前年度净资产调整** | 3201 | 前期差错更正 | 新增科目 |

## 快速判断三问

1. **这笔钱是代收代付吗？** → 是，走 1801/2601 受托代理，不进收入费用。
2. **这笔收入是捐赠还是服务？** → 要不要交付对价：无对价是捐赠（4101），有对价是服务/销售。
3. **这笔费用归哪类？** → 花在项目上是业务活动成本（5101），募捐是筹资费用（5401），行政是管理费用（5301），共同费用要分摊。
