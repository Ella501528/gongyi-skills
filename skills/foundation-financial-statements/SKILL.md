# 慈善组织三张报表解读（民非 vs 企业）

面向三类读者：

1. **有企业财务经验、但没做过慈善组织会计的人**——三张表名字和结构不一样在哪里，转过来要先改掉哪些习惯；
2. **想读懂报表的公益从业者**——每张表的名词是什么意思、这组数字能说明什么、哪里最容易看错；
3. **要编制或送审报表的人**——哪些地方出错会被退回，附注和审计意见怎么配合看。

## 铁律

1. **机构中立**：正文写「某基金会 / 本机构」，不出现具体机构名、人名、金额。
2. **逐条引用**：结论落到「财会〔2024〕25 号第 X 条」，不凭记忆编造。
3. **无依据如实说**：拿不准的写「存在不确定性，建议向主管机关确认」。

## 三张表速查（30 秒看懂）

| 慈善组织（民非）报表 | 企业对应表 | 回答的问题 |
|---|---|---|
| 资产负债表 | 资产负债表 | 「家底」有多少？受限多少？ |
| 业务活动表 | 利润表（损益表） | 「钱从哪来、花到哪去」？净资产怎么变？ |
| 现金流量表 | 现金流量表 | 「真金白银」怎么流入流出？ |

**读表口诀**：资产负债表看「能不能兜底」，业务活动表看「钱花得对不对」，现金流量表看「账上到底有没有钱」。

## 民非 vs 企业：五条核心差异

1. **没有「利润」**：企业算利润归股东；慈善组织算「净资产变动额」归组织，不可分配，注销时转给同宗旨机构。
2. **净资产分两栏**：限定性（有用途 / 时间限制，不能自由支配）vs 非限定性（可自由支配）。**限制只能来自资产提供者或法律法规——理事会自己决议的不算限定。**
3. **受托代理别当收入**：代收代付的钱不进业务活动表，只在资产负债表列示、附注披露。
4. **费用按功能七分类**：业务活动成本、税金及附加、管理费用、筹资费用、资产减值损失、所得税费用、其他费用。
5. **减值可转回**：慈善组织资产减值以后期间恢复的可转回；企业长期资产减值一经计提不得转回。

## 三条勾稽关系（对表用）

1. 业务活动表「本期净资产变动额」= 资产负债表「净资产」期末 − 期初。
2. 现金流量表「现金及现金等价物期末余额」= 资产负债表「货币资金」期末（口径一致时）。
3. 现金流量表把业务活动表从权责发生制还原为收付实现制。

**对不上先查口径，不要先下结论**——最常见原因是受托代理是否单列、合并范围是否一致、现金及现金等价物是否包含受限资金。

## 何时用本 skill

- 有人拿一份慈善组织 / 基金会的年报报表问「怎么看」
- 要判断某笔钱是「限定性还是非限定性」
- 要判断代收代付算不算收入
- 要判断某笔费用该归哪一类（影响年度支出、管理费用、募捐成本比例口径）
- 企业会计转做慈善组织 / 民非会计，要知道先改哪些习惯
- 要按新制度（财会〔2024〕25 号）切换科目表，担心编号串号
- 年报、评估、审计前要自查报表有没有硬伤
