# 三张报表解读（民非 vs 企业）

面向两类读者：①有企业财务经验、但没做过非营利组织的会计——快速看懂三张表的异同；②想读懂报表的公益人——弄懂每张表的名词、结构与能说明什么。

## 铁律

1. **机构中立**：正文写「某基金会 / 本机构」，不出现具体机构名、人名、金额。
2. **逐条引用**：结论落到「财会〔2024〕25 号第 X 条」，不凭记忆编造。
3. **无依据如实说**：拿不准的写「存在不确定性，建议向主管机关确认」。

## 三张表速查（30 秒看懂）

| 民非（基金会）报表 | 企业对应表 | 回答的问题 |
|---|---|---|
| 资产负债表 | 资产负债表 | 「家底」有多少？受限多少？ |
| 业务活动表 | 利润表（损益表） | 「钱从哪来、花到哪去」？净资产怎么变？ |
| 现金流量表 | 现金流量表 | 「真金白银」怎么流入流出？ |

**读表口诀**：资产负债表看「能不能兜底」，业务活动表看「钱花得对不对」，现金流量表看「账上到底有没有钱」。

## 民非 vs 企业 五条核心差异（记住这五条就够入门）

1. **没有「利润」**：企业算利润归股东；民非算「净资产变动额」归组织，不可分配、注销转同宗旨机构。
2. **净资产分两栏**：限定性（有用途/时间限制，不能自由支配）vs 非限定性（可自由支配）；限制只能来自资产提供者或法律法规，理事会自己决议不算限定。
3. **受托代理别当收入**：代收代付的钱不进业务活动表，只在附注披露。
4. **费用按功能七分类**：业务活动成本、税金及附加、管理费用、筹资费用、资产减值损失、所得税费用、其他费用。
5. **减值可转回**：民非资产减值以后期间恢复的可转回；企业长期资产减值一经计提不得转回。

## 何时用本 skill

- 有人拿一份民非报表问「怎么看」
- 企业会计要转做基金会/民非会计
- 判断某笔钱是「限定性还是非限定性」
- 判断代收代付算不算收入
- 判断某笔费用该归哪一类（影响费用红线）
