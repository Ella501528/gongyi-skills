# 模板 07 · 决议落实台账（可填）

**{基金会全称}　第 {X} 届理事会决议落实台账**

> 来源：从纪要"决议"栏逐条拆过来，**纪要没有的不要凭记忆补**。编号规则：`{届次}-{会议序号}-{决议序号}`，例：`三届-4次-03`。每次理事会**首项议程固定通报上次会议决议落实情况**；缺这句，台账再漂亮也是死的。

| 决议编号 | 届次 | 决议内容（原文摘录，动词开头） | 责任部门 | 责任人 | 协办 | 完成时限 | 验收标准 | 当前状态 | 进展说明 | 完成日期 | 验收凭证 | 通报届次 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| {届次}-{序号} | | | | | | {YYYY-MM-DD} | {文件/批复/到账/公示截图} | □ 未启动<br>□ 进行中<br>□ 已完成<br>□ 逾期<br>□ 已终止 | | | | | |

**状态取值**：`未启动 / 进行中 / 临期 / 逾期 / 阻塞 / 待补证 / 已闭环`
**类型**（在决议内容标注）：`执行类 / 报批类 / 整改类 / 知会类`；知会类不计入落实率分母。

**逾期项单独看（理事长只介入这些）**

| 决议编号 | 决议内容 | 责任人 | 原时限 | 已逾期天数 | 阻塞原因 | 需理事长介入 | 新的完成时限 |
|---|---|---|---|---|---|---|---|
| | | | | | | □ 是 □ 否 | |

**闭环关键**
- 决议表述用动词开头、能量化就量化（见 `references/resolution-wording.md`）。
- 变更或撤销决议必须经理事会表决，不得由理事长/秘书长口头处置。
- 凭证与台账条目一一对应；台账写"已闭环"但无凭证的，状态回退为"待补证"。
- 落实率口径：已闭环数 ÷（应落实决议数 − 知会类）。
