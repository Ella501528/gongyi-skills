# 决议表述规范（resolution-wording）

> 一份可执行的决议能回答四个问题：谁、做什么、什么时间前、什么标准。决议写得可执行，决议落实台账才有抓手。

## 一、四要素

| 要素 | 问什么 | 写法 |
|---|---|---|
| **谁** | 责任人/责任部门 | 具体到人，不接受"秘书处""相关部门" |
| **做什么** | 具体动作 | 动词开头，能量化就量化 |
| **什么时间前** | 时限 | 具体到日期，不接受"尽快""近期""下次会议前" |
| **什么标准** | 验收标准 | 文件/批复/到账/公示截图之一 |

## 二、正反例

| | 表述 | 评价 |
|---|---|---|
| 反例 | 原则同意推进该项目。 | 无可执行性，无法验收 |
| 正例 | 同意开展{项目名称}，由{部门}负责，于{YYYY}年{MM}月{DD}日前完成{具体动作}，预算不超过{金额}元，执行情况向{下次理事会/监事会}报告。 | 四要素齐全 |
| 反例 | 请秘书长尽快落实。 | 无时限、无标准 |
| 正例 | 责成秘书长于{YYYY-MM-DD}前完成{事项}，形成{书面报告}报理事会。 | 可追踪 |

## 三、来源与拆解

- 决议表述来源：会中 E09 当场宣读的决议要点，或 D09 单份材料的"提请审议的事项"第 5 段（一句话，可直接抄进纪要"决议"栏）。
- 会后拆解：纪要在 48 小时内起草，逐条决议拆进 `templates/07-决议落实台账.md`（责任人/时限/验收标准/状态）。
- 闭环：下一次会议**首项议程固定通报上次会议决议落实情况**；变更或撤销决议必须经理会表决，不得由理事长/秘书长口头处置。

## 四、决议书单独出具的情形

需要单独《决议书》的场合（变更登记、银行开户、投资、不动产处置、专项基金设立等）：统一编号 `{基金会简称} 理事会决议〔{YYYY}〕第{NN}号`。内容含：标题编号、会议基本情况、决议事项（分条）、表决情况（同意/反对/弃权、是否全票）、生效与执行要求、理事签名/盖章/日期。多数登记机关表格要求上传"决议书"或"纪要"——两种都接受时用纪要，明确要"决议"的单独出决议书（见 `templates/04-决议书.md`）。

## 五、类型标注（供落实台账用）

| 类型 | 含义 | 是否计入落实率分母 |
|---|---|---|
| 执行类 | 秘书处可独立完成 | 是 |
| 报批类 | 需报登记机关/业务主管单位 | 是 |
| 整改类 | 针对问题限期改 | 是 |
| 知会类 | 不需追踪 | **否**（不计入分母） |
