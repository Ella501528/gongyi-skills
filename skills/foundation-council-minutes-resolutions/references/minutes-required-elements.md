# 纪要必备要素校验清单（minutes-required-elements）

> 发文前逐项打钩。缺一项就可能被退回。十项速查卡（同时覆盖民政表格体与成文纪要两套）。

## 一、十项必备要素

| # | 检查项 | 常见漏法 |
|---|---|---|
| 1 | 基金会全称处**已加盖公章** | 漏盖章，直接退回 |
| 2 | 会议地点写到**门牌与房间号** | 只写"会议室" |
| 3 | 应到／实到理事人数齐全 | 只写实到 |
| 4 | **应列席监事几名、实列席监事几名** | 整段漏写（最易漏） |
| 5 | 明确**表决方式**（举手／无记名投票） | 不写 |
| 6 | 逐项记载**同意／反对／弃权票数** | 只写"会议通过" |
| 7 | 明确**是否全票通过** | 不写 |
| 8 | **决议正文**可执行（谁、做什么、何时、什么标准） | 只写"原则同意" |
| 9 | **监事意见栏 + 监事本人签名**（多位监事逐人签） | 空缺或共签一份 |
| 10 | 出席／缺席名单**列到人**，不是只写人数 | 只写"出席 5 人" |

## 二、额外校验（记录与免责）

| # | 检查项 | 说明 |
|---|---|---|
| 11 | 反对、弃权理事**已记名** | E08 落点；记录里写到人，纪要至少写"反对：{姓名}；弃权：{姓名}" |
| 12 | 逐项决议与议程一一对应，无漏项 | 议程有、纪要无 → 缺项 |
| 13 | 回避事项已记载 | "{姓名}因{事由}回避本项表决，未参与表决亦未委托他人代为表决，本项表决基数为{N-1}票" |
| 14 | 会议记录（底稿）已出 | 记录 ≠ 纪要；免责以"记载于会议记录"为准 |

## 三、标准写法速查

| 场景 | 可直接套用的句子 |
|---|---|
| 有效性 | 会议应到理事{N}人，实到理事{M}人（其中受托{K}人），实到人数超过理事总人数的三分之二，符合《章程》规定，本次会议有效。 |
| 监事列席 | 应列席监事{A}人，实列席监事{B}人。{姓名}监事全程列席并监督本次会议。 |
| 通过 | 经表决，同意{X}票，反对{Y}票，弃权{Z}票，本项议案获得通过。 |
| 全票 | 与会理事一致同意，本项议案全票通过。 |
| 未通过 | 经表决，同意{X}票，反对{Y}票，弃权{Z}票，未达到章程规定的表决门槛，本项议案未获通过。 |
| 回避 | {姓名}因{事由}回避本项表决，未参与表决亦未委托他人代为表决。 |
| 监事意见 | 本次会议的召集程序、出席人数、表决方式符合法律法规和本会《章程》规定，各项决议有效。 |
| 监事发现问题 | 监事发现{……}，建议理事会在{期限}内完成整改并将结果书面反馈监事会。 |

## 四、两个常见误区

1. **只写"一致通过"**：小基金会常全票，那就在纪要写"全票通过"——登记机关要求明确"是否全票通过"，写"全票"和写"非全票"都合规，**不写才不合规**。
2. **监事只写一个"同意"**：多位监事须**逐人签字**，不可共签一份；一个没来也要写"实列席 0 人"。
