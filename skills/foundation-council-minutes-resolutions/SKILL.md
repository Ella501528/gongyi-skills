# 纪要与决议（minutes-and-resolutions）

一句话定位：把会上的事变成**一篇成文的纪要**（不是一堆表）和**可执行的决议**，并让反对票/弃权票落到人、让监事逐人签、让决议盯到底。**纪要是一篇文件，逐项记载同意/反对/弃权票数，不能只写"会议通过"。**

## 作业顺序

1. 先读 `references/minutes-four-forms.md`：先对号入座选形态（A 现场条目体 / B 现场叙事体 / C 通讯函审体 / D 民政表格体），再动手。
2. 再读 `references/minutes-required-elements.md`：发文前按必备要素逐项校验（应到实到、监事列席、逐项票数、是否全票、监事意见栏逐人签）。
3. 然后读 `references/resolution-wording.md`：把决议写成"谁、做什么、什么时间前、什么标准"。
4. 套模板出成品：`templates/01-现场条目体纪要.md`、`templates/02-现场叙事体纪要.md`、`templates/03-通讯函审体纪要.md`、`templates/04-决议书.md`、`templates/05-签署意见表.md`、`templates/06-签字回收台账.md`、`templates/07-决议落实台账.md`。

## 使用铁律

1. **纪要是一篇成文文件，不是一堆表**：登记机关、年报、档案要的是一篇文字；表格只在发文前自查保留。占位符填完即成稿。
2. **逐项记载票数**：每个议题记同意/反对/弃权票数，**不能只写"会议通过"**；是否全票通过必须写明。
3. **反对票、弃权票写到人**：这是理事的免责凭证（《基金会管理条例》——表决时异议并记载于会议记录者可免责）。记录里写到人，纪要至少写"反对：{姓名}；弃权：{姓名}"。
4. **监事意见栏逐人签**：多位监事须**逐人签，不可共签一份**；一个没来也要写"实列席 0 人"。
5. **两套都要有**：民政表格体（登记机关填报格式）与机构存档成文纪要是**两套并行**，都保留；明确要"决议"的单独出决议书。
6. **记录 ≠ 纪要**：记录是底稿（免责以"记载于会议记录"为准），纪要是成品；先出记录再提炼纪要，反对/弃权记名落在记录里。
