# 慈善组织物资发放台账

物资类支出是检查、审计里最容易被追问的一块，追问的落点只有一个：**每一件物资去哪了**。本技能把台账做成能自证的三件事：**记全、对平、能处置**。

## 什么时候会用到它

| 时机 | 你要做的事 |
|---|---|
| 采购前 | 用第 2 节定比价与回避口径 |
| 物资到货 | 用第 3 节做入库登记（品名、规格、数量、单价、供应商、票据号、验收人签字） |
| 发放时 | 用第 4 节做发放登记（日期、接收方、数量、签收人、用途），与受益对象名册对应 |
| 结项或中途盘点 | 用第 5 节做三数对账；剩余物资按第 6 节处置 |
| 提交年度报告、迎接检查评估前 | 把台账交给 `scripts/check_ledger.py` 跑一遍，拿异常清单 |

一句话：**入库数 = 发放数 + 剩余数**，三个数必须对得上。这是检查时最常被追问的一条。

## 一、台账四段结构

| 段 | 记什么 | 落什么凭证 |
|---|---|---|
| **采购** | 品名、规格、数量、单价、金额、供应商、比价方式、审批 | 比价记录、采购审批单、采购合同 |
| **入库** | 品名、规格、数量、单价、供应商、票据号、验收人签字 | 入库单、发票或收据 |
| **出库发放** | 发放日期、接收方、数量、签收人、用途 | 出库单、签收单 |
| **结存处置** | 剩余数量、处置方式、审批 | 处置审批单、入账凭证 |

台账可以是 Excel，也可以是纸质册；**字段齐、能对平**比用什么工具重要。

## 二、采购：三方比价与回避

- **比价触发**：达到机构规定额度的采购，应履行**三方比价**（或按制度走招标、竞争性磋商），保留比价记录与审批。额度由机构制度定，本技能只做"有没有留"的校验。
- **回避**：采购经办人与供应商存在关联关系的，**应当回避**；涉及关联方的，按关联交易程序处理（另属关联方线）。
- **留什么**：比价表（三家报价、联系人与报价日期）、选定理由、审批签字。

## 三、入库

至少要能回答：**什么货、多少、什么价、谁供的、哪张票、谁验的**。

字段：品名、规格、数量、单价、供应商、票据号、验收人签字。

> 验收人签字不能由采购经办人一人兼任；送货方与验收方分开是基本内控。

## 四、出库发放

字段：发放日期、接收方、数量、签收人、用途。

两条硬要求：

1. **签收人要能指到人**——本人签，或经本人明确委托的人签（留委托记录）。
2. **接收方要与受益对象名册对应**——台账上的接收方，应能在受益对象名册里找到（`gongyi-beneficiary-registry`）。

## 五、三数对账（核心）

> **入库数 = 发放数 + 剩余数**

三个数对不上，就意味着有物资去向无法说明。差额再小也要查：差 2 件，就是 2 件说不清。

对账频率建议：**每次发放后抽对一次，结项前全对一次**。

## 六、剩余物资处置

清点 → 登记 → 审批 → 处置（转赠 / 变卖入账 / 报废）→ 处置结果入账并留档。

- 转赠他方的，取得接收凭证；
- 变卖的，收入入账，不得坐支；
- 报废的，说明原因并留审批。

处置前**建议**与捐赠人沟通意愿并形成书面记录（属良好实务，非法定强制，依据见 `references/依据原文摘录.md`）。

## 七、脚本：台账体检

```
python scripts/check_ledger.py --input sample_data/sample_input.json --out ./台账体检报告.xlsx
```

- **输入**：一份 JSON（结构见 `sample_data/sample_input.json`）。
- **输出**：Excel 四表——汇总 / 三数对账 / 异常清单 / 待补材料。
- **规则**：八条，逐条见 `references/判定规则索引.md`。

### 边界与降级（必读）

| 情况 | 怎么处理 |
|---|---|
| 未安装 openpyxl | 自动降级输出 CSV（同目录、按表分文件） |
| 未提供受益对象名册（`beneficiary_ids`） | M6「接收方对不上名册」**报"无法判定"**，不猜 |
| 未设定采购比价额度 | M2 **报"未设定额度，无法判定"**，不默认按 0 处理 |
| 采购走的是招标／竞争性磋商 | 在 `procurement_method` 标注，M2 按已履行处理，不再要求三家报价 |
| 单据部分缺失 | 只报已知缺口，不推定缺失之外的情况 |
| 数据含真实供应商与个人信息 | 对外提交前脱敏；脚本输出默认打码接收方姓名 |

## 八、配套

- **方法依据**：《公益项目全流程合规手册》第 2.4 节（物资采购、入库与发放）、2.3 节（给付形态·实物）、3.3 节（归档清单·物资类）、3.4 节（剩余物资处置）。
- **空白表格**：`gongyi-project-templates` 内的「物资管理台账.xlsx」。
- **对账上游**：`gongyi-beneficiary-registry`（受益对象名册）。

## 九、免责

本技能为操作性工具，不构成法律意见。比价额度、审批权限以机构制度与资助方约定为准；涉及关联交易的，另按关联交易程序处理。
