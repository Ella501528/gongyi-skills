# 反例与边界示例（物资发放台账）

> 示例均为虚构，供应商名与机构名用 ×× 占位。

---

## 一、三数对账的反例（最常被追问）

### 反例 1 · 直接送现场，没走入库

供应商把 200 个书包直接送到学校现场发放，入库单没做，出库单做了 200 个。

- **现象**：入库数 0，发放数 200，剩余 0 → 三数不成立。
- **怎么查**：查送货单与现场签收单；补一张入库单，登记"直发现场"的路径。
- **根因**：把"入库"当成了"进仓库"，而没理解入库是**登记造册的起点**。

### 反例 2 · 差 2 件不当回事

入库 100 件，发放 98 件，剩余 0。

- **现象**：差额 2 件，去向不明。
- **为什么仍要查**：差额再小，也意味着 2 件物资无法说明去向；累计起来就是财产管理问题。
- **正确做法**：或补 2 人的发放记录，或剩余 2 件入剩余台账并说明。

### 反例 3 · 剩余物资默认留下

项目结项，账上还有 30 件物资，没人提，留在机构库房。

- **问题**：剩余财产不能默认留下，应按方案或协议处理，未规定的用于目的相同或相近的其他慈善项目并公开。
- **要做**：清点 → 登记 → 审批 → 处置（转赠／变卖入账／报废）→ 入账留档。

## 二、其余六条规则的典型反例

| 规则 | 反例 | 说明 |
|---|---|---|
| M2 缺比价 | 采购 3 万元物资，只有一家报价 | 达到额度须三方比价；走招标的要在方式栏标注，才能免于三家报价 |
| M3 未回避 | 采购经办人与供应商是亲属，未申报 | 应回避；涉关联方的按关联交易程序处理 |
| M4 入库要素缺失 | 入库单只有品名和数量，没有验收人签字 | 验收人签字是被追问的第一项；且不应由经办人一人兼任 |
| M5 出库要素缺失 | 签收单只有名字，没写日期和数量 | 三个都要有：日期、数量、签收人 |
| M6 对不上名册 | 发放对象张××在受益对象名册里找不到 | 无名册依据的发放，去向说不清 |
| M8 数量金额异常 | 单价 60 元 × 200 个 = 13000 元 | 单价与金额不符，核对单据 |

## 三、边界示例（容易判错的三种）

### 边界 1 · 小额采购要不要比价

- **安全**：机构制度定 5000 元以下可单一询价；一笔 800 元的采购，留一张询价单即可。
- **危险**：把一笔 3 万元采购拆成 7 笔 4000 元，规避比价。
- **判据**：看**制度额度**，也看**是否为规避而拆分**。拆分规避是内控问题。

### 边界 2 · 志愿者顺手从库房拿了一件

- **安全**：登记出库、写用途（如"活动备用"）、事后归还或补审批。
- **危险**：不登记，认为"内部人拿的不算发放"。
- **判据**：出库就要登记，**去向必须有记录**，与是谁拿的无关。

### 边界 3 · 物资过期报废

- **安全**：清点登记 → 说明原因 → 审批 → 报废 → 留档。
- **危险**：直接扔掉，不登记、不审批。
- **判据**：报废是处置的一种，同样要走"清点—登记—审批—留档"。

## 四、不该用本技能的场合

| 场合 | 该用什么 |
|---|---|
| 要的是空白台账表格 | `gongyi-project-templates` 的「物资管理台账.xlsx」 |
| 要核对受益对象资格 | `gongyi-beneficiary-registry` |
| 要判关联方、议关联交易 | 关联方线 |
| 要项目整体合规体检 | 「公益项目合规官」专家包 |

> 本技能只处理**物资这一条线**的去向与对平。
