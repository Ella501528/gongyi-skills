# 慈善组织关联交易公开与责任

## 何时使用

- 要生成关联交易公开文本
- 要核对公开与报送时限
- 要填报年度关联方名单及关联关系说明
- 要核查三处口径一致性
- 要分析违规后果与损失挽回途径

## 何时不用本技能

- 关联方名单还没梳理出来 → 先用关联方识别与登记，名单是报送的前提
- 要判断这笔交易该走什么程序、定价是否公允 → 用关联交易合规审查
- 主体不是慈善组织（企业、政府采购、事业单位等）→ 公开义务与时限不同，本技能不适用
- 要的是法律定性、争议代理或对外答复 → 本技能不作法律意见，交律师、登记管理机关或专业机构

## 输入输出契约

**你要准备什么**

一份按本包 `sample_data/sample_input.json` 结构填写的事实 JSON。本技能负责 `facts.disclosure` 分组，取值三态：`true`（存在或已完成）、`false`（不存在或未完成）、`null`（资料未取得）。

| 字段 | 采集什么 |
|---|---|
| `disclosed_within_30d` | 交易发生后三十日内是否已在平台公开具体内容和金额 |
| `annual_list_filed` | 每年 5 月 31 日前是否已报送关联方名单及关联关系说明 |
| `skip_filing_because_no_transaction` | 是否以当年无交易为由跳过名单报送 |
| `note_four_elements_complete` | 财报附注四项要素是否齐备 |
| `pricing_policy_disclosed` | 定价政策是否已披露 |
| `three_sources_consistent` | 年报、平台、财报三处口径是否一致 |
| `basic_info_disclosed_within_30d` | 重要关联方基本信息是否自形成之日起三十日内公开 |
| `correction_needed`、`correction_published` | 是否需要更正、是否已公布更正说明 |

**跑之前先装依赖**（只需一次）

```
pip install openpyxl
```

未安装也能跑，脚本会自动降级为 CSV 清单与 Markdown 摘要。

**跑完得到什么**

在包根目录执行：

```
python scripts/run_check.py -i 我的机构.json
```

得到 `（输入文件同级目录）/out/关联方合规体检报告_YYYYMMDD.xlsx`，四个工作表：体检摘要、缺陷清单、待确认项、评分明细。控制台同时输出 Markdown 摘要。用于年报核对时，另逐项核对意见表，每项标注通过、缺陷或待确认，并附依据与修改方式。

**什么叫成功**

1. 报告文件已生成，四个工作表均有内容；
2. 报告中的评分、命中数、待确认数与控制台摘要完全一致；
3. 两个时限节点分别有结论：交易发生后三十日公开，与每年 5 月 31 日名单报送，互不替代；
4. 「待确认项」列出需补充的字段路径，补齐后复评，评分上升即说明公开与报送缺口已补上。

**资料不全或跑不动时怎么办**

- 字段填 `null` 即标记为「待确认」，不计入评分分母，既不会被算作通过，也不会被算作命中；
- 名单报送类规则以 `facts.identification.has_related_party` 为前提，该字段缺失会使相关规则整体转为「待确认」，先补它；
- 未安装 openpyxl 时自动降级为 CSV 清单与 Markdown 摘要，不中断；
- 报告文件被 Excel 或 WPS 占用时，用 `-o` 指定新文件名再跑；输入 JSON 语法错误会给出行列位置。

## 一、公开与报送：两个节点，别混

| 节点 | 要求 | 依据 |
|---|---|---|
| **交易发生后三十日内** | 在慈善信息公开平台公开**具体内容和金额** | 信息公开办法第 14 条 |
| **每年 5 月 31 日前** | 向办理其登记的民政部门报送**关联方名单及关联关系说明** | 信息公开办法第 15 条 |

**易漏提示**：年度名单报送是**独立义务**，即便当年没有发生关联交易，只要存在关联方，报送义务依然存在。不要因为没有交易就跳过。

**与第 13 条的区别**：重大资产变动、重大投资、重大交易及资金往来属第 13 条事项，关联交易属第 14 条，两类并列，不要混用条款。

## 二、公开文本要素

须包含具体内容和金额。交易类型对应六类情形之一：接受重要关联方捐赠 / 对其资助 / 共同投资 / 委托其投资 / 发生交易 / 其他资金往来。

## 三、财务会计报告披露

在会计报表附注中披露"发生关联方交易的说明"：关联方关系的性质、交易类型、交易要素（金额、未结算项目金额条款和条件、未结算应收项目坏账准备金额、定价政策）。

## 四、三处口径一致性核查

| 口径 | 内容 |
|---|---|
| 年度工作报告 | 关联方名单、关联交易情况 |
| 慈善信息公开平台 | 基本信息中的关联方、交易公开条目 |
| 财务会计报告 | 报表附注中的关联方关系与交易要素 |

**建议**：以同一份关联方台账作为三处唯一数据源，避免多头维护造成名单不一致、金额对不上。这是审计与评估中最容易被追问的问题。

## 五、更正义务

已公开信息需要更正的，应在平台填写并公布更正说明；基本信息发生变更的，变更后三十日内公布（信息公开办法第 16 条）。

## 六、违规后果

**对组织**（《慈善法》第 110 条第一项，违反第十四条造成慈善财产损失）：

1. 责令限期改正，予以警告，并没收违法所得
2. 逾期不改正的，责令限期停止活动并进行整改
3. 经依法处理后一年内再出现同类情形，或有其他情节严重情形的，吊销登记证书并予以公告

**对个人**（第 112 条）：

对直接负责的主管人员和其他直接责任人员处**二万元以上二十万元以下罚款**，并没收违法所得；情节严重的，**禁止其一年至五年内担任慈善组织的管理人员**。

## 七、损失挽回与责任追究

- **向参与决策的理事提出赔偿请求**：理事会违反规定或章程决策不当致使组织遭受财产损失的，参与决策的理事应承担相应赔偿责任（《基金会管理条例》第 43 条）。
- **请求人民法院撤销决定**：捐助法人的决策机构、执行机构或法定代表人作出决定的程序违反法律、行政法规、法人章程，或决定内容违反法人章程的，捐助人等利害关系人或者主管机关可以请求人民法院撤销该决定；但依该决定与善意相对人形成的民事法律关系不受影响（《民法典》第 94 条）。
