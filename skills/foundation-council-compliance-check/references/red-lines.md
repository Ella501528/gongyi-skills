# 硬红线与法条（red-lines）

> ⚠️ **版本提示（2026-09-29）**：《基金会管理条例》修订草案已于 2026-09-11 经国务院常务会议审议通过，**尚未正式公布施行**。本文依据的仍是现行《基金会管理条例》（国务院令第 400 号，2004 年施行）。修订正式公布后，本文涉及的条款号与数字门槛须逐项重新核对。


> 本文件汇总理事会治理的"一碰就违规"项。合规体检时这些项**只要不符合就标红、优先整改**，不存在"披露了就合规"的缓冲。
> 法条写清名称 + 条款号；记不准的标注"以现行文本核实"，严禁编条款号。

## 一、人员红线

| 红线 | 要求 | 依据 | 体检项 |
|------|------|------|--------|
| 理事人数 | 5 人至 25 人 | 《基金会管理条例》第二十条 | A03 |
| 每届任期 | 不超过 5 年（以章程为准，但不得超 5 年） | 《基金会管理条例》及章程 | A04 |
| 领酬理事比例 | 领取报酬的理事不超过理事总人数的 1/3 | 《基金会管理条例》（具体条款号以现行文本核实） | A05 |
| 监事 / 非专职理事取酬 | 监事及非专职理事不得从基金会获取报酬 | 《基金会管理条例》（具体条款号以现行文本核实） | A06、C03 |
| 理事监事近亲属交易禁令 | 理事、监事及其近亲属不得与所在基金会有**任何**交易行为 | 《基金会管理条例》忠实义务与利益冲突限制相关条款（具体条款号以现行文本核实） | B08、C06、E02 |
| 负责人年龄 | 理事长 / 副理事长 / 秘书长常见口径不超过 70 周岁 | 以现行规定与本会章程核实（未检索到可统一引用的单一法条） | B04 |
| 现职国家工作人员任负责人 | 在职公务员不得兼任基金会理事长 / 副理事长 / 秘书长 | 中办国办《关于党政机关领导干部不兼任社会团体领导职务的通知》等现行规定与《基金会管理条例》相关要求 | B05 |
| 近亲属同任理事会 | 理事的近亲属不得同在理事会任职 | 《基金会管理条例》（具体条款号以现行文本核实） | B06 |
| 法定代表人兼任 | 法定代表人不兼任其他组织法定代表人，须为内地居民 | 《基金会管理条例》（具体条款号以现行文本核实） | B07 |
| 监事禁止兼任 | 理事、理事近亲属、基金会财会人员不得兼任监事 | 《基金会管理条例》（具体条款号以现行文本核实） | C02 |
| 监事人数结构 | 1–2 人为监事，满 3 人设监事会；不要求奇数 | 通行做法；法律未强制单数 | C01 |
| 监事交易禁令 | 监事及其近亲属不得与基金会有任何交易 | 《基金会管理条例》（具体条款号以现行文本核实） | C06 |

## 二、会议红线

| 红线 | 要求 | 依据 | 体检项 |
|------|------|------|--------|
| 会议频次 | 每年理事会会议不少于 2 次 | 《基金会管理条例》（具体条款号以现行文本核实） | D01 |
| 法定人数 | 出席理事达章程规定（通常 2/3 以上）方可开会 | 条例与章程 | D04 |
| 特别决议基数 | 章程修改、选举罢免负责人、重大募捐投资、分立合并→出席理事 2/3 以上 | 《基金会管理条例》 | D05 |
| 财务资产制度 / 重大投资基数 | 财务和资产管理制度、重大投资方案→**全体理事** 2/3 以上 | 《慈善组织保值增值投资活动管理暂行办法》第九条 | D06 |
| 关联回避 | 关联事项须回避表决并记载于纪要 | 民发〔2025〕46 号六 | D11、E03 |

## 三、交易与披露红线

| 红线 | 要求 | 依据 | 体检项 |
|------|------|------|--------|
| 关联方名单 | 应建立并定期更新 | 民发〔2025〕46 号六 | E01 |
| 交易禁令 | 理事、监事及其近亲属不得与基金会有任何交易 | 《基金会管理条例》 | E02 |
| 关联交易程序 | 须履行回避与披露 | 民发〔2025〕46 号六 | E03 |
| 重大关联交易 | 须上理事会集体决定，不得授权个人 | 条例 / 46 号二 | E04 |
| 主要捐赠人任职 | 须排查在理事会任职情况 | 46 号 / 条例 | E05 |
| 交易披露 | 须在年报与信息公开中如实披露 | 《基金会管理条例》 | E06 |

## 四、红线处置原则

- **零容忍项（交易禁令、取酬禁止、人数 / 比例 / 任期）**：查到不符合，立即整改，不是"补披露即可"；
- **制度缺项（委托参会、回避、关联交易报告、信息披露等）**：属 `基础` 制度必备项，须补齐制度文本；
- **所有数字门槛**以现行《基金会管理条例》《慈善组织保值增值投资活动管理暂行办法》与本会章程核对，46 号文无数字。
