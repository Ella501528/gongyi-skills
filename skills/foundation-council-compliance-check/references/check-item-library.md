# 检查项库（check-item-library）

> ⚠️ **版本提示（2026-09-29）**：《基金会管理条例》修订草案已于 2026-09-11 经国务院常务会议审议通过，**尚未正式公布施行**。本文依据的仍是现行《基金会管理条例》（国务院令第 400 号，2004 年施行）。修订正式公布后，本文涉及的条款号与数字门槛须逐项重新核对。


> 本库整理自 A1-理事会治理合规体检表，共 **59 项**，按六域组织。每项含：**编号 / 检查项 / 依据代码 / 判定标准**。
> **依据代码约定**：`T`=基金会管理条例；`N`=民发〔2025〕46 号《关于加强社会组织理事会建设的意见》；`M`=慈善组织保值增值投资活动管理暂行办法；`C`=本会章程（参数项，须逐机构确认）；`F`=内部档案规范。个别项另引"中办国办意见""属地"，以注释保留。
> **关键提醒**：46 号文是规范性文件，**全文无任何具体数字**；凡涉及数字的门槛来自条例、办法与章程。

---

## 域一：治理结构与章程（16 项，A01–A16）

| 编号 | 检查项 | 依据 | 判定标准 / 合规底线 |
|------|--------|------|---------------------|
| A01 | 章程是否明确理事会职权、议事规则、表决办法 | T/C | 必备条款，缺项须修订章程并核准 |
| A02 | 是否制定《理事会工作制度》 | N二 | 建议建立；冲评估等级的机构必备 |
| A03 | 理事人数是否在 5 至 25 人区间 | T | 硬红线，超出即违规 |
| A04 | 每届任期是否不超过 5 年 | T/C | 硬红线，以章程为准但不得超过 5 年 |
| A05 | 领酬理事是否不超过理事总人数的三分之一 | T | 硬红线 |
| A06 | 监事及非专职理事是否未从基金会获取报酬 | T | 硬红线 |
| A07 | 是否建立《委托参会制度》（可否委托、受托人资格、是否计入出席、一人受托上限） | N六 | 制度必备；受托是否计入出席由章程决定 |
| A08 | 是否建立《回避表决制度》 | N六 | 制度必备 |
| A09 | 是否建立《关联交易报告制度》 | N六 | 制度必备 |
| A10 | 是否建立《信息披露制度》 | N六 | 制度必备 |
| A11 | 是否划分理事会／理事长／秘书长／监事会／办事机构权责边界 | N二 | 防越位，建议年度复盘 |
| A12 | 是否制定《三重一大事项判定规则》——哪些必须集体决定、不得授权个人 | N二 | 不得把三重一大决策权授权理事长或秘书长个人 |
| A13 | 是否制定《党组织参与决策事项清单》及参与三重一大安排 | N八 | 设党组织的机构必备 |
| A14 | 是否设置理事会办公室（依托秘书处）作为常设支撑机构 | N二 | 建议设置 |
| A15 | 是否建立理事履职记录、档案管理与信息公开制度 | N九 | 建议建立 |
| A16 | 是否建立内部矛盾纠纷防范化解机制（理事长协调→民主协商→第三方调解/司法） | N | 建议建立并留升级路径记录 |

## 域二：理事（10 项，B01–B10）

| 编号 | 检查项 | 依据 | 判定标准 / 合规底线 |
|------|--------|------|---------------------|
| B01 | 理事名册是否齐全（姓名、届次、任期起止、联系方式） | T/C | 名册为基础台账，须与备案一致 |
| B02 | 本届理事会是否已超过任期未换届 | T/C | 超期即违规；确需延期须单独上会审议 |
| B03 | 理事连任是否符合章程规定的连任上限 | C | 以章程为准 |
| B04 | 负责人（理事长／副理事长／秘书长）年龄是否符合要求 | T/C | 常见口径不超过 70 周岁，以现行规定与章程核实 |
| B05 | 是否存在在职公务员兼任基金会负责人 | 中办国办意见 | 硬红线，须清理 |
| B06 | 理事变动是否及时向登记管理机关备案 | T | 变动须备案，未备案影响年报与评估 |
| B07 | 是否建立理事履职记录（出席率、履职评价） | N九 | 建议建立；年报与评估会查 |
| B08 | 理事及其近亲属是否与基金会发生任何交易 | T | 硬红线，零容忍 |
| B09 | 理事是否具备完全民事行为能力、无不得任职情形 | T | 任职资格底线 |
| B10 | 是否设名誉理事长；如设，是否排查主要捐赠人任职条款 | C | 关联交易风险源，须排查 |

## 域三：监事（8 项，C01–C08）

| 编号 | 检查项 | 依据 | 判定标准 / 合规底线 |
|------|--------|------|---------------------|
| C01 | 监事人数是否符合要求（1 至 2 人为监事，满 3 人设监事会） | T | 满 3 人须设监事会；不要求奇数 |
| C02 | 理事及其近亲属是否未担任监事 | T | 硬红线 |
| C03 | 监事是否未从基金会获取报酬 | T | 硬红线 |
| C04 | 监事是否列席理事会会议并发表意见 | T | 列席与监督为法定职责 |
| C05 | 会议纪要是否设置监事意见栏并由监事本人签署 | T/F | 多位监事须逐人签，不可共签一份 |
| C06 | 监事及其近亲属是否与基金会发生任何交易 | T | 硬红线，零容忍 |
| C07 | 监事是否按章程任期任职、是否与理事任期同步换届 | C | 以章程为准 |
| C08 | 监事变动是否及时备案 | T | 变动须备案 |

## 域四：会议（14 项，D01–D14）

| 编号 | 检查项 | 依据 | 判定标准 / 合规底线 |
|------|--------|------|---------------------|
| D01 | 每年理事会会议是否不少于 2 次 | T | 硬红线 |
| D02 | 会议通知是否提前 5 日发出（决议重要事项的会议不少于 7 日） | T/C | 通知期出自章程示范文本（条例未规定），非 46 号文；以本机构章程为准 |
| D03 | 议案材料是否提前送达（常规会 10 日、临时会 5 日） | T/C | 以章程为准 |
| D04 | 出席理事人数是否达到章程规定（通常三分之二以上） | T/C | 会议能否召开的门槛，会前必须预核验 |
| D05 | 特别决议事项是否达到出席理事三分之二以上（章程修改、选举罢免负责人、章程规定的重大募捐投资、分立合并） | T | 基数为出席理事 |
| D06 | 财务和资产管理制度、重大投资方案是否达到决策机构全体组成人员三分之二以上 | M九 | 基数为全体理事，比 D05 更严格，人没来齐就过不了 |
| D07 | 普通决议是否达到出席理事过半数 | T/C | 以章程为准 |
| D08 | 会议记录是否完整、有无反对意见记载（免责以记载于会议记录为准） | T | 免责条文原话为记载于会议记录 |
| D09 | 会议纪要要素是否齐全（应到实到、监事列席人数、表决方式、逐项票数、监事意见） | T/F | 缺项易被退回 |
| D10 | 委托出席是否符合章程（受托人资格、一人受托上限、是否计入出席） | N六/C | 受托是否计入出席由章程决定 |
| D11 | 关联事项是否回避表决并在纪要中记载 | N六 | 硬要求 |
| D12 | 反对票与弃权票是否逐项记载 | T/F | 不能只写会议通过 |
| D13 | 通讯方式开会是否符合章程约定、是否留存全部书面反馈原件 | C | 章程有约定方可采用 |
| D14 | 会议材料与签字页是否归档、卷内目录是否齐备 | F | 档案可追溯 |

## 域五：关联交易与利益冲突（6 项，E01–E06）

| 编号 | 检查项 | 依据 | 判定标准 / 合规底线 |
|------|--------|------|---------------------|
| E01 | 是否建立关联方名单并定期更新 | N六 | 排查的基础 |
| E02 | 理事、监事及其近亲属是否与基金会有任何交易 | T | 硬红线，零容忍 |
| E03 | 关联交易是否履行回避与披露程序 | N六 | 程序要件 |
| E04 | 重大关联交易是否上理事会集体决定 | T/N二 | 不得授权个人 |
| E05 | 是否排查主要捐赠人在理事会任职情况 | N/T | 关联交易风险源 |
| E06 | 关联交易是否在年报与信息公开中如实披露 | T | 披露义务 |

## 域六：信息公开与报送（5 项，F01–F05）

| 编号 | 检查项 | 依据 | 判定标准 / 合规底线 |
|------|--------|------|---------------------|
| F01 | 理事会会议情况是否在年度工作报告中如实填报 | T | 年报必备 |
| F02 | 理事、监事变动是否及时公开 | T | 信息公开义务 |
| F03 | 理事会重大决议是否按要求公开 | T | 信息公开义务 |
| F04 | 换届材料是否按规定时限报登记管理机关 | T/属地 | 属地口径，换届示例（北京）为会前 30 日报送、会后 30 日内提交 |
| F05 | 章程修改是否办理核准 | T | 修改须核准 |

**合计：16 + 10 + 8 + 14 + 6 + 5 = 59 项。**
