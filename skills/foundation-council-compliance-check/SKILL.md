# 合规体检（理事会治理自查）

「合规体检」是对理事会治理六大域（治理结构 / 理事 / 监事 / 会议 / 关联交易 / 信息公开）做一次全面自查，共 **59 项检查项**。本 Skill 是年检、抽查、换届三道关口的前置动作——先体检、出缺项、建整改台账，再决定补什么材料。

> 核心知识资产：A1-理事会治理合规体检表（8 个工作表、59 项检查项）。全部检查项库见 `references/check-item-library.md`。

## 作业顺序

1. **定体检范围与频次**（基础）：建议每年至少一次；换届前、评估前、年报前各加一次专项体检（见 A1「0-使用说明」）。
2. **分域逐项自查**（基础）：按 治理结构与章程 / 理事 / 监事 / 会议 / 关联交易 / 信息公开 六个域，逐项在「自查结果」选 符合 / 不符合 / 不适用，不符合的填问题描述、整改期限、责任人。
3. **先卡硬红线**（基础）：凡触红线的（理事人数、任期、领酬比例、取酬禁止、交易禁令、任职资格）一律标"不符合"并优先整改（见 `references/red-lines.md`）。
4. **核对两个 2/3**（基础，最易写错）：特别决议（条例口径，基数=出席理事）与财务资产管理制度 / 重大投资方案（办法第 9 条，基数=全体理事）必须分清楚（见 `references/two-thirds-rules.md`）。
5. **汇总结论**（基础）：填「7-体检结论汇总」，得出 通过 / 有条件通过 / 不通过，列出待整改项编号。
6. **出问题清单与整改台账**（基础）：把"不符合"项导出为问题清单，逐条建整改台账（含责任人、期限、状态）。
7. **做章程一致性核对**（进阶）：把体检发现的制度缺项与章程条款逐条对照，确认"章程写没写、制度建没建、执行留没留痕"（见 `templates/04-章程一致性核对表.md`）。

## 使用铁律

1. **数字门槛只来自条例、办法与章程**：凡涉及具体数字的门槛，一律来自《基金会管理条例》《慈善组织保值增值投资活动管理暂行办法》与本会章程；民发〔2025〕46 号是规范性文件，**全文无任何具体数字**，不得据其写"每年几次""2/3"等门槛。
2. **两个 2/3 绝不混用**：条例特别决议基数=**出席理事**；财务和资产管理制度、重大投资方案（办法第 9 条）基数=**全体理事**，更严格，人没来齐就过不了。
3. **红线零容忍、不可"披露即合规"**：理事、监事及其近亲属不得与基金会有任何交易；监事及非专职理事不得取酬；理事人数 5–25、领酬理事≤1/3、任期≤5 年——这些是硬底线，不是补个披露就过关。
4. **分级不劝退**：动作建议一律标 `基础` / `进阶`；禁止"小机构不必硬套"等劝退式表述，改为"按机构实际情况取用必要环节"。
5. **法条写清名称与条款号**：引用法条须写法律名称 + 条款号；记不准的写"以现行文本核实 / 未检索到明确依据"，严禁编条款号。
6. **隐私零容忍**：不出现真实机构名、真人姓名、联系方式；示例用"某某基金会""张三"，模板用 `{占位符}`。
