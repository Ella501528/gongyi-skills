# 基金会等级评估·存量材料盘点与归位

只读扫描本地资料库，按指标末级要点自动匹配归位，输出缺项清单与待人工确认清单

## 能力

面向基金会/社会组织等级评估的存量材料盘点与归位。对机构已有的本地资料库做只读扫描建索引，匹配到评估指标末级要点，按 index / link / copy 三种模式就位到归档文件夹树，回填清单主表，并输出缺项清单、待人工确认清单、同名多版本清单与归位体积预演。自带 7 个脚本：扫描建索引、指标匹配、主体区分、文件就位、一致性校验、同名多版本检测、结果回填。

## 触发方式

在对话中直接描述需求即可，例如：

- 「把我们今年的评估指标表拆成逐项资料清单」
- 关键词：公益慈善、等级评估、材料归位、资料盘点、归档
