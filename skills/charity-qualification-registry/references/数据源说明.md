# 数据源说明

本库全部数据来自官方公开渠道。逐源记录取数方式、参数含义与注意事项。

---

## 一、慈善中国（cszg.mca.gov.cn）

全国慈善信息公开平台，民政部主办。覆盖 R1 慈善组织名录、R2 公开募捐资格、R6 信用状况、R7 慈善信托。

### 1.1 访问门槛

列表页与详情页均会重定向到滑块校验页 `/biz/ma/csmh/filter/slideCaptchaindex.html`。通过后同一会话内不再拦截。

求解方式（`core/session.py`）：请求 `getSlideCaptcha` 取背景图与缺口图 → 对背景图做反混合网格搜索定位缺口左边界 → 在验证页上下文调用站内 `encode64` 编码答案 → 提交 `slideCaptchaCheck` 直至返回 `status=success`。全程走网络请求与页面内脚本，不模拟鼠标轨迹，无头模式可运行。

实测多数情况 1–3 次尝试内通过。失败时抛出异常，不会静默返回空数据。

### 1.2 用到的接口

| 用途 | 接口 |
|---|---|
| 列表 | `/biz/ma/csmh/a/csmhaDoSortNew.html`（返回 HTML 表格片段） |
| 总数 | `/biz/ma/csmh/a/csmhaDoSortCountNew.html`（返回 JSON `{"count":N}`） |
| 详情 | `/biz/ma/csmh/a/csmhadetail.html?aaee0101=<机构ID>` |

每页 15 条。翻页由 `pageNo` 参数控制，无需点击操作。

### 1.3 列表接口参数

| 参数 | 含义 | 取值 |
|---|---|---|
| `pageNo` | 页码 | 从 1 开始 |
| `aaee0102_03` | 关键词 | 统一社会信用代码或机构名称 |
| `zzlb` | 组织类别 | 0 全部／1 社会团体／2 民办非企业单位／3 基金会 |
| `zzzt` | 组织状态 | 0 全部／1 正常／2 注销／3 撤销 |
| `xyzk` | 信用状况 | 0 全部／1 正常／2 活动异常名录／3 严重违法失信名单 |
| `mjzg` | 是否具有公开募捐资格 | 0 全部／1 是／2 否 |
| `djnx` | 登记年限 | 0 全部／1 一年内／2 一到五年／3 五到十年／4 十年以上 |
| `azzx0023` | 登记区域代码 | 12 位数字，如 `110000000000` 北京 |
| `benji` | 本级 | 0／1 |
| `field` / `sort` | 排序字段与方向 | 如 `aaee0105` / `desc` |

### 1.4 列表返回字段

解析自 HTML 表格片段的 5 列：

| 列 | 说明 |
|---|---|
| 序号 | 仅用于展示 |
| 统一社会信用代码 | 同时作为详情链接锚文本 |
| 组织名称 | **状态后缀紧随其后**（如「正常」「活动异常名录」），需单独剥离 |
| 成立时间 | 站点返回英文月份格式（`Aug 27, 2026`），入库前统一转 ISO |
| 登记管理机关 | 即「注册部门」 |

机构 ID 取自链接参数 `aaee0101`，作为本库的主键 `org_id`。

### 1.5 详情页字段

`组织名称` `统一社会信用代码` `成立时间` `登记管理机关` `是否取得公益性捐赠税前扣除资格`
`税前扣除资格有效期` `是否具有公开募捐资格` `慈善组织认定登记日期` `组织住所`
`法定代表人` `业务范围` `电子邮箱地址` `传真号` `门户网站` `官方微博` `联系人`
`联系电话` `官方微信公众号` `移动客户端等其他网络平台`

主标签含 `年度工作报告和财务会计报告` `公开募捐情况` `慈善项目有关情况` `慈善信托有关情况` `重大事件` `其他公示信息`；
基本信息子标签含 `行政处罚信息` `评优获奖信息` `等级评估信息`。

> 该源**不提供「业务主管单位」字段**。

## 二、公益性捐赠税前扣除资格名单（R3）

### 2.1 发布主体与频率

财政部 + 税务总局 + 民政部联合公告，一年发布 1–2 批，通常在上年末或年初。

### 2.2 取数方式

公告全文由各地税务局官网转载，**正文即纯文本编号名单，无需下载附件**。用 `httpx` 直接抓取即可，无需浏览器渲染。

多省互为备份，脚本按顺序尝试，取第一个解析成功的源。更换源时同步更新 `fetch_tax.py` 的 `SOURCES`。

### 2.3 公告结构

```
一、YYYY年度—YYYY年度符合公益性捐赠税前扣除资格的公益性社会组织名单
    1.机构全称
    2.……
二、YYYY年度—YYYY年度符合……名单
    1.……
三、取消公益性捐赠税前扣除资格的公益性社会组织名单
    1.机构全称
```

解析规则：识别以 `一、二、三、` 开头且含「名单」的段落标题 → 从标题提取年度区间 → 提取段落内形如 `序号.机构全称` 的条目。含「取消」的段落单独处理为负向记录。

### 2.4 已知批次

| 文号 | 发布时间 | 内容 |
|---|---|---|
| 2025 年第 21 号 | 2025-12-31 | 2025—2027 年度 8 家 + 2026—2028 年度 109 家 |
| 2024 年第 22 号 | 2024-12-31 | 2024—2026 年度 + 2025—2027 年度；含取消 1 家 |

### 2.5 注意

- 同一机构可能同时出现在多个批次名单中（有效期区间不同），以最新公告为准。
- 「取消资格」名单是独立的高价值负向信息，不可略过。

## 三、尚未纳入的数据源

| 名录 | 数据源 | 难点 |
|---|---|---|
| R4 非营利组织免税资格 | 省级财政／税务／民政联合公布 | 各地格式差异极大，见下方四地实测 |
| R5 社会组织评估等级 | 省市民政部门公告 | 分散在不同层级民政部门，公告形式不统一；慈善中国详情页有「等级评估信息」子标签可作补充 |
| R7 慈善信托备案 | 慈善中国 | 首页有独立查询模块，接口待确认 |
| R8 互联网公开募捐服务平台 | 民政部公告 | 数量少（约 30 家）、变动极少，可静态维护 |

### 3.1 R4 四地实测（2026-09）

| 城市 | 发布层级 | 名单形态 | 实现难度 |
|---|---|---|---|
| **上海** | 市级统一（分批） | **HTML 结构化表格**：序号／统一社会信用代码／名称／有效期起／有效期止／主管税务机关 | **低** —— 唯一可直接解析的 |
| **广州** | 省级／市级／区级三层 | 公告页为 HTML，名单在 **PDF／WPS 附件**；但设有**政策专题汇总页**，一页列出全部历史公告 | 中 —— 有汇总页便于发现，需 PDF 解析 |
| **深圳** | 市级统一（按批次） | 名单在 **PDF 附件** | 中 —— 来源集中，但需 PDF 解析 |
| **北京** | 市级汇总 + **各区各自发布** | 区级公告多为 **PDF 附件**，格式不一 | **高** —— 来源最分散 |

**建议推进顺序**：上海（直接做）→ 深圳（单一来源）→ 广州（有汇总页）→ 北京（最分散）。

上海的名单带统一社会信用代码，可与机构主表精确匹配，是四地中数据质量最高的。

### 3.2 上海 R4 样例

```
序号  统一社会信用代码        名称                有效期起      有效期止
1    5231XXXXXXXXXXXXXX    （某研究院）          2025-09-01   2029-12-31
2    5331XXXXXXXXXXXXXX    （某教育奖励基金会）   2025-01-01   2029-12-31
```

有效期规则：免税资格自获得年度起有效 **5 年**（财税〔2018〕13 号）。

## 四、抓取礼仪

- 慈善中国默认限速 0.8 秒／页（`CQR_PACE` 可调）；公告页低频访问，无需限速。
- 不并发、不重试轰炸。
- 仅采集公开披露信息；不使用任何账号登录态，不代登录，不碰密码。
